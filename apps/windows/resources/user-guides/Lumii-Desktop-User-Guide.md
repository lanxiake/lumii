## 1. 快速上手

### 1.1 界面布局

主界面分为三个区域：

| 区域 | 位置 | 说明 |
|------|------|------|
| 左侧边栏 | 最左侧 | 会话列表、功能导航、搜索框 |
| 主工作区 | 中间 | 对话内容、资讯流、工作区 |
| 设置面板 | 右侧抽屉 | 点击底部「设置」按钮展开 |

**顶部工具栏**包含以下功能按钮：
- 切换深色/浅色主题
- 调整字号
- 打开录屏面板
- 最大化/最小化/关闭

**底部会话输入区**支持：
- 文本输入（Enter 发送）
- 添加附件、技能与 Agent
- 选择推理努力程度（High / Max）
- 中途插话功能
- 上下文压缩

![主界面概览](./assets/02-chat.jpg)

### 1.2 发起第一个对话

1. 点击左侧边栏底部的 **+ 新建对话**
2. 在输入框中输入你的问题
3. 按 `Enter` 或点击发送按钮
4. 等待 AI 回复

### 1.3 会话管理

| 操作 | 方法 |
|------|------|
| 新建对话 | 点击「+新建对话」按钮 |
| 搜索会话 | 在顶部搜索框输入关键词 |
| 置顶会话 | 点击会话卡片上的 📌 按钮 |
| 删除会话 | 点击会话卡片上的 🗑 按钮 |
| 切换标签页 | 点击「默认」或「渠道」标签 |

### 1.4 顶部快捷功能

主界面顶部提供以下快捷入口：

| 按钮 | 功能 |
|------|------|
| 工作空间文件 | 打开工作空间文件浏览器 |
| 资料库 | 访问 Wiki 知识库 |
| Enter pet mode | 进入宠物/桌宠模式 |

主工作区还可切换到 Dashboard 视图，展示最新资讯流与快捷入口：

![Dashboard 资讯流](./assets/01-dashboard.jpg)

## 2. 必须配置

### 2.1 模型配置（核心）

**模型配置是使用 AI 功能的前提。** 进入：**设置 → 模型配置**

![模型配置页面](./assets/08-settings-model-config.jpg)

#### 配置参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| Provider 类型 | API 提供商 | OpenAI 兼容 / Anthropic / DeepSeek 等 |
| 接口地址 | API Base URL | `https://api.openai.com` 或自定义 |
| API Key | 访问密钥 | `sk-...` |
| API 格式 | 请求格式 | Responses（推荐）/ Completions |
| 模型 ID | 模型标识 | `MiniMax-M2.7`, `gpt-4o` 等 |
| 上下文长度 | 最大 Token 数 | 根据模型填写（单位：K） |

#### 支持的 Provider 类型

| Provider | 说明 | 适用场景 |
|----------|------|----------|
| **OpenAI 兼容** | OpenAI、DeepSeek、MiniMax 等 | 通用场景 |
| **Anthropic** | Claude 系列 | 高质量对话 |
| **Google Gemini** | Gemini 系列 | Google 生态 |
| **DeepSeek** | DeepSeek 专用 | 性价比高 |
| **Ollama（本地）** | 本地部署的 Ollama | 完全离线 |
| **LM Studio（本地）** | 本地部署的 LM Studio | 完全离线 |

#### 配置步骤

1. 选择 Provider 类型（建议 OpenAI 兼容）
2. 填写接口地址（如使用第三方 API）
3. 填入 API Key
4. 选择 API 格式（**建议 Responses**，支持缓存）
5. 填写模型 ID，多个用逗号分隔
6. 为每个模型填写上下文长度（单位：K）
7. 点击 **保存全部** 按钮

> **提示**：首次配置建议从「已启用/未启用」切换按钮了解功能区域划分，点击「收起配置」可隐藏详细配置。

### 2.2 渠道设置（可选）

如需接入微信或企业微信，进入：**设置 → 渠道设置**

![渠道设置页面](./assets/12-settings-channels.jpg)

| 渠道 | 功能 | 状态 |
|------|------|------|
| 微信 | 接入微信对话 | 需扫码接入 |
| 企业微信 | 接入企业微信 | 需扫码接入 |

#### 接入微信步骤

1. 点击 **扫码接入** 按钮
2. 使用微信扫描二维码
3. 确认授权连接
4. 连接成功后显示「已连接」状态

> **注意**：微信接入需要用户先发送一条消息才能激活被动消息接收。

#### 断开连接

已连接的渠道可点击 **断开** 按钮解除连接。

## 3. 核心功能

### 3.1 对话与任务

#### 会话管理

| 操作 | 按钮位置 | 说明 |
|------|----------|------|
| 新建对话 | 左下角 | 点击「+新建对话」 |
| 搜索会话 | 左侧中部 | 输入关键词快速定位 |
| 置顶会话 | 会话卡片右上 | 📌 按钮，重要会话置顶 |
| 删除会话 | 会话卡片右上 | 🗑 按钮，删除后会话不可恢复 |

#### 会话标签页

- **默认**：普通对话会话
- **渠道**：微信/企业微信接收的消息会话

#### 会话功能菜单

每个会话卡片支持：
- **定时任务**：为当前会话创建定时任务
- **抓取资讯**：一键抓取最新资讯
- **会话置顶/删除**：管理会话列表

### 3.2 技能市场

进入：**设置 → 技能**

Lumii 内置 18 个已安装技能，覆盖多个场景：

| 类别 | 技能数 | 功能说明 |
|------|--------|----------|
| 代码开发 | 1 | Codex/Claude Code 等编程助手 |
| 技能管理 | 3 | 创建、管理、评估技能 |
| 内容创作与发布 | 1 | 小红书内容创作与发布 |
| 设计与可视化 | 3 | 图片生成、海报设计、前端界面 |
| 视频创作 | 2 | 视频生成、剪辑、配音 |
| 文档与分析 | 5 | Word、PDF、Excel、PPT 处理 |
| 语音与音频 | 1 | 本地 TTS 语音合成 |
| 智能体协作 | 1 | 多智能体团队协作 |
| 未分类 | 1 | 其他功能 |

### 4.2 工作空间

进入：**设置 → 工作空间**

![工作空间页面](./assets/10-settings-workspace.jpg)

| 配置项 | 说明 |
|--------|------|
| 工作空间目录 | 默认为 `C:\Users\<用户>\.lumii\workspace` |
| 选择目录 | 点击可自定义工作空间路径 |
| 恢复默认 | 恢复系统默认路径 |
| 保存设置 | 保存工作空间配置 |

#### 目录结构

```
workspace/
├── uploads/     # 用户上传的文件
├── outputs/     # AI 生成的文件（图片、文档、代码等）
└── files/       # 用户的个人文件
```

#### 输出组织规范

生成的文件按项目/任务组织：

```
outputs/<project-or-task>/
├── documents/   # 报告、文章、笔记
├── data/        # CSV、JSON、Excel
├── images/      # 生成的图片
├── audio/       # 生成的音频
├── video/       # 生成的视频
└── code/        # 源代码文件
```

## 5. 工作目录

### 5.1 目录说明

| 目录 | 用途 | 访问方式 |
|------|------|----------|
| `uploads/` | 用户上传的文件，AI 可读取处理 | 工作空间文件按钮 |
| `outputs/` | AI 生成的文件（图片、文档、代码等） | 工作空间文件按钮 |
| `files/` | 用户的个人文件 | 工作空间文件按钮 |

### 5.2 文件管理

- 点击顶部工具栏的「工作空间文件」按钮可打开文件浏览器

- AI 可直接读取 `uploads/` 和 `files/` 目录中的文件

## 6. 快捷键与故障排查

### 6.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 新建对话 |
| `Ctrl + K` | 搜索会话 |
| `Ctrl + ,` | 打开设置 |
| `Escape` | 关闭弹窗/面板 |

### 6.2 故障排查

| 问题 | 解决方案 |
|------|----------|
| AI 无响应 | 检查模型配置和 API Key 是否正确 |
| 微信无法连接 | 确认已扫码接入，被动消息需要先发一条消息 |
| 技能无法使用 | 检查技能是否已启用 |
| 定时任务未执行 | 检查任务状态和执行记录 |
| 语音识别不工作 | 下载语音模型或切换到云端识别 |

### 6.3 日志位置

日志目录：`C:\Users\<用户>\.lumii\logs`

| 日志文件 | 内容 |
|----------|------|
| `main-YYYY-MM-DD.log` | 主进程日志 |
| `agent-runtime-YYYY-MM-DD.log` | Agent 运行时日志 |
| `channel-*.log` | 渠道适配器日志 |

如遇问题，可查看日志文件排查错误。

### 6.4 客户端自愈

如遇配置异常，可尝试以下操作：

| 操作 | 命令 | 说明 |
|------|------|------|
| 健康检查 | `lumii doctor` | 检查应用状态 |
| 查看日志 | `lumii logs list` | 列出日志文件 |
| 清理日志 | `lumii logs clean` | 清理旧日志 |
| 重启应用 | `lumii app restart` | 重启桌面客户端 |

> **警告**：重启应用会中断当前对话。
