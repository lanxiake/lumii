## 1. Wiki 是什么

Wiki 是你的**个人资料库**：把文件、网页链接、笔记放在一起，像文件夹一样浏览和搜索。

**三个特点：**

1. **先收进来，再慢慢分** — 新东西默认进「收件箱」，不必立刻想放哪  
2. **在 App 里就能看** — 点标题预览内容；很少需要打开磁盘上的原文件  
3. **文件在 workspace 里** — 资料保存在 `<工作空间>/wiki/` 文件夹，资源管理器里也能看到  

与「工作记忆」「个人记忆」不同：Wiki 存的是**真实资料和正文**，不是对话摘要。聊天文字不会自动进 Wiki；你上传的文件、保存的链接可以。

**应用内帮助**：Wiki 顶栏右侧 **?** 按钮可打开操作指引抽屉；左栏与各功能悬停可查看简要说明。

## 3. 资料怎么进来

### 3.1 添加文件

点 **「+ 添加文件」**，或聊天里上传附件 → 资料进入 **收件箱**。

- 原文件**不会自动搬家**，只在 Wiki 里建立「引用」  
- 系统会尝试抽取正文方便搜索（PDF、Word、Markdown 等）  
- **不会自动帮你分类** — 分类由你决定  

### 3.2 添加链接

点 **「+ 添加链接」**，粘贴网址 → 进入 **收件箱**。

- 默认**只保存链接**（标题 + 网址），**不会自动下载网页**  
- 需要离线阅读时，在预览里点 **「保存网页内容」**  

### 3.3 从文件夹导入（先预览映射，再确认整理）

Wiki → **收件箱** → **「从文件夹导入」**：

1. 选择本地文件夹（例如 `outputs/某任务/`）  
2. 系统预览可导入数量与目录结构 → 确认  
3. **默认先规划映射方案**（按源目录树推断落点），在预览面板确认或调整后再整理入库  
4. 需要跳过预览、直接 AI 分类时，可在 Agent 指令里明确要求（见 §3.5）  
5. 无法确定的文件留在 **收件箱**，可批量重试或手动归档  

原文件不移动，Wiki 只建立引用。适合一次性整理任务产物、下载目录等。

### 3.4 新建笔记

在某个分类下可新建 Markdown 笔记，直接写在 `wiki/` 文件夹里。

### 3.5 让 Agent 帮忙整理

在聊天中可以直接说：

> 帮我把 `outputs/竞品调研` 目录下的文件整理到 Wiki（资料库）

Agent 会通过 **`lumii-ui` CLI**（不是只读 wiki 工具）完成：

1. `wiki folder scan` — 预览可导入文件、`directoryTree`、`topicOccupancy`  
2. `wiki folder import` — **默认先预览映射**（`migrateRun.phase=review`），确认后再 apply  
3. `wiki inbox count --status pending` — 验证是否还有待人工处理的条目  

仅当用户明确要求「只导入不分类」时加 `--no-auto-classify`。

## 4. 日常怎么用

### 4.1 收件箱（推荐先看这里）

新资料都会先到 **收件箱**。不必一条条点，可以批量处理：

1. 左栏点 **收件箱**  
2. **勾选**要处理的条目（或点 **全选**）  
3. 选操作：  
   - **批量归档到…** — 一次把多条放进同一分类（最常用）  
   - **批量重试** — 对失败/待处理的条目重新跑后台处理  
   - **全部重试** — 未勾选时，一键重试所有可重试条目  
   - **批量删除** — 永久删除所选条目  

单条操作：点标题预览 → **归档到…** / **重试** / **删除**。

### 4.2 浏览已分类资料

1. 左栏点 **工作 / 学习 / 生活 / 收藏 / 归档**  
2. 右侧出现该分类下的资料列表  
3. **点任意一行** → 弹出预览（详情抽屉）  

列表行尾 **⋯** 菜单：移到…、保存网页内容、迁入 wiki、稍后处理、删除等。

### 4.3 预览（最常用）

点标题或整行 → 看正文、Markdown 或链接卡片。

- **文件**：显示提取出的文字；看原文件用预览区里的「打开原文件」  
- **链接（未保存）**：显示标题和网址；点「在浏览器打开」或「保存网页内容」  
- **已保存的网页**：显示 Markdown 正文  

### 4.4 搜索

顶栏搜索框 → 输入关键词 → 回车。悬停搜索框可看说明。

### 4.5 分类（移到… / 归档到…）

1. 在列表点 **⋯ → 移到…** 或收件箱里 **归档到…**  
2. 选 **工作 / 学习 / 生活 / 收藏 / 归档**，再选小类  
3. 点 **确定**  

对已入库文件，选择器里可点 **「让 AI 建议」** 参考分类（采纳与否由你决定）。

**批量移动**：在分类目录内多选文件后 **移动到…**；在收件箱多选后 **批量归档到…**。

### 4.6 保存网页内容

只对**链接类**资料：预览 → **「保存网页内容」** → 等几秒离线可读。

### 4.7 迁入 wiki（可选）

对**本地文件引用**：预览或 ⋯ → **「迁入 wiki」** → **复制**到当前分类，**原文件保留**。

## 5. 分类怎么选（口诀）

| 分类 | 放什么 |
|------|--------|
| **收件箱** | 刚进来、还没想好 |
| **工作** | 跟上班、项目、赚钱有关 |
| **学习** | 主动在学、在读、在备考 |
| **生活** | 私人、家庭、证件、日记 |
| **收藏** | 网上看到的链接、模板、参考资料 |
| **归档** | 暂时不用了 |

**拿不准就留在收件箱**，没有对错。

## 8. 常见问题

**Q：为什么新文件一直在收件箱？**  
A：正常。系统**不会自动分类**；可勾选多条 **批量归档到…**，或暂时留在收件箱。

**Q：能不能 AI 自动全部归档？**  
A：默认**不会静默改分类**。可用 **批量归档** 手动一次归位；对已分类文件可用 **全库重新编目** 让 AI 给建议（须你确认）。

**Q：保存链接后为什么看不到正文？**  
A：默认只存链接。需要正文请点 **「保存网页内容」**。

**Q：原文件会被移动或删除吗？**  
A：不会。只有主动 **迁入 wiki** 才会复制到 `wiki/`。
