## 触发词

知识猫图解 / 做一套图解 / 图解百科 / 科普图解 / 自然科普系列 / 博物馆图鉴风

## 四步生成流程（摘要）

```text
STEP 1 主体识别与科学叙事提炼（分类 / 认知颠覆点 / 核心科学结论）
  ↓
STEP 2 动态分镜模块选择（M00～M99，4～7 张，禁止强行套用不适配模块）
  ↓
STEP 3 逐张生成独立英文 Prompt（含 STYLE DNA + 单张模板）
  ↓
STEP 4 系列规划表 → 模块依据 → 逐张 Prompt → 平台适配说明
```

## 视觉硬约束（摘要）

| 维度 | 规范 |
|------|------|
| 背景 | 暖羊皮纸 `#F0EDE6` + 亚麻质感 |
| 标题 | 中文宋体粗体 + 全大写英文副标题 |
| 标注 | 细线 + 白色小圆点锚点，禁止气泡框 |
| 画风 | 写实 3D CGI 科学图解（DK 百科美学） |
| 比例 | 3:4 竖版（1024×1365） |
| 页脚 | `— 知识猫图解 · 第X页 / 共N页 —` |
