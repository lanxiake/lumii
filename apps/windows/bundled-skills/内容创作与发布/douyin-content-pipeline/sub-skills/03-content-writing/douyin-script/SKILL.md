# 抖音短视频脚本

为抖音（及同类竖版短视平台）生成带时间轴的分镜脚本、口播稿、字幕文案与发布描述。

合并自原 `tiktok-script` 与 `tiktok-captions`，面向中文抖音场景本地化。

## 适用场景

- 用户说「写一条抖音脚本」「帮我写口播稿」
- 用户需要 15/30/60 秒短视频分镜
- 用户需要发布标题、描述、话题标签
- 用户要把长文/干货改写成抖音短视频

**不适用**：付费投放策略（见独立广告类技能）、YouTube 长视频频道策略。

## 视频规格（供剪辑/拍摄参考）

| 规格 | 值 | 说明 |
|------|-----|------|
| 画幅 | 9:16 竖版 | 标准手机全屏 |
| 分辨率 | 1080×1920 | 推荐 |
| 时长 | 15-60 秒 | 干货教程可到 3 分钟 |
| 格式 | MP4 / MOV | H.264 + AAC |
| 字幕 | 必须 | 约 85% 用户静音观看 |

## 默认工作流

### Step 1：收集输入

若信息不足，一次性询问：

- **主题**：这条视频讲什么？
- **钩子角度**：什么能让人停下滑动？
- **目标受众**：年龄、兴趣、痛点
- **时长**：15 / 30 / 60 秒（或更长教程）
- **形式**：口播、屏录教程、图文卡点、剧情演绎
- **CTA**：关注、评论、收藏、橱窗/链接

### Step 2：写钩子（前 2-3 秒）

钩子决定约 95% 的完播表现。观众在 2 秒内决定留或走。

| 公式 | 示例 | 适用 |
|------|------|------|
| 反常识 | 「kubectl 不是一个人在干活」 | 知识科普 |
| 痛点直击 | 「还在手动改 YAML？停」 | 教程 |
| 结果预告 | 「3 步让 Pod 自愈」 | 干货清单 |
| 提问 | 「你知道 apply 背后有几个组件吗？」 | 好奇心 |
| 数字冲击 | 「6 个组件，少一个都跑不起来」 | 清单类 |

**规则**：

- 0.5 秒内开口，禁止「大家好我是…」式开场
- 第一帧有视觉变化或文字叠加
- 不要用 Logo 开场

### Step 3：写主体（按时长）

**15 秒结构**：

```text
[0-2s]  钩子 — 一句话 + 视觉打断
[2-10s] 一个核心点 — 快、准、具体
[10-15s] CTA — 关注/收藏/评论
```

**30 秒结构**：

```text
[0-2s]  钩子
[2-8s]  铺垫 — 为什么现在要看
[8-22s] 内容 — 最多 3 个要点
[22-28s] 收束 — 结果或对比
[28-30s] CTA
```

**60 秒结构**：

```text
[0-2s]  钩子
[2-8s]  场景 — 给谁、解决什么问题
[8-38s] 要点 1-3（每点 8-12 秒）
[38-50s] 总结 — 「一句话记住」
[50-55s] 证明 — 数据/对比/前后
[55-60s] CTA
```

**内容规则**：

- 一条视频 = 一个核心观点
- 口语化，约 8 年级阅读难度
- 能演示就演示（屏录、白板、实物）
- 剪掉废话，每秒都要有信息

### Step 4：标注画面与字幕

在脚本中标注：

```text
[0:00] 口播：「停！kubectl apply 背后站着 6 个打工仔」
       画面：特写 + 手写风标题字卡
       字幕：kubectl apply 背后有 6 个组件

[0:03] 口播：「第一个是 API Server…」
       画面：架构简笔画 + 箭头标注
       字幕：① API Server — 大门保安
```

### Step 5：写发布描述与标签

**描述结构**：

```text
[钩子句 — 与视频同能量]
[补充 1-2 句价值说明]
[CTA：收藏/关注/评论区提问]

#话题1 #话题2 #话题3 …（5-15 个，垂类为主）
```

| 标签类型 | 数量 | 示例 |
|----------|------|------|
| 垂类核心 | 3-5 | #kubernetes #云原生 #程序员 |
| 场景痛点 | 3-5 | #运维日常 #踩坑记录 |
| 宽泛流量 | 2-3 | #干货分享 #技术分享 |
| 热点（慎用） | 0-2 | 需与内容强相关 |

**标题**：≤30 字，含数字或痛点更佳。

### Step 6：输出完整包

输出到 `final.md`，格式：

```markdown
# 标题

## 元信息
- 时长：30 秒
- 形式：屏录 + 口播
- 受众：…

## 分镜脚本
（带时间轴的口播 + 画面 + 字幕）

## 发布描述
（标题 + 正文 + 标签）

## 剪辑备注
（BGM 风格、转场、封面帧建议）
```

## 与流水线的文件对应

| 本技能产出 | 流水线文件 |
|-----------|-----------|
| 分镜结构 | `outline.md` |
| 完整脚本包 | `final.md` |
| 发布用精简版 | 由流水线 Step 6 写入 `publish.md` |

## 质量检查

- [ ] 前 3 秒有明确钩子
- [ ] 全程有字幕文案
- [ ] 只有一个核心观点
- [ ] 标题 ≤30 字
- [ ] 无绝对化、虚假功效表述
- [ ] 9:16 竖版假设一致
