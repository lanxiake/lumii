# H3 生成结果迭代优化

## 工作流程

1. 用户描述问题现象（或提供视频截图/描述）
2. 根据问题诊断矩阵定位根因
3. 给出具体修改方案（提示词改哪里 / 工作流改哪个参数）
4. 制定 A/B 对比测试方案
5. 回到 `h3-workflow-designer` 执行优化后的版本

## 问题诊断矩阵

### 画面类问题

| 问题现象 | 根因 | 修改方案 |
|---------|------|---------|
| 主体脸变形/换脸 | 首段未明确锚定参考图外貌 | 在 [Shot 1] 首句加 `keeps her appearance, hairstyle, clothing from <Picture 1>` |
| 主体身体比例失真 | 参考图未锚定位置/姿态 | 加 `maintains her {座位/站位} and posture from <Picture 1>` |
| 场景频繁变换 | 场景描述缺少"全程一致"语句 | 在 Shot 段落末尾加一句：`The setting remains consistent throughout, no cuts` |
| 镜头抖动/剧烈晃动 | 未说明镜头状态 | 明确加 `camera holds steady with only a gentle natural handheld drift` |
| 人物出现多次/分裂 | Shot 标签错误或参考标签混用 | 检查所有 Shot 标签严格递增，参考标签唯一 |
| 动作僵硬/机械感 | 时间轴过细（每秒一段）或用指令式描述 | 改为3阶段流程化描述（开始→发展→结束），删精确秒数限制 |
| 一镜到底变成多镜头 | 误写了 [Shot 2] 硬切标签 | 删除所有 [Shot N>1]，改用承接语（`the motion continues naturally` 等） |
| 动作只有前几秒正确 | 末段缺少收尾锚定 | 末段补：收尾动作 + 表情定格 + 声音收束，明确"定格" |

### 音频类问题

| 问题现象 | 根因 | 修改方案 |
|---------|------|---------|
| 有背景音乐/配乐 | 音频声明靠后或用否定式 | 把 Audio 描述移到 `integrated_multimodal_description` **最前面**，用肯定式：`Female vocal humming a cappella, no instrumental accompaniment` |
| 出现对话/旁白声 | 提示词含心理活动描述 | 删除所有"内心感受/想起/回忆/想说"类描述 |
| 口型对不上歌词 | 歌词未保留原文/无声线描述 | 歌词用 `<d>[Chinese] 原文。</d>` 逐句保留 + 写声线描述（音色/清晰度） |
| 声音质量差/嘈杂 | soundscape 描述过于宽泛 | 精细化 `overall_soundscape`，明确指定每类声音的质量和比例 |

### 生成质量问题

| 问题现象 | 根因 | 修改方案 |
|---------|------|---------|
| 画面模糊/低清 | 当前模式 megapixels 太低 | 升级模式：快速验证(0.15) → 普通(0.6) → 高质量(0.9，≤10s) |
| 产品文字模糊/乱码 | 使用了 v1 pruned 模型 | 换用 v2 full INT8 模型（v1 剪枝版细节弱，不适合文字特写） |
| 皮肤/材质塑料感 | TE-Speed 开启了 | 关闭 TE-Speed（8步+INT8 场景实测失真），只保留 SageAttention |
| 重跑结果完全一样 | ComfyUI 结果缓存 | 换 `noise_seed`（换一个随机数），不能用同 seed 重跑 |
| 生成速度极慢（30min+） | SageAttention 未生效 | 检查 KJNodes 版本（需 2.x），确认控制台有 `sageattn` 输出 |

## A/B 对比测试流程

当不确定提示词修改是否有效时，做对比测试：

```
Step 1  保留原工作流（不修改原文件）
Step 2  另存修改后的工作流，命名加 "_v2" 区分
Step 3  使用相同 noise_seed、相同素材图
Step 4  两个版本都提交生成，等待完成
Step 5  对比两版本的5项验收指标：
         脸一致 / 动作对 / 口型对 / 情绪对 / 时长对
Step 6  选定优化有效的方向，继续迭代或升级模式出片
```

**关键**：对比测试阶段使用快速验证模式（megapixels=0.15），不要在普通/高质量模式做对比（成本太高）。

## 迭代优化策略

### 针对真人写实视频

1. **首帧锚定不足** → 最常见问题，先加强首段参考描述
2. **动作不自然** → 减少时间轴细分，改用流程描述
3. **音频混乱** → 音频声明前置 + 肯定式表述

### 针对产品/广告视频

1. **文字清晰度** → 必须用 v2 full 模型，不可用 v1 pruned
2. **产品变形** → 加具体产品形状/颜色/文字的精确描述
3. **镜头运动** → 明确声明 `slow, steady` 或 `static`

### 针对动画/卡通视频

1. **v1 pruned 固有细节损失** → 不是参数问题，是剪枝导致，降低对细节的预期或换 v2
2. **快节奏抽卡** → v1 配合快速验证模式，速度快（~120-180s/条）

## 优化后提交

修改完提示词/参数后，回到 `h3-workflow-designer` 的步骤3（参数展示确认环节）：
- 将修改点明确标注为"优化项"
- 使用相同素材 + 新 seed（或相同 seed 对比）
- 快速验证模式验证优化效果，通过后再升级模式
