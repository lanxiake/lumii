# H3 提示词编写与优化

## 工作流程

1. 确认输入模式：T2VA / I2VA / FL2VA / L2VA / Ref2VA
2. 基础模式读 `references/base-prompt-guide.md`，全参考模式读 `references/ref-prompt-guide.md`
3. 多类型示例参考 `references/prompt-examples.md`
4. 保持字段名、段落顺序、标签和时间标注与规范完全一致
5. 完成后向用户展示中文版 + 英文版，等待确认

## 输入模式说明

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| T2VA | 纯文本生成完整视听时间线 | 无素材，从零创作 |
| I2VA | 以首帧图片为起点向前延伸 | 有角色参考图 |
| FL2VA | 描述首帧到尾帧的连续路径 | 有首尾两张参考图 |
| L2VA | 推断开场并收敛到提供的尾帧 | 只有结尾图片 |
| Ref2VA | 全参考模式，严格保留参考内容 | 有多张参考图/视频/音频 |

## 基础模式三段式结构（T2VA/I2VA/FL2VA/L2VA）

```
integrated_multimodal_description:
  [Shot 1] 详述视觉/动作/镜头/对话——构图、主体、环境、动作、摄像机运动
  At 00:05.000 [Shot 2] ...（后续镜头用严格递增时间戳卡点）

overall_soundscape:
  1-4 句，概括全片环境音和动作音效（场景自然音、人声等）

non_diegetic_music:
  1-3 句，描述画外背景音乐（乐器/速度/节奏/动态变化）
```

**写作要求**：
- 英文写作，保留对白/歌词/可见文字的原始语言
- 每个 Shot 描述：构图 + 主体 + 环境 + 动作 + 摄像机 + 声音 + 参考内容出现时机
- 禁止情节总结、未解析的参考标签、与目标时长不符的时间标注

## 全参考模式（Ref2VA）六段式结构

```
subject_definitions    → 定义所有参考标签（人物/道具/场景）
summary                → 整体内容概述
retention_analysis     → 每个参考元素的保留分析
detailed_description   → 分 Shot 详细描述（与基础模式格式一致）
overall_soundscape     → 同上
non_diegetic_music     → 同上
```

参考标签在所有段落中保持一致，详见 `references/ref-prompt-guide.md`。

# 一镜到底专项（虚拟人物/短视频竖屏）

## 原则

- 以 **3 秒为基准**分段，允许按动作自然划分（如 2s+4s+3s+3s），总时长精确等于目标时长
- **禁止** `[Shot 2]` 硬切标签，改用连续承接语（见下方）
- **开始 3 秒**必须锚定首帧图，明确保持图片中的外貌/服装/位置/姿态
- **结束 3 秒**必须有收尾锚定：收尾动作 + 表情定格 + 声音收束
- 每段四要素：**动作 + 表情 + 声音/歌词 + 镜头状态**

## 时长-分段速查

| 目标时长 | 帧数（17n+5） | 分段建议 |
|---------|------------|---------|
| 5s | 121 | [0-2s]+[2-5s] |
| 10s | 245 | [0-2s]+[2-5s]+[5-8s]+[8-10s] |
| 15s | 362 | [0-3s]+[3-6s]+[6-9s]+[9-12s]+[12-15s] |

帧数公式：`max(5, round(秒×24)) + (5 - (max(5, round(秒×24)) % 17)) % 17`

## 常用承接语

- `the motion continues naturally`（动作自然延续）
- `the camera holds a static shot`（镜头保持固定）
- `she keeps swaying with the beat`（随节拍继续摆动）
- `her expression softens from X to Y`（表情从X过渡到Y）
- `the vocals carry over seamlessly`（声音无缝衔接）

## 画面比例铁律

| 场景 | 比例 | megapixels | 说明 |
|------|------|-----------|------|
| 竖版人物（自拍/短视频） | **2:3 Portrait** | 0.15/0.6 | 原图 1024×1536，禁止 9:16（会横向拉伸） |
| 横版通用 | 16:9 | 0.4-0.6 | 广告/风景/通用 |
| 方形 | 1:1 | 0.4 | 产品特写/社交媒体 |

## 提示词诊断速查

生成结果不符合预期时，根据问题类型找根因：

| 问题现象 | 根因 | 改法 |
|---------|------|------|
| 主体脸/身体变形 | 首段未锚定参考图外貌 | 首段加 `keeps her appearance/outfit from <Picture 1>` |
| 动作僵硬/机械感 | 时间轴过细（每秒一段）或有硬切 | 改为 3 段式流程化，用承接语 |
| 口型对不上歌词 | 歌词未用原文 + 无声线描述 | 加 `<d>[Chinese] 歌词原文。</d>` + 声线描述 |
| 背景音乐盖过人声 | 音频描述靠后/否定式 | 把 Audio 声明提到最前面，用肯定式 |
| 场景不一致/切换 | 环境描述不够明确 | 在结尾补一句环境全程一致的明确描述 |
| 人物说话/对话声 | 提示词含心理活动描述 | 删除所有"内心感受/想起/回忆"类描述 |

> 不满意时优先调用 `h3-quality-optimizer` 进行系统诊断。

## 输出规则

- 向用户展示：① 中文版（便于审核）② 英文版（实际使用）
- 包含三段式全部字段，不可简化
- 每次确认提示词后再进入工作流设计阶段
