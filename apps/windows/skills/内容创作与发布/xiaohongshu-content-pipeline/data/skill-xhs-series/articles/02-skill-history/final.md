# 🔥 半年内Anthropic、OpenAI、Google全冲了，Skill凭什么？

2025年下半年，"Skill"这个词突然在AI圈炸开。

你可能好奇：**Plugin存在这么多年、GPTs上线一年多，为什么"S教你"突然成了行业共识？**

先说结论：Plugin没死，GPTs也还活着。但Skill填补了它们都解决不了的那个大窟窿——"固定场景怎么做才能稳定交付"。

下面用真实时间线说清楚这件事。

## 📌 起点：2025年6月，Anthropic开源MCP

2025年6月，Anthropic开源了**MCP（Model Context Protocol）**——一个让AI模型安全调用外部工具的开放协议。

MCP的意义不在于"多有技术突破"，而在于它解决了一个务实问题：**之前每家的插件标准各自为战**，你给ChatGPT写的插件Gemini用不了，给Gemini写的集成Claude用不了。

MCP定义了一套统一的接口——你为Claude写好的工具集成，换成Gemini也能用（只要对方支持MCP）。

这是后续一切的基础：**先统一工具怎么被AI调用，才能谈怎么打包完整流程。**

## 🚀 爆炸扩散：2025年10月→12月→2026年1月

**2025年10月16日**——Anthropic发布 **Agent Skills**
这是"Skill"概念第一次被明确提出。核心创新点：
- 用**文件夹+SKILL.md文件**组织技能包
- 强调**渐进式加载**（metadata在系统prompt，正文按需读入）
- 支持内嵌代码脚本，AI可以按需执行
- 关键设计：**AI自己判断什么时候加载哪个Skill**

Anthropic工程师在博客里说了一句很实在的话：*"Building a skill for an agent is like putting together an onboarding guide for a new hire."*——给Agent写Skill，就像给新人写入职指南。

**2025年12月18日**——Anthropic将Agent Skills开源为开放标准，上线 [agentskills.io](https://agentskills.io/)，宣布跨平台可移植性。

**几乎同时，2025年12月**——BleepingComputer披露 OpenAI正在内部测试 **Skills（代号"hazelnuts/榛子"）**
- 以文件夹形式组织，包含指令、上下文、示例、可执行代码
- 可被AI自动识别、动态加载、组合调用
- 支持将现有GPT一键转换为Skill

**2026年1月前后**——OpenAI Skills预计上线

三巨头中的两家已经在半年内入局。

## 🔧 那Google呢？

2026年5月Google I/O上，Google发布了 **Gemini Spark**——一个能24小时运行在云上的个人AI助手，支持多步骤任务、跨应用协作，且已开放MCP协议接入第三方应用。

虽然没有直接叫"Google Skills"，但Spark的本质就是**基于MCP协议的技能执行引擎**——你告诉它"每天9点拉销售数据出报告"，它记住这个Skill并自动执行。

再加上Gemini 3.5 Flash专为Agent和编码场景优化，方向已经很明显：**Google也在做同样的事，只是名字不一样。**

**至此，半年内全球前三的AI公司全部指向同一个方向。**

## 🤔 所以Skill和插件到底区别在哪？

技术的角度可能有点枯燥，说个直观的对比。

| | **Plugin** | **GPTs** | **Skill** |
|--|-----------|---------|-----------|
| 本质 | 新能力（能搜索/算数） | 能力+预设prompt | 能力+流程+规则+代码 |
| 授权时机 | 你告诉AI用 | 你选中它 | **AI自己判断何时加载** |
| 输出稳定性 | 看AI心情 | 比你写好一点 | 固定流程，稳定输出 |
| 可分享性 | 平台绑定 | 可分享但不通用 | **跨平台标准** |
| 可组合性 | 单打独斗 | 简单组合 | 多个Skill可串联成工作流 |

**区别的核心就一句话：Plugin是你告诉AI"用什么"，Skill是AI自己知道"什么时候该用这个"。**

## 💡 普通人怎么判断：哪些场景值得写Skill？

三问框架：

**① 高频吗？** 你或团队每周至少做3次 → 回报大于投入
**② 固定吗？** 每次流程大差不差 → 稳定的流程才能稳定输出
**③ 有门槛吗？** 涉及多步操作、跨系统协作 → 纯文字搬运不配叫Skill

| 场景 | 高频？ | 固定？ | 有门槛？ | 结论 |
|------|--------|--------|---------|------|
| 周报生成 | ✅ | ✅ | ✅ | **写Skill** |
| 翻译一段文字 | ❌ | ✅ | ❌ | 直接问AI |
| 分析财报+生成PPT | ✅ | ✅ | ✅ | **必须写Skill** |
| 让AI查个天气 | ❌ | ❌ | ❌ | 别逗了 |

三条满足两条，大胆写。一条都不满足？prompt里加几个词就够了。
