# 第2篇配图方案（v2）

## 整体风格规范
- 所有图片：3:4竖版（宽768×高1024，实际使用1024×1536），手绘方格笔记本风格
- 背景：白底浅灰色方格线（5mm间距），1.5px圆珠笔灰线
- 文字：手写体（中文用偏楷体的手写风格），红/蓝/绿/黑四色马克笔
- 用色规范：标题=红色粗马克笔，正文=黑色细笔，强调=蓝色，对比=绿色
- 信息密度：每张图包含3-6个核心信息点

### 图4【Plugin vs Skill】一图看懂核心区别

**画面布局：** 左右两栏对比，中间用粗线隔开，上方标注"Plugin vs Skill"。

**左栏「Plugin」：**
- 背景色：浅灰色底
- 标题（灰色）："告诉AI用什么"
- 四个对比项（自上而下）：

| 维度 | Plugin |
|------|--------|
| 本质 | 新能力（能搜索/算数） |
| 调用方式 | 你告诉AI去用 |
| 输出稳定性 | 看AI心情（不稳定） |
| 可组合性 | 单打独斗 |

- 每一项写完后画一个小✗符号（灰色）

**右栏「Skill」：**
- 背景色：浅蓝色底
- 标题（蓝色加粗）："AI自己知道何时用"
- 四个对比项（与左栏对齐）：

| 维度 | Skill |
|------|-------|
| 本质 | 流程+规则+代码打包 |
| 调用方式 | AI自动识别加载 |
| 输出稳定性 | 固定流程，稳定输出 |
| 可组合性 | 多个Skill可串联 |

- 每一项写完后画一个小✓符号（绿色）

**底部横跨两栏：**
一句话总结（红色粗笔）：
"Plugin解决AI能不能做 → Skill解决怎么做才能稳定"

**视觉参考：** 左右对比表格，左边灰暗+叉，右边明亮+勾，视觉冲击力强。

### 图5【三问框架+判断表】（原第5张保留并升级）

**上半部分（三问框架）：**

第三段台阶旁标注（红色）：

每段台阶旁画一个小图标：①日历标记、②两个叠放方块、③三个齿轮串联。

**三阶之上**用红色大字标注："值得写"
**三阶之下**黑色小字："满足两条以上才值得"

**下半部分（判断表）：**

4×2缩略手绘表格：

| 场景 | 三问结果 | 结论 |
|------|---------|------|
| 周报生成 | ✅✅✅ | 写Skill（红色✦） |
| 翻译文字 | ❌✅❌ | 直接问 |
| 分析财报做PPT | ✅✅✅ | 必须写Skill（红色✦✦） |

**底行大字（红色粗笔）：**
