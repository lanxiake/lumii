# 第1篇配图方案（v2）

## 整体风格规范
- 所有图片：3:4竖版（宽768×高1024，实际使用1024×1536），手绘方格笔记本风格
- 背景：白底浅灰色方格线（5mm间距），1.5px圆珠笔灰线
- 文字：手写体（中文用偏楷体的手写风格），红/蓝/绿/黑四色马克笔
- 用色规范：标题=红色粗马克笔，正文=黑色细笔，强调=蓝色，对比=绿色
- 信息密度：每张图包含3-6个核心信息点，不空泛

---

### 图1【封面】三概念对比 + 结论标题

**画面布局：** 上半部分画三个竖列，分别标注"Plugin""Agent""Skill"。

**左栏（Plugin）：** 
- 画一个简笔眼睛图标（模仿"传感器"），下方画几个小插件方块，颜色灰色
- 标注文字（黑色细笔）："给AI装能力 / 不会主动干活"

**中栏（Agent）：**
- 画一个简笔大脑图标，带几条虚线箭头向外发散
- 标注文字（蓝色笔）："能自主规划 / 但每次都从头来"

**右栏（Skill）：**
- 画一个简笔工具箱图标，内部有齿轮和棒状物
- 标注文字（红色细笔）："流程+工具+规则打包 / 一键执行"
- 右栏底边画一条加粗下划线，突出"推荐"之意

**三列之间：** 用红色大大的"≠"符号连接，强调它们不是一回事。

**画面底部：** 留一行空间，用红色粗马克笔大字手写：
"Plugin ≠ Agent ≠ Skill 别搞混了！"
下面小字（黑色）："不是替代关系，是三个层次"

**视觉参考：** 类似学霸笔记本的对比笔记页，三栏并列，中间用斜线或箭头串联。

### 图2【极端对比】同一个需求，差20倍

**画面布局：** 左右两栏对比，中间用一条粗红色竖线分开，上方标注"同一个需求：把销售数据做成PPT邮件发给老板"

**左栏「没Skill」：**
- 画一条混乱的折线箭头（类似迷宫），经过6个节点：
  ① 你说需求 ② AI回复"好的" ③ 你手动导出Excel ④ 你粘贴给AI ⑤ AI回文字 ⑥ 你手动做PPT+发邮件
- 每个节点旁标注时间消耗（约5-8分钟）
- 终点位置画一个巨大的计时器，显示"40分钟"
- 计时器用红色圈出，旁边画一个愤怒/疲惫的小表情
- 箭头使用黑色细线，带有多个回折

**右栏「有Skill」：**
- 画一条平滑的粗蓝箭头（直线或微弧），经过4个节点：
  ① 你说需求 ② Skill自动拉数据库 ③ Skill生成PPT+填邮件 ④ 你点发送
- 每个节点旁标注时间消耗（约20-30秒）
- 终点位置画一个计时器，显示"2分钟"
- 计时器用绿色圈出，旁边画一个👍手势
- 箭头使用蓝色粗笔，笔直没有阻碍

**底部：** 一行大字（红色）："同一个需求，效率差20倍"

**视觉参考：** 左右对比时间线，一边乱成一团，一边笔直通畅。

### 图3【渐进式对比】Plugin → GPTs → Skill

**画面布局：** 左右没有对比，改成**左→中→右三阶段递进**，自下而上展示演化路径。

**左侧「Plugin / 初级阶段」：**
- 画一把简笔吉他
- 上方标注（黑色）："给你一把吉他 / 弹成啥样看你自己"
- 下面画一个小箭头，指向中间

**中间「GPTs / 中级阶段」：**
- 画一把吉他+一个调音器
- 上方标注（蓝色）："给你吉他+调音器 / 比纯兵器好点但有限"
- 下面画一个小箭头，指向右侧

**右侧「Skill」：**
- 画一把吉他+乐谱+手机（显示教学视频）+自动伴奏设备图标
- 上方标注（红色）："吉他+谱+视频+自动伴奏 / 照着练稳定输出"
- 吉他/乐谱/手机三个元素用虚线框圈在一起，标注"技能包"

**整个画面顶部：** 大字标题（红色粗笔）："Plugin → GPTs → Skill 的演进"
**整个画面底部：** 小字（蓝色）："解决的问题在变：能力→理解→流程"

**视觉参考：** 经典的"三级进化"排布，类似生物进化树或产品迭代图。

### 图4【判断三问+选择矩阵】判断&选择

**画面布局：** 上半部分画"三条黄金法则"，下半部分画"选择矩阵"，等分画面。

**上半部分（判断三问）：**

三个并排的气泡/卡片，每个包含一问：

卡片①「可复用？」（红色标题）：
- 图标：循环箭头
- 正文：这次用和下次用效果一致
- 底部真伪标签：真Skill ✓（绿色） | 假Skill → "开盲盒" ✗（红色）

卡片②「有边界？」（蓝色标题）：
- 图标：一个圈围住的区域
- 正文：知道自己的职责范围
- 底部真伪标签：真Skill ✓（绿色） | 假Skill → "范围太模糊" ✗（红色）

卡片③「可分享？」（红色标题）：
- 图标：分享/发送箭头
- 正文：别人装上直接能用
- 底部真伪标签：真Skill ✓（绿色） | 假Skill → "需要手写prompt" ✗（红色）

每个卡片用细线连接到底部一行大字：
**"满足两条以上才是真Skill"**

**下半部分（选择矩阵）：**

一个4行2列的表格（手绘风格，无网格线，用分隔线）：

| 你的场景 | 推荐 |
|---------|------|
| 偶尔查天气/算个数 | → Plugin（绿色标注"轻量"） |
| 自主完成复杂任务 | → Agent（蓝色标注"灵活"） |
| 固定场景每周3次+ | → **Skill**（红色加粗标注"最优解"） |
| 简单提问就够 | → 直接对话（灰色标注"别过度设计"） |

表格右侧画一把小箭头指向**Skill**格，标注"选它"（红色笔）。

**视觉参考：** 上半像"三条便签贴纸"，下半像"决策树末尾的推荐表"。
