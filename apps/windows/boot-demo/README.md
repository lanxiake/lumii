## 🎬 三幕剧结构

### 第一幕：初始化（0–2秒）
**视觉**：黑客入侵既视感
- HEX码矩阵雨密集下落（120个粒子）
- 网格透视背景逐渐显现
- 终端逐行输出日志
- 进度条缓慢上升到33%

**音效**：单一低频提示音（200Hz），表示系统启动

**节奏**：缓慢、神秘、进入状态

---

### 第二幕：加载（2–4.5秒）
**视觉**：能量汇聚与数据结构化
- 代码雨逐渐消退
- **24条能量线**从屏幕四周向中心汇聚，呈波动呼吸状
- **200个粒子**从分散逐渐聚合成中心圆形
- **毛刺特效**（RGB分离、扫描线、噪声）表示数据处理压力
- **扫过式高光条**贯穿屏幕（类似光学扫描）
- 进度条加速推进到67%

**音效**：四级上升音阶（220 → 280 → 350 → 440Hz）  
- 每130ms一个音符，表示加载进度
- 音量与进度条同步

**节奏**：加速、紧张、高能量

---

### 第三幕：就绪（4.5–6.5秒）
**视觉**：系统激活与完全就绪
- 中心核心**脉冲发光**，呼吸频率3Hz
- **五层脉冲环**展开，色相循环（洋红→青→琥珀）
- 每层独立衰减曲线，产生持续冲击感
- 中心耀斑**十字闪烁**（高频闪烁）
- 黑客终端显示 `[>>] Ready for commands`
- 进度条冲向100%
- Logo飞行动画（中心→左上角）

**音效**：胜利音效
- 先期：440Hz + 660Hz（双音和弦）
- 延迟100ms：880Hz + 1320Hz（高八度强化）
- 最后：1600Hz上升扫过（科幻传送音）

**节奏**：爆发、胜利、系统就绪

## 🔧 技术亮点

### 粒子系统优化
```javascript
// 粒子复用 → 无GC抖动
streamParticles.forEach(p => {
  p.x += (p.targetX - p.x) * easing * 0.08  // 缓动汇聚
})
```

### 能量线贝塞尔曲线
```javascript
// 不是直线，而是波动曲线 → 流体感
ctx.quadraticCurveTo(midX + sin(angle)*40, midY + cos(angle)*40, toX, toY)
```

### 毛刺处理（三层）
1. **水平条纹扰动** — 爆炸式数据崩溃
2. **RGB通道分离** — 复古故障美学
3. **竖直噪声** — CRT显示器效应

### Web Audio合成
- 无音频文件加载延迟
- 三种波形：sine（柔和）、square（刺激）、triangle（温暖）
- 动态增益包络：快速上升 → 指数衰减
