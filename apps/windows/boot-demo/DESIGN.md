# 灵栖开机引导动画 · 赛博启动设计

## 核心理念

放弃传统"宇宙学"叙事（奇点→大爆炸→银河），转向**系统内核启动的赛博朋克视觉语言**：

1. **矩阵代码雨** — 初始化时的数据流入
2. **能量汇聚** — 加载时的结构涌现（粒子聚合）
3. **脉冲激活** — 就绪时的系统脉冲

## 视觉分层

### 第一幕：初始化（0–2s）
- 代码矩阵雨下落（HEX码，密集流动）
- 网格透视背景逐渐清晰
- 黑客终端逐行输出日志
- 进度条 0% → 33%

**音效**：单一低频 200Hz 音调（启动引导）

### 第二幕：加载（2–4.5s）
- 代码雨逐渐消退
- 能量线从屏幕边缘向中心汇聚（24条，波动呼吸）
- 粒子聚合成中心几何形状（200个粒子）
- 毛刺故障特效（RGB分离、扫描线扰动）
- 扫过式高光条贯穿屏幕（电影感）
- 进度条 33% → 67%

**音效**：四声上升音阶（加载进度）

### 第三幕：就绪（4.5–6.5s）
- 中心核心脉冲发光（呼吸感）
- 五层脉冲环展开（洋红→青→琥珀，交错发射）
- 耀斑十字闪烁
- 终端显示 "SYSTEM ONLINE"
- 进度条 67% → 100%
- Logo从中心飞向左上角（Logo区域）

**音效**：双频完成音（440Hz + 660Hz + 1200Hz）

## 技术栈

- **渲染**：Canvas2D，无3D库依赖
- **音效**：Web Audio API（合成，无音频文件）
- **帧循环**：requestAnimationFrame，dt积分
- **时序**：全局 `elapsed` 累加，各特效独立强度控制 0–1

## 粒子系统

| 系统 | 数量 | 角色 |
|-----|------|------|
| 代码雨 | 120 | 初始化视觉反馈 |
| 能量线 | 24 | 汇聚动画 |
| 聚合粒子 | 200 | 结构形成 |
| 脉冲环 | 30 | 就绪脉冲 |

## 阶段时序

```
init:   0.0s → 2.0s   (initStr:  0 → 1.0)
load:   2.0s → 4.5s   (loadStr:  0 → 1.0)
ready:  4.5s → 6.5s   (readyStr: 0 → 1.0)
end:    6.5s → 淡出
```

## 控制界面

- **播放**：开始完整序列（带音效）
- **重置**：回到初始化状态
- **声音**：toggle音效
- **冻结**：选择特定阶段进行调试

## 特效细节

### 毛刺（Glitch）
- 水平条纹扰动（爆炸感）
- RGB分离（复古视效）
- 竖直白线噪声

### 能量线
- 波动频率 2–3 Hz
- 贝塞尔曲线连接（不是直线）
- 末端高光点

### 脉冲环
- 5层，不同衰减率
- 色相循环：洋红 → 青 → 琥珀
- 频率递进（底层慢，上层快）

### 扫描线
- 全屏8像素周期动画
- 半透明覆盖（仿真CRT显示器）

## 性能优化

- 粒子复用，无 GC 抖动
- Canvas 分层渲染（background清除一次）
- 条件检查 `if (strength < 0.01) return` 早期退出
- dt限制 `Math.min(0.05, ...)` 防止帧率下降时时间跳跃

## 集成路径

将此DEMO集成到主应用的启动流程：

1. **替换 `SplashOverlay.tsx`** 中的视频播放逻辑
2. **连接 `startup:progress` 事件** 到 `BootVisual.progress()` 回调
3. **音效由真实启动声音替代** （可选保留或使用系统声音）
4. **阶段推进** 由真实启动阶段 (S0–S8) 驱动，而非时间
5. **Logo飞行** 与右上角Sidebar品牌位对齐

## 已知限制

- 粒子数量固定，未根据分辨率动态调整（可优化）
- 音效为合成，未与真实应用启动音同步
- 无物理碰撞或约束（简化设计）
