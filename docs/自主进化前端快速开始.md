# 自主进化 Agent 前端可视化 - 快速开始

## 概述

本指南帮助你快速启动自主进化 Agent 的前端可视化功能，包括离线审批、仪表板展示和用户交互。

## 前置条件

- Node.js 18+
- 已完成基础的 Agent Runtime 配置
- 数据库已初始化

## 安装步骤

### 1. 验证数据库 Schema

运行应用时，数据库会自动迁移到 V31，添加以下表：

- `autonomous_approvals` - 审批队列
- `autonomous_approval_settings` - 用户审批设置

你可以通过以下 SQL 验证：

```sql
SELECT name FROM sqlite_master WHERE type='table' AND name LIKE 'autonomous%';
```

预期输出：
- autonomous_goals
- autonomous_satisfaction_scores
- autonomous_approvals
- autonomous_approval_settings
- ... 等其他自主进化相关表

### 2. 配置环境变量

在 `.env` 文件中添加（可选，使用默认值）：

```bash
# 是否启用自主进化
AUTONOMOUS_ENABLED=true

# 是否自动批准 L0 内部目标
AUTONOMOUS_AUTO_APPROVE_INTERNAL=true

# 自动批准每日上限
AUTONOMOUS_AUTO_APPROVE_DAILY_CAP=5
```

### 3. 注册 IPC 处理器

在 `apps/windows/src/main/ipc/ipc-handlers-registry.ts` 中：

```typescript
import {
  setAutonomousIpcDeps,
  registerAutonomousIpcHandlers
} from './autonomous-ipc'

export interface IpcHandlersDeps {
  // ... 现有依赖
  getAutonomousCoordinator: () => AutonomousCoordinator | null
}

export function registerAllIpcHandlers(deps: IpcHandlersDeps): void {
  // ... 现有注册

  // 注册自主进化 IPC
  setAutonomousIpcDeps({
    getCoordinator: deps.getAutonomousCoordinator,
  })
  registerAutonomousIpcHandlers()
}
```

### 4. 导出 Preload API

在 `apps/windows/src/preload/index.ts` 中：

```typescript
import { autonomousApi } from './api/autonomous-api'

// 导出到 window 对象
contextBridge.exposeInMainWorld('autonomousApi', autonomousApi)
```

在 TypeScript 声明文件中添加类型（如 `window.d.ts`）：

```typescript
declare global {
  interface Window {
    autonomousApi: typeof import('./preload/api/autonomous-api').autonomousApi
  }
}
```

### 6. 添加导航入口

在主导航菜单中添加入口：

```tsx
import { useEffect, useState } from 'react'

function Navigation() {
  const [pendingCount, setPendingCount] = useState(0)

  useEffect(() => {
    // 定期查询待审批数量
    const interval = setInterval(async () => {
      const status = await window.autonomousApi.getStatus()
      setPendingCount(status.pendingGoalsCount)
    }, 30000)

    return () => clearInterval(interval)
  }, [])

  return (
    <nav>
      {/* ... 其他导航项 */}
      <a href="/autonomous">
        <span>🧠 自主进化</span>
        {pendingCount > 0 && (
          <span className="badge">{pendingCount}</span>
        )}
      </a>
    </nav>
  )
}
```

### 7. 集成审批流程到 Coordinator

在 `packages/agent-runtime/src/autonomous/autonomous-coordinator.ts` 中：

```typescript
import { ApprovalQueue } from './approval-queue'
import { ApprovalDeliveryService } from './approval-delivery'
import { ApprovalTimeoutScanner } from './approval-timeout-scanner'
import { ApprovalDbAdapter } from './approval-db-adapter'
import { classifyGoalRisk } from './goal-risk-classifier'
import { shouldAutoApprove } from './auto-approval-policy'

export class AutonomousCoordinator extends EventEmitter {
  private approvalQueue!: ApprovalQueue
  private deliveryService!: ApprovalDeliveryService
  private timeoutScanner!: ApprovalTimeoutScanner

  async initialize(): Promise<void> {
    // ... 现有初始化代码

    // 初始化审批系统
    const approvalDb = new ApprovalDbAdapter(this.db)
    this.approvalQueue = new ApprovalQueue(approvalDb)
    
    this.deliveryService = new ApprovalDeliveryService(
      this.channelRouter, // 需要注入
      this.settingsProvider // 需要注入
    )

    this.timeoutScanner = new ApprovalTimeoutScanner(
      this.approvalQueue,
      this.goalRepo, // 需要实现
      15 * 60 * 1000
    )

    this.timeoutScanner.start()

    // 注册目标生成事件监听
    this.on('goal:generated', this.onGoalGeneratedWithApproval.bind(this))
  }

  async shutdown(): Promise<void> {
    this.timeoutScanner?.stop()
    // ... 现有关闭代码
  }

  /**
   * 处理目标生成（带审批）
   */
  private async onGoalGeneratedWithApproval(goal: AutonomousGoal): Promise<void> {
    const classification = classifyGoalRisk(goal)
    const autoApproval = await shouldAutoApprove(goal, this.approvalQueue.db)

    if (autoApproval.shouldAutoApprove) {
      // 自动批准
      const approval = await this.approvalQueue.createApproval(goal, classification.level)
      await this.approvalQueue.applyAutoPolicy(approval.id, autoApproval.reason)
      await this.approveGoalInternal(goal.id)
    } else {
      // 创建审批请求并推送
      const approval = await this.approvalQueue.createApproval(goal, classification.level)
      const result = await this.deliveryService.deliver(approval, goal, this.userId)
      
      if (result.ok && result.target) {
        await this.approvalQueue.markDelivered(
          approval.id,
          result.target.channel,
          result.target.peerId
        )
      } else {
        await this.approvalQueue.markUnreachable(approval.id, result.errorCode!)
      }
    }
  }

  /**
   * 批准目标
   */
  async approveGoal(goalId: string, options?: { note?: string }): Promise<AutonomousGoal> {
    // 记录审批决策
    const history = await this.approvalQueue.db.getApprovalHistory(goalId)
    const pending = history.find((a) => a.status === 'pending')
    
    if (pending) {
      await this.approvalQueue.applyUserDecision(pending.id, 'approved', options?.note)
    }

    // 执行批准
    return this.approveGoalInternal(goalId)
  }

  /**
   * 拒绝目标
   */
  async rejectGoal(
    goalId: string,
    options?: { reason?: string; neverAskAgain?: boolean }
  ): Promise<void> {
    // 记录审批决策
    const history = await this.approvalQueue.db.getApprovalHistory(goalId)
    const pending = history.find((a) => a.status === 'pending')
    
    if (pending) {
      await this.approvalQueue.applyUserDecision(pending.id, 'rejected', options?.reason)
    }

    // 更新目标状态
    await this.rejectGoalInternal(goalId)
  }
}
```

## 常见问题

### Q1: 页面显示"无法加载自主进化数据"

**原因**: IPC 处理器未正确注册或 Coordinator 未初始化。

**解决**:
1. 检查 `ipc-handlers-registry.ts` 中是否调用了 `registerAutonomousIpcHandlers()`
2. 检查 `deps.getAutonomousCoordinator()` 是否返回有效实例
3. 查看主进程日志是否有错误

### Q2: 自动批准不生效

**原因**: 环境变量未设置或目标类型不符合自动批准条件。

**解决**:
1. 检查 `.env` 中 `AUTONOMOUS_AUTO_APPROVE_INTERNAL=true`
2. 确认目标类型是 `learning`、`capability-improvement` 或 `memory-optimization`
3. 检查是否达到每日上限（默认 5 个）

### Q3: 渠道推送失败

**原因**: 渠道未连接或用户未配置审批设置。

**解决**:
1. 确保飞书/微信/企微已登录并连接
2. 检查用户审批设置中配置了正确的渠道
3. 查看 `delivery_status` 字段，如果是 `unreachable`，检查渠道连接

### Q4: 超时策略未触发

**原因**: 超时扫描器未启动或扫描间隔太长。

**解决**:
1. 确认 `timeoutScanner.start()` 已调用
2. 检查 `expires_at` 是否正确设置
3. 可以缩短扫描间隔用于测试（如 1 分钟）
