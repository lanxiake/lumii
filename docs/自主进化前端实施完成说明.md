## 🚀 如何使用

### 1. 数据库迁移

系统会自动执行 schema 迁移，将 `autonomous_approvals` 和 `autonomous_approval_settings` 表添加到数据库中。

### 2. 启用自主进化

确保配置文件中已启用自主进化：

```typescript
// packages/agent-runtime/src/autonomous/config.ts
export const AUTONOMOUS_CONFIG = {
  enabled: true,
  // ...
}
```

### 3. 配置审批设置

用户可以通过前端页面配置审批设置：

- **审批渠道**: local（仅本地）/ feishu / weixin / wecom / off
- **自动批准内部目标**: 是否自动批准 L0 内部目标
- **免打扰时段**: 设置不推送审批的时间段

### 4. 访问仪表板

在应用中导航到自主进化仪表板页面，可以看到：

- 📊 满意度评分和趋势
- 🎯 待审批目标列表
- 批准/拒绝操作按钮

### 5. 渠道审批（离线审批）

当配置了外部渠道（飞书/微信/企微）后：

1. Agent 生成目标后自动推送审批请求到配置的渠道
2. 用户在渠道中回复 `1`（同意）、`2`（拒绝）或 `3`（以后同类自动同意）
3. 系统自动回填决策并执行
4. 超时未回复时按类型应用默认策略

### 6. 集成渠道送达

在目标生成后自动创建审批并推送：

```typescript
async function handleGoalGenerated(goal: AutonomousGoal) {
  // 风险分级
  const classification = classifyGoalRisk(goal)
  
  // 判断是否自动批准
  const autoApproval = await shouldAutoApprove(goal, db)
  
  if (autoApproval.shouldAutoApprove) {
    // 自动批准
    await approveGoal(goal.id)
    await recordDecision(goal.id, 'approved', 'auto-policy', autoApproval.reason)
  } else {
    // 创建审批请求
    const approval = await approvalQueue.createApproval(goal, classification.level)
    
    // 尝试推送到渠道
    const result = await deliveryService.deliver(approval, goal, userId)
    
    if (result.ok) {
      await approvalQueue.markDelivered(approval.id, result.target!.channel, result.target!.peerId)
    } else {
      await approvalQueue.markUnreachable(approval.id, result.errorCode!)
    }
  }
}
```
