# source: 官方
# title: 青云地铁集团开通满月新闻通气会实录（节选）

问：有媒体报道12号线"客流缺口超四成"，集团如何回应？

周总经理：第一个月票款收入2413万元；9月11日单日客运量达68.9万人次，为开通以来最高。需要说明统计口径：对外发布的日均客运量51.2万人次包含站内换乘，换乘量约占25%；若按不含换乘的进站量口径，日均进站量为38.4万人次。用进站量去对比工可预测，两个口径不能直接相减。

客流占全市公共交通出行量的12.6%（智慧出行大数据口径）。早高峰行车间隔6分钟，平峰8分钟，后续将根据客流图逐步压缩。西郊段一期因征地问题尚未开工，预计2027年开通。
