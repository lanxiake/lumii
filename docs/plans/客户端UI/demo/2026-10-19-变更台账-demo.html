提案规则：只留本会话

  1. 写文件工具直接登记（file_write / edit / move …）。
  2. bash / 脚本产物：路径必须在本轮命令文本或工具输出里出现（或落在命令点名的目录下），才计入。
  3. 同一 workspace 的其他会话、后台进程改动一律不进入卡片与台账。
  4. 归属记录仍是「本轮」粒度，不影响历史消息里已落盘的 fileChanges。

与现状的差别

现状（切到「现状」查看）：diff 里没人认领的路径会作为「未归属」并入本轮卡片， 于是别的会话改的宠物素材也出现了。

提案：这类路径直接排除；本会话 bash 明确写到的文件仍保留， 并标出来源（bash · 命令中出现）。

可讨论的点

1. 诊断入口是否保留：面板底部默认收起的「已排除 N 个非本会话改动」。

2. bash 动态批量产物（路径没出现在命令里）是否接受“不计入”，还是给一个目录级兜底。

3. 逐轮卡片与右侧台账都采用同一套过滤结果。
