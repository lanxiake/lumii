# Experimental Features UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将设置→实验功能改为列表入口 + 栈式详情子页，并修复提示词风格/自主进化嵌入布局。

**Architecture:** `ExperimentalSection` 用本地 `ExperimentalView` 在 `list | promptStyle | autonomous` 间切换；列表无开关；`PromptStyleDetail` 只管风格切换；`AutonomousPage embedded` 单列布局修复。

**Tech Stack:** React, CSS Modules, Vitest, Testing Library, 现有 settings/autonomous 服务

**Spec:** `docs/design/客户端UI/2026-09-13-实验功能页UI重设计.md`

## Global Constraints

- 不改 IPC / 存储 / 自主进化业务语义
- 去掉提示词段表；保留 detailed/terse 切换
- 自主进化保留 7 Tab
- 设置内栈式子页，不加全局 Router
