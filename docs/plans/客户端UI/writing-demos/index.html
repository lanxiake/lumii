创作型工作的前端方案

面向写小说、写公众号、做短视频的用户：把「大量文件的阅读、修改、对比、引用、整理」做成一套可复用的工作台原语，再按场景组装。每个方案都是可交互的静态页，直接点开对比。

01 推荐底座

通用创作工作台

扩展现有 ChatPage 工作台，增加「聊天 / 写作」双模式：左边文件、中间文档、右边对话。写作模式复用同一套聊天与工具卡片，不另起一个 App。

03 公众号

公众号编辑器

标题候选、手机端实时预览、发布前检查、素材图与引用来源并列。把「写」和「发」之间的返工压到一次完成。

04 短视频

短视频分镜台

分镜卡 + 脚本 + 素材网格 + 9:16 预览 + 字幕检查。让脚本、画面、时长、字幕在同一个界面里对齐，而不是散在四个工具中。

06 引用

三种引用模型

同一个案例切换三种深度：轻量稳定引用、块级 transclusion、文件级引用。用来决定第一版做到哪一层，以及失效时怎么回退。
