# Backlog：同步长工具过程可见性 + 媒体预览统一

> 承接 Phase 1.1 后台任务卡体验补丁之后的下一迭代项。  
> **状态（2026-10-24）**：P0 两项已落地（ToolCallCard 运行中摘要/已用/中断 + Markdown/工具图统一 ImageLightbox；成片仍 FilePreview）。

## 背景

Phase 1 / 1.1 已覆盖走 `backgroundTools` detach 的后台 MCP（含 ComfyUI）的进度、日志、里程碑、健康态与折叠态媒体预览。  
**同步 ToolCallCard**（bash / 浏览器 / 大文件读写等）与 **回合内媒体结果** 仍是另一条路。

## 范围（建议）

### P0 下一迭代

1. **长耗时同步工具的过程可见性**  
   在 ToolCallCard 运行中行增加与后台卡同源的轻量信息：运行中摘要、已用时、可中断。  
   不必整卡搬迁到 BackgroundTaskCard。

2. **回合内媒体结果统一预览**  
   收口 `image_generate`、截图、录屏成片、聊天 Markdown 图与后台卡缩略图：  
   点图即 Lightbox / 点成片即 FilePreview，避免两套交互。

### 明确不做（本 backlog）

- 给所有同步工具强行上里程碑（无真实阶段信号时会成假进度）
- 完整 CardRegistry / 插件市场
