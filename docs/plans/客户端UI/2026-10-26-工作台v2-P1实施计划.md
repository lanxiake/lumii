## 一、目标与验收

### 1.1 一句话目标

P0 让产物「看得见、不淹没」；P1 让产物「有身份（契约/缩略图/版本）、拿得走（多选/导出/对比）、不用管磁盘（自动清理）」。

### 2.3 AG-UI 对齐（事件 → 状态 → 卡片）

P1 **不引入 `@ag-ui/*` 依赖、不新增 SSE 端点**，但工作台的状态模型按 AG-UI 的
「事件流 + 共享状态（snapshot/delta）+ interrupt/resume」来设计——这样卡片是状态的视图，
而不是渲染层从工具名/文件快照里各自猜；将来要接 AG-UI 传输时不用重写 UI。

| Lumii 现有信号 | AG-UI 家族 | 工作台怎么用 |
|---|---|---|
| `agent:start/end/error`、`isStreaming` | `RUN_STARTED/FINISHED/ERROR`、`STEP_*` | 任务组状态（running/done/failed） |
| `agent:tool:start/progress/end` | `TOOL_CALL_START/ARGS/END/RESULT` | 工具卡与 running 占位卡；`RESULT` 里的 `details.artifacts` |
| 切会话加载的 `parts + fileChanges` | `STATE_SNAPSHOT` / `MESSAGES_SNAPSHOT` | 历史卡片的 ready/failed/cancelled 全量重建 |
| 运行中的声明/缩略图就绪/文件写入 | `STATE_DELTA`（RFC 6902 的本地子集） | 卡片局部更新，不重算整本台账 |
| `agent:background-task` / `outputs` | `ACTIVITY_SNAPSHOT/DELTA` | 后台任务卡、视频产出 |
| `permission:request` / `ask_user` | `INTERRUPT` + `resume` | 「等你拍板」卡；用户动作 = resolved/cancelled 的本地映射 |
| 缩略图/版本等派生结果 | `CUSTOM` | 只更新对应卡片，不进消息正文 |

**四条硬规则**

1. **Agent 权威、UI 本地**：产物/任务/中断是 agent 状态；选中、筛选、宽度、跟随是本地 UI 状态，两者不混写。
2. **snapshot + delta**：会话加载是一次 snapshot；运行中只发 delta。禁止每帧重算全会话台账（P0 的遗留 L11 在这里一并解决）。
3. **卡片即状态视图**：每张卡必须有显式生命周期（见 §4.5），渲染层不再按 `lname === 'image_generate'` 这类嗅探决定长相与动作。
4. **人机回路是卡片交互**：审批/提问卡是 interrupt；按钮产生 resume（allow/deny/answer），过期/取消是显式状态，不是「卡突然消失」。

### 2.4 明确缺口（本阶段要新建）

1. 契约类型与产出方声明；台账消费 `parts`。
2. 侧车元数据读写（PPT/第三方技能）。
3. 缩略图服务（视频首帧、大图压缩、PPT 页数）+ 磁盘缓存 + IPC。
4. 全量版本查询（当前只覆盖已加载的 60 条消息）。
5. 消息定位/高亮（无现成接口）。
6. 多选区间选择、批量导出/复制、对比视图。
7. 结果动作条（文档选区动作随 P2）。
8. 通知类型策略、主进程可见设置、未查看角标、跟随、自上次查看。
9. 跨会话「全部」列表（可复用 `files:list`，但需映射与限制说明）。
10. 自动清理的 TTL/配额/回收站到期/设置页/审计读取/会话删除联动。

## 四、目标类型与契约

### 4.1 产物声明（agent-runtime 类型 → renderer 复用）

```ts
// packages/agent-runtime/src/types/artifact.ts（新增；browser.ts 导出）
export type ArtifactKind =
  | 'image' | 'image-set' | 'video' | 'audio' | 'doc' | 'slides'
  | 'sheet' | 'site' | 'code' | 'archive' | 'other'

export interface ArtifactMeta {
  width?: number
  height?: number
  durationSec?: number
  pages?: number
  words?: number
  bytes?: number
  model?: string
  prompt?: string
  params?: Record<string, string | number | boolean>
}

export interface ArtifactDeclaration {
  kind: ArtifactKind
  /** 工作区相对路径（posix）；远端产物用 remoteUrl，二选一 */
  path?: string
  /** 远端产物（ComfyUI 等）：仅用于展示，不参与打开/清理 */
  remoteUrl?: string
  role?: 'deliverable' | 'intermediate'
  title?: string
  cover?: string
  meta?: ArtifactMeta
}

export interface ToolResultDetails {
  artifacts?: ArtifactDeclaration[]
  [key: string]: unknown
}
```

生产方示意（`bridge-tool-registrar-integration.ts`）：

```ts
details: {
  ...result,
  artifacts: [{
    kind: 'image',
    path: result.filePath,
    role: 'deliverable',
    meta: { width: result.width, height: result.height, model: result.model, prompt: result.revisedPrompt },
  }],
}
```

### 4.2 声明解析（唯一纯函数）

```ts
// apps/windows/src/shared/artifact-declaration.ts（新增）
export function readDeclarations(result: unknown): ArtifactDeclaration[]
export function declarationToArtifact(
  declaration: ArtifactDeclaration,
  fallback: { turnId: string; timestamp: number; sourceTool?: string },
): Artifact | null   // 校验 path 为相对路径、无 ..、kind 合法
```

规则：
- `result?.details?.artifacts` 必须是数组，最多取 50 条；
- 无合法 `path` 且无 `remoteUrl` → 丢弃（不报错）；
- `path` 含 `..`、绝对路径、反斜杠 → 归一化后拒绝；
- 声明与 `fileChanges` 同路径时，**声明覆盖 kind/role/meta**，状态仍取 `fileChanges`。

### 4.4 缩略图契约

```ts
// shared/artifact-thumbs-types.ts（新增）
export interface ArtifactThumbResult {
  ok: boolean
  /** lumii-local://media/?path=...（缓存文件） */
  url?: string
  meta?: { width?: number; height?: number; durationSec?: number; pages?: number }
  error?: string
  fromCache?: boolean
}

// preload: window.electronAPI.artifact.thumb(relativePath) / readMeta(paths) /
//          export({paths, mode:'zip'|'copy'})
// 版本历史走既有 agent-runtime 命令通道：
//   sendCommand({ type: 'artifact:history', sessionKey, path })
//   （与 conversation:messages 同层，能拿到 bridge.conversationRepo；不新开 raw IPC）
```

主进程：
- 缓存目录 `<dataRoot>/cache/thumbs/`；
- key = `sha1(workspaceDir + relPath + mtimeMs + size)`；
- 图片：`sharp().resize(256, 256, { fit: 'inside' }).webp({ quality: 78 })`；
- 视频：`runFfmpeg(['-ss','0.5','-i',src,'-frames:v','1','-vf','scale=256:-2',out])`，失败返回 `ok:false`；
- PPT：jszip 读 `ppt/slides/slide*.xml` 计数（无缩略图）；
- 并发 2，同 key 复用飞行中的 Promise；
- 缓存 LRU：启动时/每日清理按 mtime 删到 ≤500MB。

### 4.5 卡片状态机（AG-UI 状态视图）

```ts
// apps/windows/src/shared/card-state.ts（新增）
export type CardLifecycle =
  | 'running'      // TOOL_CALL_START 之后、END 之前（占位卡）
  | 'waiting_input'// INTERRUPT：等审批/等回答
  | 'ready'        // 有路径/有声明，可打开
  | 'failed'       // tool 失败或产物缺失
  | 'cancelled'    // interrupted / 用户取消

export interface ArtifactCardState {
  /** 稳定 id：ready 用 path；占位用 `tool:<toolCallId>` */
  id: string
  toolCallId?: string
  turnId: string
  timestamp: number
  kind: ArtifactKind
  lifecycle: CardLifecycle
  /** ready 时才有 */
  path?: string
  title?: string
  meta?: ArtifactMeta
  /** running 占位：从工具参数里拿到的可展示信息（不承诺文件存在） */
  placeholder?: { prompt?: string; fileName?: string }
  /** failed 时的用户可读原因；重试只预填 prompt，不自动发 */
  error?: string
  retry?: { toolName: string; prompt?: string }
}

export interface TaskGroupState {
  key: string
  label: string
  status: 'running' | 'waiting_input' | 'done' | 'failed'
  startedAt: number
  cards: ArtifactCardState[]
}

export interface InterruptState {
  id: string
  kind: 'permission' | 'ask_user'
  sessionKey: string
  status: 'open' | 'resolved' | 'cancelled' | 'expired'
  /** 交给卡片渲染的最小字段 */
  title: string
  detail?: string
  /** 用户动作 → 现有 IPC（allow-once/allow-always/deny 或 answer） */
  resume: 'allow-once' | 'allow-always' | 'deny' | 'answer'
}
```

**snapshot 构建**（纯函数，切会话/回放）：

```ts
export function buildWorkbenchSnapshot(input: {
  messages: readonly LedgerMessageLike[]
  interrupts: readonly InterruptState[]
  now: number
}): { tasks: TaskGroupState[]; cards: ArtifactCardState[] }
```

- 每个 tool part → 一张卡：`status='running'` → running；`done` 且有声明/路径 → ready；`error` → failed；`interrupted` → cancelled；
- 声明/`fileChanges` 提供 path/meta；两者都没有但工具有声明的 `placeholder` 信息 → 仍给 running 占位（运行中）或 failed（已结束且无产物）；
- 历史里失败的工具卡保留（可重试），不因「没有文件」被吞掉。

**delta**（运行中）：新 tool part/声明/缩略图就绪只更新对应卡（`upsertCard`），不重算整本台账。
P1 用「按消息增量缓存」实现，接口形状与 AG-UI `STATE_DELTA` 对齐。

**动作 = 状态函数**：

| lifecycle | 一级动作 |
|---|---|
| running | 中断（复用 `handleAbort`）/ 查看进度 |
| waiting_input | 允许一次 / 总是允许 / 拒绝（权限）；回答（提问） |
| ready | 打开 / 导出 / 定位 / 对比 / ⋯ |
| failed | 重试（预填原 prompt，进 composer）/ 查看错误 |
| cancelled | 重试（同上）/ 移入回收站（有 path 时） |

## 八、风险与回滚

| 风险 | 概率 | 缓解 | 回滚 |
|---|---|---|---|
| 缩略图生成拖慢列表 | 中 | 懒加载 + 并发 2 + 缓存 + 失败降级 | 关闭请求即回 P0 占位 |
| ffmpeg 在部分机器失败 | 低 | 失败返回 `ok:false`；卡片显示图标 | 无需回滚 |
| 侧车被第三方技能写坏/过多 | 低 | 只在声明产物上读取；≤64KB；坏 JSON 静默 | 停止读取侧车 |
| 占位卡与真实产物重复/闪烁 | 中 | 占位卡只来自「最后一条 assistant 里仍在 running 的工具」，工具结束即消失；ready 卡按 path 去重；结束仍无产物 → failed，不静默消失 | 关闭占位卡，只显示 ready |
| 运行中每帧重算状态 | 中 | 按消息对象 WeakMap 缓存；流式只重算最后一条 | 回退到 1s 节流 |
| 全量版本 SQL 变慢 | 中 | 只按 conversationId + LIKE；30s 缓存；分页上限 | 回退到已加载 `ledger.versions` |
| 定位翻页循环 | 中 | 最多 20 次/10s + 超时兜底 | 隐藏「定位」入口 |
| 通知打扰 | 中 | 默认仅等拍板 + 聚焦抑制 + 免打扰 + 去重 | 策略设 off |
| 自动清理误删 | 低 | 成品不动 + TTL + 引用跳过 + trash 7 天 + 可关 + 审计 | 关闭 `enabled` 并恢复 trash |
| 配额清理过激 | 低 | 只清 intermediate/ephemeral；目标 80%；最老优先 | 调阈值/关闭 |
| 多选导出内存峰值 | 中 | 单次 ≤500MB；大文件提示分批；zip 流式生成 | 禁用批量导出 |
| 会话删除联动误删 | 低 | 默认不勾；二次确认；只移到 trash | 恢复 trash |
