## 维护须知

- 新增领域子目录时，在本文件「领域子目录」表中登记一行，并在该子目录内建 `README.md`；同时确认 [`../design/`](../design/) 侧有同名目录。
- 计划文档完成后，在文首更新状态行（已完成 / 部分完成 / 已结案），便于后来者判断是否还需要读。
- 已被取代的早期草稿应删除并在新文档中注明「本计划已并入/取代 XXX」，不要留下两份内容重叠的计划。
