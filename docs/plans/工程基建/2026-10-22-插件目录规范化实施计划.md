## 0. 问题与目标

现状：插件代码分三处——`src/main/extensions/*.ts`（接线）、`src/main/<impl>/`（实现）、
`src/main/plugin-*.ts`（宿主与管理）。同时 `src/main/plugins/` 被另一套「运行时依赖安装」
（CloakBrowser 等）占用，**同词不同义**。

实测的耦合度（核心直接 import 插件实现）：

| 插件 | 被核心直接 import 的次数 |
|---|---|
| pet | 19 |
| perf | 13 |
| voice | 9 |
| workspace-vcs | 9 |
| screen-record | 7 |
| channel | 20+ 个文件 |

结论：**搬家本身不会解开耦合**，但能让边界看得见、让删除有确定落点。

目标：

1. 一份代码只在一个地方：`plugins/builtin/<id>/` 同时放清单、接线、实现、测试。
2. 新增/删除插件只动一处清单（`plugins/registry.ts`，一个插件一行，`hot` 标记派生运行期启停）。
3. 搬完补一条守卫，防止实现再散回顶层。

非目标：

- 不做沙箱与权限（沿用决策记录 D1/D2）。
- 不改 `channel/` 的位置：它是四个 channel-* 插件**共享**的子系统，被 agent-runtime 直接使用，
  塞进某个插件目录只会制造假边界。在 README 里声明为共享子系统。

## 1. 目标结构

```
src/main/plugins/
  README.md          目录约定 + 新增/修改/删除/升级/卸载清单
  registry.ts        唯一清单（BUILTIN_EXTENSIONS + hot）
  host.ts            createPluginHost
  control.ts         设置页控制面（list / setEnabled / remove）
  active.ts          isExtensionActive 运行期门
  builtin/<name>/    index.ts（manifest + apply）+ 实现 + 测试
  external/          外部扩展加载、官方扩展同步、路径、脚手架、自检、依赖引导
  external-src/      官方外部扩展源码（构建成 resources/extensions/<id>/main.js）
  install/           插件中心的运行时依赖安装（不是本系统的插件）
```

## 3. 工具与判据（迁移怎么做）

搬迁是机械操作，但有两个已经踩过的坑：

1. **相对说明符重写**必须按「旧路径解析、新路径生成」，且只改引号内的那一段——
   用 `ts.createPrinter` 重印会把全文重排、LF→CRLF、静默漏删（见记忆 `ast-batch-rewrite-hard-gates`）。
   本次用一次性脚本 `/tmp` 下的 `lumii-rewrite-imports.mjs`：正则覆盖
   `from '…'`、`import('…')`、`require('…')`、`vi.mock('…')`，保持原扩展名风格
   （`.js` / `.mjs` / 无扩展名），**目标与导入方都没动时一个字符都不改**。
2. **目录搬运用 `git mv`**，保留文件历史；后再重写 import。

验收判据（每批）：

| 判据 | 说明 |
|---|---|
| `tsc --noEmit` 零错误 | 类型层就是引用完整性 |
| 该插件的测试文件通过 | 单个插件搬完就能跑，不必等全量 |
| `node scripts/check-wiring.mjs` 通过 | 接线守卫不吃路径变化 |
| `git status` 只含本批预期的文件 | 防脚本波及无关文件 |

回滚：每批一个提交，`git revert <sha>` 即可单独回退。

## 4. 风险

| 风险 | 处置 |
|---|---|
| 动态 import / `vi.mock` 里的相对路径漏改 | 脚本已覆盖四种形态；`tsc` 与测试兜底 |
| `.js` / `.mjs` 说明符被改写坏 | 保持原风格；已修过一次（`commands.mjs` 被剥掉扩展名） |
| 路径类配置不同步（构建脚本、守卫基线、ipc 归属表） | 每批跑守卫；基线与 `build-official-extensions.mjs` 随 A 批更新 |
| 并行会话在同一工作区改代码 | 提交前按文件显式 `git add`，不用 `git add -A` |
| 文件行尾被脚本改成 LF | 重写只替换引号内字符串，不整文件重排 |
