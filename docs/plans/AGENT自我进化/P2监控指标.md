## 一、指标清单

| 指标 | 类型 | 来源事件 | 目标/告警 |
|------|------|----------|-----------|
| `memory-ranking-ndcg` | Gauge | 离线评估任务 | 相对 P1 基线不下降；连续 3 次下降告警 |
| `memory-feedback-latency` | Histogram | `memory-feedback-recorded` | p95 < 100ms |
| `memory-model-version` | Gauge | `memory-model-retrained` | 单调递增；回滚时记录原因 |
| `memory-ineffective-count` | Gauge | `ineffective-memories-identified` | 突增需人工复核 |
| `tool-selection-success-rate` | Gauge | `tool-feedback-recorded` | 按工具、任务类型分别观察 |
| `tool-selection-exploration-rate` | Gauge | `tool-selected` | 偏离配置预算 ±50% 时告警 |
| `skill-success-rate` | Gauge | `skill-usage-recorded` | 连续低于 60% 触发缺口 |
| `skill-gap-count` | Gauge | `skill-gaps-identified` | 持续增长需人工介入 |
| `layer-contribution` | Gauge | 协调器归因 | 四层贡献总和应接近 1 |
| `exploration-mode` | Counter | 调度决策 | 检查是否出现同时探索多层 |
| `conflict-detected` | Counter | `conflict-resolved` / `conflict-unresolved` | critical 未解决需告警 |
| `conflict-resolved` | Counter | `conflict-resolved` | 与 detected 的比值用于评估规则覆盖 |
| `pareto-frontier-size` | Gauge | 前沿维护 | 不超过 `PARETO_FRONTIER_MAX_SIZE`（100） |
| `p2-fallback-count` | Counter | 各层 fallback 日志 | 稳定低于 10%；异常升高需告警 |
| `p2-feedback-write-failure` | Counter | 写入失败日志 | 失败率 > 10% 告警 |

## 二、Telemetry 字段规范

所有 P2 事件统一包含：

| 字段 | 说明 |
|------|------|
| `agentId` | Agent 标识 |
| `sessionId` | 会话标识 |
| `correlationId` | 关联 ID，用于串联配置快照与反馈事件 |
| `strategyVersion` | 策略版本（层配置快照的版本号） |
| `modelVersion` | 模型版本（记忆排序模型的 `version`） |
| `durationMs` | 关键路径耗时 |

**禁止包含**：用户消息原文、记忆内容、查询原文、密钥/令牌、工具敏感参数。

记忆反馈只持久化 `query_length` 与特征快照，不写入 `query` 本身（见 `memory_usage_feedback` 表）。

## 三、性能门槛

来自实施计划 7.2 节，已在 `__tests__/integration/p2-e2e.test.ts` 的"性能门槛"用例中覆盖：

- 单次配置选择纯计算 p95 < 50ms
- 单次反馈记录异步提交，不增加主流程 p95 超过 100ms
- 记忆排序候选 100 条以内 p95 < 50ms
- 工具采样选择 p95 < 10ms
- 帕累托前沿默认不超过 100 个配置

## 五、灰度观察项

按实施计划第十二节，发布采用 feature flag：先离线回放，再 5% 灰度，观察至少 7 天。灰度期间重点观察：

1. `p2-fallback-count` 是否稳定低于 10%
2. `layer-contribution` 四层是否出现单层长期垄断（归因失真信号）
3. `exploration-mode` 是否始终为单层探索
4. `conflict-detected` 中 critical 的绝对数量与解决率
5. 记忆 NDCG@5、工具成功率、技能满意度相对 P1 基线的变化

未达门槛时保持 P1 策略，不自动扩大灰度范围。
