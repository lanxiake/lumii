## 阅读顺序（接手时）

1. 现状与边界：第一期**实施计划 §9** → 第二期**计划反思**（两条合起来才是最新状态）；
2. 要动某块之前：读对应设计（一期的看 `design/` 第一期设计，二期的看 `2026-10-01-第二期运行时对等设计.md`）；
3. 无头形态：先读**无头模式用户引导设计**，部署与排查看**部署指南**。
