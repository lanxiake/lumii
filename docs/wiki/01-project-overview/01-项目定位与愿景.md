# 项目定位与愿景

## Lumii 项目简介

Lumii（灵栖）是一款**本地优先的 AI 桌面伙伴**，以 Electron 桌面应用为载体，构建了一套完整的 Agent（智能体）系统。它不仅是传统的对话式 AI 助手，更是一个具备自主决策能力、长期记忆和多设备协同能力的智能伙伴。

项目定位为「开源独立版」桌面 AI 助手，强调数据本地化、隐私安全与用户控制权，同时提供丰富的扩展能力（技能系统、MCP 服务、多智能体协作）。

当前版本：`v0.1.3`

---

## 核心价值主张

### 1. 自主进化 Agent

Lumii 的 Agent 系统不仅仅是被动响应指令，而是具备**自主性与进化能力**：

- **自主调度**：内置 `autonomous` 模块，Agent 可自主生成目标、规划任务、执行动作
- **自我反思**：通过 `reflection-engine` 和 `meta-cognition-engine` 进行元认知反思
- **技能进化**：动态学习和优化工具使用策略（`tool-evolution`、`skill-evolution`）
- **记忆演化**：长期记忆通过巩固、摘要、遗忘机制持续演化

### 2. 多层记忆系统

Lumii 构建了完整的分层记忆架构，让 AI 真正「记住」用户：

| 记忆层级 | 说明 | 管理方式 |
|----------|------|----------|
| AI 灵魂 (SOUL) | AI 的人格、风格、行为准则 | 编辑 SOUL 描述 |
| 工作记忆 | 当前项目的资源、事实、上下文 | 自动管理 + 手动配置 |
| 个人记忆 | 用户的偏好、历史、身份信息 | `profile_memory` 管理 |
| Wiki 知识库 | 结构化知识存储与检索 | `wiki_*` 工具集 |

### 3. 多设备同步与双连接架构

Lumii 设计了独特的**双连接架构**，支持灵活的部署模式：

- **Gateway 连接**：通过中心网关实现多设备同步、云端协作
- **Node 模式连接**：本地节点模式，支持离线/局域网独立运行
- **设备配对服务**：安全的设备认证与双 Token 机制（UI Token + Node Token）
- **多端协同**：Windows 桌面端为主，可扩展移动端、Web 端

## 目标用户与使用场景

### 目标用户

| 用户群体 | 核心诉求 |
|----------|----------|
| 开发者/技术工作者 | 代码助手、任务自动化、文档处理 |
| 知识工作者 | 知识管理、信息整合、内容创作 |
| 创作者 | 文案撰写、图片/视频生成、创意辅助 |
| 效率追求者 | 定时任务、工作流自动化、多工具集成 |
| 隐私敏感用户 | 本地优先、数据可控、开源透明 |

### 典型使用场景

1. **智能对话与任务执行**
   - 自然语言对话，支持上下文理解与中途插话
   - 调用本地工具执行 Shell 命令、文件操作、代码编写

2. **知识管理与 Wiki 构建**
   - 自动抓取资讯并生成综述
   - 文档分类、标签化、语义检索
   - 支持 Obsidian Vault 同步

3. **多智能体协作（AI 团队）**
   - 创建分工明确的 Agent 团队
   - 支持 Map/Grid/Feed 多种视图模式
   - 复杂任务拆解与并行执行

4. **技能生态与工具扩展**
   - 内置 18+ 技能（代码开发、文档处理、设计可视化等）
   - 支持 SkillNet 技能市场与本地导入
   - MCP（Model Context Protocol）服务集成，47+ 工具可用

5. **自动化与定时任务**
   - Cron 表达式与间隔重复调度
   - 早间简报、工作日报、每周复盘自动生成
   - 工作区文件自动整理

6. **桌宠与陪伴模式**
   - Live2D 虚拟形象可视化
   - 情绪表达与唇形同步
   - 桌面常驻陪伴交互
