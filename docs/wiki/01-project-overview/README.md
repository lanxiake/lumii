# 01. 项目概览

## 简介

本章节是 Lumii 项目的全景导览，旨在帮助新加入的开发者、产品经理和外部贡献者在最短时间内建立对项目的完整认知。内容涵盖 Lumii 的诞生背景、产品愿景、核心价值主张、目标用户画像以及在 AI 桌面助手领域的差异化定位。通过阅读本章，读者能够理解项目「为什么存在」以及「希望走向何方」，为后续深入技术细节建立上下文基础。

除了产品视角的介绍，本章还梳理了 Lumii 的技术栈全景图，从 Electron 桌面端框架、React 渲染层、TypeScript 类型系统，到 AI Agent 运行时、向量数据库、MCP 协议集成等核心技术组件的选型与组合逻辑。研发协作模式、版本管理策略、发布节奏等团队运作机制同样在此章节说明，确保每位参与者都能清晰了解项目的运作方式。
