## Monorepo 结构说明

项目采用 pnpm Workspace 的 Monorepo 架构，按**应用层**与**共享库层**分离：

```
lumii/
├── apps/
│   └── windows/          # Windows 桌面 Electron 应用
│
└── packages/             # 可复用的共享库（纯 TypeScript）
    ├── agent-runtime/    # Agent 运行时核心
    ├── pet-core/         # 桌宠共享逻辑
    └── (其他共享包...)
```

### 分层原则

| 层级 | 目录 | 职责 | 依赖约束 |
|------|------|------|----------|
| 应用层 | `apps/windows` | Electron 特定实现、UI、系统集成 | 可依赖 packages/* |
| 共享库层 | `packages/*` | 通用业务逻辑、纯算法、类型定义 | 不得依赖 apps/* |

### 协作边界

- **Electron 专属逻辑**（窗口管理、IPC、托盘、文件系统）→ `apps/windows/src/main`
- **通用 Agent/记忆/工具逻辑** → `packages/agent-runtime`
- **桌宠纯逻辑**（状态机、映射策略，不含渲染）→ `packages/pet-core`

## 核心包职责边界

### packages/pet-core — 桌宠共享核心

**定位**：纯 TypeScript 共享库，为 Windows 桌面端和移动端提供统一的桌宠逻辑。

**严格约束**：不得依赖 React、Electron、PixiJS 或 DOM API。

| 模块 | 文件 | 职责 |
|------|------|------|
| 状态机 | `state/petStateMachine.ts` | 宠物状态流转（待机/说话/思考/动作等） |
| 情绪映射 | `mapping/emotion-tag-parser.ts` | Agent 信号 → 情绪标签解析 |
| 信号映射 | `mapping/agentSignalMapper.ts` | Agent 运行时事件 → 宠物动作信号 |
| 表情策略 | `expression/state-expression-policy.ts` | 状态 → 表情/动作决策策略 |
| 唇形同步 | `lipsync/mouth-waveform.ts` | 语音波形 → 口型动画数据 |
| 渲染抽象 | `render/pet-renderer.ts` | 渲染器接口定义（WebView/其他实现） |
| 模型配置 | `model/pet-model-types.ts` | 宠物模型元数据类型定义 |

### packages/agent-runtime — Agent 运行时核心

**定位**：客户端 Agent 运行时，驱动 `pi-agent-core` 在本地执行。

**主要模块群**：

| 模块群 | 关键文件 | 职责 |
|--------|----------|------|
| **Agent 内核** | `agent/` | Agent 实例、编排器、子代理经纪人、令牌预算、卡住检测 |
| **自主系统** | `autonomous/` | 目标生成、规划器、反思引擎、情绪、人格追踪、能力评级 |
| **记忆系统** | `memory/` | 分段记忆、记忆索引、巩固/摘要、合并、温度调节 |
| **上下文压缩** | `compact/` | 多种压缩策略（微压缩、摘要压缩、硬裁剪） |
| **工具系统** | `tools/` | 内置工具（40+）、MCP 代理、工具钩子、工具运行器 |
| **存储层** | `storage/` | SQLite 本地数据库、会话/消息/任务/Wiki 仓储 |
| **提示词构建** | `prompt/` | 系统提示词构建器、SOUL、Guide、Section |
| **Wiki 知识库** | `wiki/` | Wiki 分类、图谱、摄取、遗忘、导出、Vault 同步 |
| **权限与安全** | `security/` | 权限检查、参数解析、沙箱、确认消息 |
| **消息总线** | `messaging/` | 发布/订阅消息系统，跨模块解耦 |
| **能力注册** | `capability/` | 能力源（工具/技能/MCP）统一注册 |
| **可靠性** | `reliability/` | 卡住防护、自愈、消息修复 |
| **Shell 执行** | `shell/` | 多平台 Shell 提供器（Bash/PowerShell/Cmd） |
