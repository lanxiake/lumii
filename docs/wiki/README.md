## Wiki 定位

本 Wiki 是 Lumii 桌面智能助手项目的知识库与开发实践指南，既是项目专属的技术文档体系，也是可复用的通用软件开发方法论手册。Wiki 以 Lumii 的真实研发历程为载体，系统性整理了从需求分析、架构设计、编码实现到测试运维的全流程工程实践，沉淀了大型 TypeScript/Electron 应用开发中的架构决策、设计模式、问题诊断与优化经验。

Lumii 是一款集成了多模态 AI 对话、自主进化 Agent、记忆与知识库系统、跨设备数据同步的桌面生产力工具，涵盖 Electron 主进程、渲染进程、Node.js 服务层、向量数据库、MCP 协议等多技术栈。本 Wiki 不仅记录「如何做」，更解释「为什么这样做」，帮助开发者在面对类似技术挑战时做出有依据的工程决策。

## 快速开始指南

### 新开发者三步上手

1. **建立项目认知**：先阅读 [01. 项目概览](./01-project-overview/README.md) 了解项目背景与技术栈，再查看仓库根目录的 [`AGENTS.md`](../../AGENTS.md) 获取协作规范。

2. **搭建开发环境**：按照 [05. 实施指南 · 环境搭建](./05-implementation/README.md) 的步骤完成依赖安装与本地启动，确保 `pnpm dev` 能正常运行 Windows Electron 开发环境。

3. **认领第一个任务**：从 [09. 开发规范手册](./09-standards/README.md) 熟悉代码风格后，选择标记为 `good-first-issue` 的任务开始实践，提交前运行 `pnpm typecheck` 和对应包的测试。

### 常用命令速查

```bash
pnpm install       # 安装依赖并重建原生模块
pnpm dev           # 启动 Windows Electron 开发环境
pnpm typecheck     # 全 workspace 类型检查
pnpm build         # 构建 Windows 应用
pnpm --filter ./apps/windows lint
pnpm --filter ./apps/windows test
pnpm --filter ./packages/agent-runtime test
pnpm --filter ./packages/pet-core test
```

## 按角色的阅读路径建议

### 新人开发者

```
项目概览 → 开发规范手册 → 实施指南（环境搭建）→ 详细设计（当前迭代模块）→ 测试与质量（提交前检查）
```

建议先通读 [09. 开发规范手册](./09-standards/README.md) 中的代码风格与提交规范，再对照 [05. 实施指南](./05-implementation/README.md) 完成第一个功能的开发。遇到问题时查阅 [07. 问题修复](./07-debugging-and-fixes/README.md) 的常见问题章节。

### 架构师

```
项目概览（愿景与约束）→ 架构设计（分层与决策）→ 经验总结（架构演进）→ 详细设计（核心模块）→ 知识索引
```

重点关注 [03. 架构设计](./03-architecture/README.md) 中的架构决策记录（ADR）和 [08. 经验总结](./08-experience/README.md) 中的架构演进复盘，理解历次架构调整的驱动因素与权衡取舍。

### 测试工程师

```
需求工程（验收标准）→ 测试与质量（策略与方法）→ 详细设计（接口契约）→ 问题修复（Bug 流程）→ 实施指南（调试工具）
```

从 [02. 需求工程](./02-requirements/README.md) 中的验收标准定义开始，结合 [06. 测试与质量](./06-testing/README.md) 的测试金字塔模型，建立各层级测试用例，使用 [07. 问题修复](./07-debugging-and-fixes/README.md) 的流程管理 Bug 生命周期。

### 产品经理

```
项目概览（愿景与范围）→ 需求工程（方法论）→ 经验总结（里程碑复盘）→ 知识索引（功能索引）→ 详细设计（交互设计）
```

使用 [02. 需求工程](./02-requirements/README.md) 的框架组织用户反馈与功能规划，参考 [08. 经验总结](./08-experience/README.md) 了解历史迭代的交付节奏，通过 [10. 知识索引](./10-knowledge-index/README.md) 快速定位功能文档。
