# 05. 实施指南

## 简介

实施指南是开发者从「理解设计」到「交付代码」的实操手册。本章节覆盖了从开发环境搭建、代码编写、调试运行到代码提交、集成构建、灰度发布的完整开发生命周期。不同于规范手册的「应该怎样」，实施指南更强调「具体怎么做」，提供了大量可直接复用的操作步骤、命令片段和检查清单，帮助开发者高效完成日常编码任务。

Lumii 作为多包（monorepo）管理的大型项目，涉及依赖安装的特殊处理、Electron 原生模块重建、多进程联调调试、增量构建优化等工程化挑战。本章节基于团队踩坑经验整理了环境搭建的避坑指南、常见编译错误速查表、调试技巧工具链（如 React DevTools、Electron 调试、性能分析）以及大型重构的安全实施策略。同时，渐进式交付方法（特性开关、分阶段合入、数据迁移双写方案等）也在此章节详细说明。
