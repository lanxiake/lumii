## 一、自主进化 Agent 系统

### 范围
构建具备长期运行、自主进化、主动学习、人格独立、情境感知五大特征的自主 Agent，涵盖元认知评估、内在目标生成、Prompt 进化、人格追踪、能力边界检测、多层进化协同（记忆/技能/工具策略）、心跳与生命感等子能力。

### 已完成度
- **P0（基础进化能力）**：✅ 已完成。满意度评分（4 维度加权）、目标生成（learning / proactive-message）、Prompt 进化（ε-greedy A/B 测试）、人格追踪（Big Five 事件记录）。
- **P1（能力边界与自我反思）**：✅ 已完成。能力边界检测（Elo Rating System）、8 个能力维度追踪、自我反思引擎、能力改进目标。
- **P2（多层进化协同）**：🟡 代码已落地，待接入产品。记忆策略进化（Learning-to-Rank）、技能策略进化、工具选择进化（Thompson Sampling）、Shapley Value 归因、冲突检测与帕累托前沿。
- **P3（协同闭环 + 多 Agent 自组织）**：🔵 设计阶段。CoordinationController 接线、离线审批架构、协同闭环落地、多 Agent 自组织。

## 二、记忆与 Wiki 知识库系统

### 范围
结构化记忆管理、资料文档管理、Wiki 式知识沉淀三大目标。基于 ERO 图谱模型（Entity/Relation/Observation）、Karpathy DKR 编译流程（raw→wiki 分层 + Triage/Compile/Cascade/Post-ingest 四步）、混合检索 + RRF 融合、矛盾检测、双时态时间建模、遗忘曲线等方法论。P0 至 P3 覆盖 CRUD、编译管线、图谱、智能检索。

### 已完成度
- **P0（MVP）**：✅ Wiki Schema + FTS5、Repo CRUD + 搜索、IPC 桥接、MemoriesPage Wiki Tab（树 + 编辑器 + 反链）、Markdown 导出。
- **P1（编译）**：✅ LLM 编译管线（Triage/Compile/Cascade/log）、source fidelity 校验、Outdated/Disputed 状态。
- **P2（图谱 + 时间）**：✅ ERO 三表、supersede 语义、矛盾扫描、双时态查询、关系强度合并。
- **P3（智能检索 + 智能 Vault）**：✅ 本地 embedding + RRF 混合检索、相关推荐、遗忘曲线；Intelligent Vault P1~P7（分类、去重、摘要向量、编目、重命名、全量上线）。
- **迁移设计**：🟡 Wiki Library 迁移设计与实施。

### 范围
从「阈值触发单阶段」升级为「分层渐进 + 无感自愈」的多层化引擎。Phase 1：Proactive Prune 三阶段（Dedup+Summarize+Truncate）、Reclaim Gate、Rearm 跑道、绝对阈值 Cap、小窗口地板。Phase 2：Per-Model 阈值覆盖（最长子串匹配）、Idle Compaction（空闲触发）、Progress-Aware 双预算超时（续命 + 封顶）。Phase 3：Commit Fence + 落库事务化、失败回滚 + 重试冷却、尾部压力降级。

### 已完成度
- **Phase 1（稳定性 + 成本）**：✅ Proactive Prune（0.48 提前触发）、Reclaim Gate 4096、Rearm 跑道（防抖动）、绝对 Cap 200K + 小窗口地板 75%。
- **Phase 2（体验 + 适配）**：✅ Per-Model 阈值 + 最长子串匹配、Idle Compaction 后台压缩（默认 300s）、ProgressFence 双预算超时（idle=120s / ceiling=600s + 流式续命）。
- **Phase 3（一致性兜底）**：✅ 压缩事务化 + commitPhase 永不中断、failure_cooldown、anti_thrash。
- **测试与报告**：✅ 多轮 Context Compression 测试用例、边界用例、修复计划、测试报告。

## 九、渠道外联与 ACP

### 范围
**渠道外联 Hub**：统一的出站注册表 + 路由（ChannelRegistry + ChannelOutboundRouter），Agent 双工具 `channel_list` / `channel_send`，三渠道 Provider（飞书真 Push、微信缓存 token 伪 Push、企微 reply_only 硬失败），微信 token 持久化缓存，Cron 通知改走同一 Router。
**ACP（Agent Companion Protocol）**：设置页仅保留 Cursor/Claude/Codex/Copilot 四件套官方风格字标图标，本机检测 + 安装链接 + 工作目录设置，本地 spawn（不再依赖 Gateway）。渠道图标去掉 emoji，采用简洁色块字标。

### 已完成度
- **渠道外联一期 MVP**：✅ Hub（Registry + Router + 三 Provider）、双工具（channel_list / channel_send，含权限确认）、微信 ReplyContext 持久化（24h stale）、Cron 飞书/微信改走 Router、硬失败 errorCode 体系、单测覆盖。
- **渠道外联二期**：✅ 富媒体出站、Settings peer 只读面板、`channelService` IPC、`message` 工具废弃合并到 Router。
- **ACP 与渠道图标**：✅ 渠道图标改官方字标风格、ACP 设置面板收缩为 4 件套 + 检测/安装/工作目录 + 本地 spawn 实现。
