# 03-页面开发模板

## 一、标准页面目录结构

```
page-name/
├── PageName.tsx              # 主页面组件（必选，<500行）
├── PageName.module.css       # 页面专属样式（仅布局类，不写组件样式）
├── PageName.test.tsx         # 页面级测试（四状态+主要交互+路由跳转）
├── components/               # 页面专属子组件（可选，仅本页用，不跨页复用）
│   ├── PageSectionCard/
│   │   ├── PageSectionCard.tsx
│   │   └── PageSectionCard.module.css
│   └── DataListItem/
│       ├── DataListItem.tsx
│       └── DataListItem.module.css
└── hooks/                    # 页面专属 hooks（可选，>2 页面共用则抽到全局 hooks/）
    └── usePageData.ts
```

**命名约定**

| 类别 | 规范 | 示例 |
| --- | --- | --- |
| 目录 | kebab-case | `settings-page/`、`approval-center/` |
| 页面组件 | PascalCase + Page 后缀 | `SettingsPage.tsx`、`AutonomousPage.tsx` |
| CSS Modules | 同名 `.module.css` | `SettingsPage.module.css` |
| 子组件 | PascalCase | `ApprovalListCard.tsx` |
| Hooks | camelCase + use 前缀 | `useApprovalQueue.ts` |

## 二、React 页面组件骨架代码（四状态完整）

**PageName.tsx**

```tsx
import React, { useCallback } from 'react';
import {
  PageHeader,
  Button,
  Loading,
  Empty,
  ErrorBanner,
} from '@/components/ui';
import { usePageData } from './hooks/usePageData';
import { DataListItem } from './components/DataListItem/DataListItem';
import styles from './PageName.module.css';

export const PageName: React.FC = () => {
  const {
    data,
    loading,
    error,
    refresh,
    clearError,
    handleCreate,
  } = usePageData();

  // ① 加载态：首次请求且无数据 → 全屏 Loading
  //    如果是刷新（已有 data）→ 显示已有数据 + 局部 inline Loading，避免闪烁
  if (loading && !data) {
    return <Loading fullPage text="页面加载中..." />;
  }

  // ② 错误态：任何时候 error 都优先展示 ErrorBanner
  //    不直接 return，让用户在错误时仍能看到已有的旧数据（若有）
  return (
    <div className={styles.pageContainer}>
      {/* Header：标题 + 描述 + 右上角操作按钮（必需） */}
      <PageHeader
        title="页面标题"
        subtitle="页面功能描述（一句话告诉用户这页是干嘛的）"
        actions={
          <>
            <Button variant="secondary" onClick={refresh} loading={loading}>
              刷新
            </Button>
            <Button variant="primary" onClick={handleCreate}>
              新建
            </Button>
          </>
        }
      />

      {/* ErrorBanner：页头下紧跟错误条（必需） */}
      {error && (
        <ErrorBanner
          message={error instanceof Error ? error.message : String(error)}
          onRetry={refresh}
          onClose={clearError}
        />
      )}

      {/* 页面内容区：flex 占满剩余高度 + 独立滚动（必需结构） */}
      <div className={styles.pageContent}>
        {/* ③ 空数据态：成功返回但数据长度 0 */}
        {!data || data.items.length === 0 ? (
          <Empty
            description="暂无数据，点击右上角【新建】添加第一条"
            action={
              <Button variant="primary" onClick={handleCreate}>
                新建第一项
              </Button>
            }
          />
        ) : (
          // ④ 成功态：正常渲染业务内容
          <div className={styles.itemList}>
            {data.items.map((item) => (
              <DataListItem key={item.id} item={item} />
            ))}
          </div>
        )}

        {/* 加载中但已有数据的 inline 提示 */}
        {loading && data && (
          <div className={styles.inlineLoading}>
            <Loading size="sm" text="数据刷新中..." />
          </div>
        )}
      </div>
    </div>
  );
};
```

## 三、页面状态管理模式（Context + 自定义 Hook）

### 3.1 何时用 Context

页面内组件嵌套超过 3 层需要共享状态（如筛选条件、排序、分页）→ 用 Page-level Context；**全局主题/用户/连接状态用 app 级 Context**。

**文件结构（5 文件法则）**

```
hooks/
├── PageContext.tsx         Context Provider + 初始状态
├── PageContext.types.ts    State + Action 类型
├── PageContext.reducer.ts  Reducer 纯函数（不产生副作用）
├── PageContext.actions.ts  业务 Action creators（可异步）
└── usePageData.ts          对外 usePageData Hook：封装 Context + 数据获取
```

### 3.2 usePageData Hook 骨架

```tsx
// hooks/usePageData.ts
import { useCallback, useEffect, useMemo } from 'react';
import { usePageState, usePageDispatch } from './PageContext';
import type { PageData } from './PageContext.types';
import { fetchData, createItem } from '@/services/page-name.service';

export const usePageData = () => {
  const { data, loading, error, filters, pagination } = usePageState();
  const dispatch = usePageDispatch();

  // 刷新函数：useCallback 包一层保证引用稳定
  const refresh = useCallback(async () => {
    dispatch({ type: 'FETCH_START' });
    try {
      const result: PageData = await fetchData({ filters, pagination });
      dispatch({ type: 'FETCH_SUCCESS', payload: result });
    } catch (err) {
      dispatch({
        type: 'FETCH_ERROR',
        payload: err instanceof Error ? err : new Error(String(err)),
      });
    }
  }, [filters, pagination, dispatch]);

  // 首次挂载 + filters/pagination 变化自动刷新
  useEffect(() => {
    refresh();
  }, [refresh]);

  const clearError = useCallback(() => {
    dispatch({ type: 'CLEAR_ERROR' });
  }, [dispatch]);

  const handleCreate = useCallback(async (form: CreateItemForm) => {
    dispatch({ type: 'CREATE_START' });
    try {
      const newItem = await createItem(form);
      dispatch({ type: 'CREATE_SUCCESS', payload: newItem });
    } catch (err) {
      dispatch({ type: 'CREATE_ERROR', payload: err as Error });
    }
  }, [dispatch]);

  // 计算派生数据：排序后列表 / 统计值等
  const sortedItems = useMemo(
    () => [...(data?.items ?? [])].sort((a, b) => b.updatedAt - a.updatedAt),
    [data],
  );

  return {
    data: data ? { ...data, items: sortedItems } : undefined,
    loading,
    error,
    refresh,
    clearError,
    handleCreate,
    // 暴露 filters/pagination 给 UI 筛选器组件
    filters,
    pagination,
    setFilters: (f) => dispatch({ type: 'SET_FILTERS', payload: f }),
    setPage: (page) => dispatch({ type: 'SET_PAGE', payload: page }),
  };
};
```

**规则**：Reducer 纯函数不做 I/O、不调 API、不改 Date/随机（纯可预测）；所有副作用（fetch/setTimeout/IPC 调用）都在 action creators 或 useEffect 里，dispatch 纯 action。

## 四、数据获取与错误边界模式

### 4.1 Service 层 + 四层错误处理

| 层级 | 职责 | 实现 |
| --- | --- | --- |
| Service（数据获取） | 调 IPC / fetch → 包装 AppError 子类抛出 | `fetchData()` throw `NotFoundError` / `PermissionError` |
| Hook（状态） | try/catch 捕获 → 存 error state + 重抛（可选） | usePageData 中的 `FETCH_ERROR` dispatch |
| UI 组件（展示） | error 非空时渲染 `<ErrorBanner onRetry>` | PageName 顶部 ErrorBanner |
| Error Boundary（兜底） | 整颗子树崩溃时（渲染期 throw）显示崩溃页 + 可重启 | `<PageErrorBoundary>` 包每个路由页 |

### 4.2 页面级 Error Boundary 用法（必需，每页路由外层包一层）

```tsx
// routes/PageErrorBoundary.tsx
import React, { Component, ErrorInfo } from 'react';
import { ErrorBanner, Button } from '@/components/ui';

interface Props { children: React.ReactNode; pageName: string }
interface State { error: Error | null }

export class PageErrorBoundary extends Component<Props, State> {
  state: State = { error: null };

  static getDerivedStateFromError(error: Error): State {
    return { error };
  }
  componentDidCatch(error: Error, info: ErrorInfo) {
    // 写崩溃日志，不上传敏感数据
    console.error(`[Page: ${this.props.pageName}] crashed`, error, info.componentStack);
  }
  handleRestart = () => {
    this.setState({ error: null });
    // 可加 IPC 调 main 重置对应模块状态
  };
  render() {
    if (this.state.error) {
      return (
        <div style={{ padding: 48 }}>
          <ErrorBanner
            title={`${this.props.pageName} 崩溃了`}
            message={this.state.error.message}
            onRetry={this.handleRestart}
          />
          <div style={{ marginTop: 16 }}>
            <Button onClick={() => location.reload()}>重启页面</Button>
          </div>
        </div>
      );
    }
    return this.props.children;
  }
}
```

## 五、页面路由与导航的集成方式

### 5.1 路由配置（集中一处）

```tsx
// routes/index.tsx
import React from 'react';
import { createHashRouter, Navigate } from 'react-router-dom';
import { PageErrorBoundary } from './PageErrorBoundary';

// 懒加载所有页面（首屏代码分割）
const DashboardPage = React.lazy(() => import('../pages/DashboardPage/DashboardPage'));
const ChatPage = React.lazy(() => import('../pages/ChatPage/ChatPage'));
const SettingsPage = React.lazy(() => import('../pages/SettingsPage/SettingsPage'));
const AutonomousPage = React.lazy(() => import('../pages/AutonomousPage/AutonomousPage'));

// 路由 ID 与 Sidebar 导航 ID 对齐（见 ViewType 联合类型）
export type RouteId =
  | 'dashboard'
  | 'chat'
  | 'settings'
  | 'autonomous'
  | 'files'
  | 'memories'
  | 'wiki'
  | 'devices';

export const router = createHashRouter([
  { path: '/', element: <Navigate to="/dashboard" replace /> },
  {
    path: '/dashboard',
    element: (
      <PageErrorBoundary pageName="Dashboard">
        <React.Suspense fallback={<div /> /* 外层 MainLayout 已处理 */}>
          <DashboardPage />
        </React.Suspense>
      </PageErrorBoundary>
    ),
  },
  {
    path: '/chat',
    element: (
      <PageErrorBoundary pageName="Chat">
        <React.Suspense><ChatPage /></React.Suspense>
      </PageErrorBoundary>
    ),
  },
  // ... 其他路由，每个都独立包 PageErrorBoundary + Suspense
]);
```

### 5.2 页面内跳转规范

| 场景 | 写法 |
| --- | --- |
| 跳转到其他页面 | `const navigate = useNavigate(); navigate('/settings/approvals');` 不写 `window.location.hash = ...` |
| 带参数跳转 | `navigate(`/memories/${encodeURIComponent(id)}`);` 组件内 `useParams()` 取 |
| 面包屑 / 后退 | `const navigate = useNavigate(); <Button onClick={() => navigate(-1)}>返回</Button>` |
| Sidebar 导航联动 | Navigate 触发 → `activeView` state 同步更新，避免 URL 与侧边栏高亮不一致 |

## 六、组件选择指南对照表

| 场景 | 推荐组件 | 用法示例 |
| --- | --- | --- |
| 页面标题 + 副标题 + 右上操作按钮 | **PageHeader（必需）** | `<PageHeader title="设置" subtitle="应用全局配置" actions={<Button>保存</Button>} />` |
| 表单主要提交动作 | **Button (variant=primary)** | `<Button type="submit" loading={submitting}>保存设置</Button>` |
| 次要取消/返回动作 | **Button (variant=ghost)** | `<Button variant="ghost" onClick={navigateBack}>取消</Button>` |
| 删除/撤销等破坏性动作 | **Button (variant=danger)** | `<Button variant="danger" onClick={handleDelete}>删除该项目</Button>` |
| 工具栏小图标按钮 | **Button (variant=ghost, size=sm)** | `<Button variant="ghost" size="sm" aria-label="搜索">🔍</Button>` |
| 首次进入页面无数据 | **Loading (fullPage)** | `if (loading && !data) return <Loading fullPage text="加载中..." />` |
| 保存中的行内按钮状态 | **Button (loading)** | `<Button loading={isSaving}>保存中</Button>` |
| 请求失败/权限不足/格式错误 | **ErrorBanner（必需）** | `<ErrorBanner message={error.message} onRetry={refetch} onClose={clearErr} />` |
| 查询成功无结果/空数组 | **Empty（推荐）** | `<Empty description="暂无记忆条目" action={<Button>新建</Button>} />` |
| 长列表懒加载 | **Table (pagination) 或 虚拟列表** | `<Table dataSource={data} columns={cols} rowKey="id" pagination />` |

## 七、重构检查清单（7 项必过）

把现有页面改造为模板时，MR  reviewer 对照检查，缺一不通过：

- [ ] **PageHeader 替换**：删除自定义 header div，统一用 PageHeader 组件，actions 传按钮组
- [ ] **ErrorBanner 替换**：删除手写 `.error { color: red }` 样式，统一用 ErrorBanner + onRetry
- [ ] **Loading 替换**：删除手写 spinner/emoji 动画，统一用 Loading 组件 fullPage/inline
- [ ] **Button 替换**：所有原生 `<button>` / `<a>` 行为按钮换成 `<Button variant=...>`，不允许裸原生按钮
- [ ] **冗余 CSS 删除**：页面 CSS 只剩 page-container / page-content / page-actions 三类布局类 + 响应式 media query；组件级样式移回子组件各自的 module.css
- [ ] **导入顺序一致**：React → 第三方库 → UI 组件 → 业务组件 → Hooks → types → 样式
- [ ] **类型完整零 any**：页面 Props/State/Hook 返回值/Service 返回值全加类型；`pnpm typecheck` 零 error / 零 eslint `no-explicit-any`
