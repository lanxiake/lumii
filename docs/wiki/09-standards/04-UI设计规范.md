# 04-UI 设计规范

## 一、设计令牌体系（Design Tokens）

### 1.1 令牌定义位置与引用层级

所有视觉样式必须通过设计令牌访问，**禁止硬编码颜色值、固定间距、固定字号**。

| 令牌层级 | 定义位置 | 引用方式 | 适用场景 |
| --- | --- | --- | --- |
| **CSS 变量**（真相源） | `src/renderer/styles/tokens.css` | `var(--mt-surface-rgb)` | 所有 CSS / CSS Modules / 行内动态像素除外 |
| **TypeScript 令牌** | `src/renderer/styles/tokens/*.ts` | `import { colors } from '@/styles/tokens/colors'` | 图表、Canvas、PixiJS（无法直接访问 CSS 变量的场景） |
| **主题覆盖** | `tokens.css` 中 `[data-theme="light"]` 选择器 | 透明覆盖同名变量 | 主题切换（见下节） |

**TS 令牌文件清单**

| 文件 | 内容 | 示例项 |
| --- | --- | --- |
| `colors.ts` | 语义化颜色（非十六进制语义名） | `surface.rgb` / `fg.level1` / `accent.primary` / `status.success` |
| `spacing.ts` | 间距系统 | `xs=4 / sm=8 / md=16 / lg=24 / xl=32 / xxl=48` 倍 scale |
| `typography.ts` | 字体层级 | `h1=28/36/bold` `body=14/22/regular` `caption=12/16/medium` |
| `shadows.ts` | 阴影系统 | `none` / `sm` / `md` / `lg` / `focus-ring` |
| `radius.ts` | 圆角系统 | `xs=2 / sm=4 / md=8 / lg=12 / pill=9999 / circle=50%` |
| `transitions.ts` | 过渡动画 | `fast=100ms / normal=200ms / slow=350ms` + easing 曲线 |
| `z-index.ts` | 层级系统 | `base=0 / card=10 / dropdown=500 / sticky-header=1000 / modal=2000 / toast=3000 / loading=4000` |
| `breakpoints.ts` | 响应式断点 | `mobile=<768 / tablet=768~1024 / desktop=>1024` |

**语义化表面与前景**

| 变量名 | 用途 | 深色默认 | 浅色默认 |
| --- | --- | --- | --- |

## 二、`[data-theme]` 主题切换机制

### 2.1 切换原理

```
document.documentElement.setAttribute('data-theme', 'light' | 'dark');
```

在 `<html>` 根节点上通过属性选择器覆盖同名 CSS 变量：

```css
/* tokens.css 基础（默认 dark，覆盖整个 app） */
:root {
  --mt-bg-primary: #0f172a;
  --mt-fg-1: #f8fafc;
  /* ... 所有深色令牌 */
}

/* 浅色主题覆盖（同名变量重定义，层叠生效） */
:root[data-theme='light'] {
  --mt-bg-primary: #fffcf6;
  --mt-fg-1: #1f2937;
  /* ... 所有浅色令牌，一一对应，不许缺 */
}
```

### 2.2 切换三要素

| # | 要素 | 实现位置 | 说明 |
| --- | --- | --- | --- |
| 1 | **用户持久化** | Settings 存储 `preferences.theme = 'system' | 'dark' | 'light'` | 支持跟随系统；`system` 模式监听 `prefers-color-scheme` media query |
| 2 | **运行时切换** | `useTheme()` Hook：`setTheme('light')` → 写 localStorage + 改 `documentElement[data-theme]` → 发 IPC 通知 main 托盘图标适配 | 切换瞬间无刷新，CSS 变量层叠秒级生效 |
| 3 | **覆盖完整性** | 主题完整性测试：dark 中定义了 N 个变量，light 也必须定义 N 个；CI 跑 CSS 解析脚本比对——缺一个就报错 | 避免某个组件在浅色下还是深色文字黑底白字灾难 |

## 三、暖奶油浅色系 + 深色主题色板说明

### 3.1 浅色：暖奶油（Warm Cream）

**设计意图**：减少长时间使用的视觉疲劳；白色不扎眼（不是纯 `#ffffff`，带 246/252/255 微暖偏米）；分隔与阴影偏暖色灰。

| 层级 | 色值（HSL） | 对应令牌 | 用途占比 |
| --- | --- | --- | --- |
| 页面背景 最底层 | HSL(45, 60%, 98%) 偏奶油白 | `--mt-bg-primary` | 70% 大面积 |
| 卡片 次级面板 | HSL(42, 55%, 96%) 奶油更浓一点 | `--mt-bg-secondary` | 25% 内容块 |
| 输入/悬停 三级 | HSL(40, 50%, 92%) 更显暖色 | `--mt-bg-tertiary` | 4% 交互元素 |
| 一级文字 | HSL(220, 25%, 17%) 深灰蓝（不是纯黑） | `--mt-fg-1` | 主要文字 |
| 主强调色 | HSL(239, 84%, 67%) 靛蓝 500 | `--mt-color-primary` | 1% 点缀（按钮/链接） |

### 3.2 深色：深蓝灰（Deep Slate）

**设计意图**：OLED 屏幕省电 + 夜间聊天不刺眼；背景不是纯黑避免文字边缘光渗；色偏蓝灰（slate）而非纯灰，和 Agent 人格的「冷静陪伴」定位一致。

| 层级 | 色值 | 令牌 | 占比 |
| --- | --- | --- | --- |
| 页面背景 | `#0f172a` slate-900 | `--mt-bg-primary` | 70% |
| 卡片背景 | `#1e293b` slate-800，+0.05 对比度 | `--mt-bg-secondary` | 25% |
| 三级背景 | `#334155` slate-700 | `--mt-bg-tertiary` | 4% |
| 文字 1 级 | `#f8fafc` slate-50 近白 | `--mt-fg-1` | 主文字 |
| 强调主色 | `#818cf8` indigo-400（比浅色调亮一档，避免黑底看不清） | `--mt-color-primary` | 1% |

### 3.3 色盲友好

- 错误/成功从不只靠颜色区分：必须同时带 ✅ / ❌ 图标 + 文字标签「成功」「失败」
- 主色/警告/危险三色在 Deuteranopia（红绿色盲 8% 男性）模拟下对比度仍 ≥ 4.5:1，所有关键色板已过 Coblis 模拟校验
- 不使用红+绿并排的 diff，用「删除线红色 + 下划线绿色 + 左删除/右添加文字标签」三重冗余

## 四、间距系统、字体层级、圆角/阴影规范

### 4.1 间距系统（4px 基础步长）

**倍数字典**：所有 margin/padding/gap 从下表取值，不得出现 `11px` / `17px` 这种非步长奇数。

| Token | 像素值 | 典型用途 |
| --- | --- | --- |
| `--mt-spacing-3xs` | 2px（0.5 步） | 内部元素微调整（checkbox 对其） |
| `--mt-spacing-2xs` | 4px | 图标 + 文字微间距 |
| `--mt-spacing-xs` | 8px | 列表项内 padding、紧凑卡片内边距 |
| `--mt-spacing-sm` | 12px | 小组件 padding |
| `--mt-spacing-md` | 16px | 标准卡片/页面 padding、组件间间隙 |
| `--mt-spacing-lg` | 24px | 页面区块之间 vertical gap |
| `--mt-spacing-xl` | 32px | Page-container padding、大卡片 gap |
| `--mt-spacing-2xl` | 48px | 大区块分离（首屏 hero 与其他内容） |
| `--mt-spacing-3xl` | 64px | 极端场景，少用 |

### 4.2 字体层级

**字体家族**：
- UI 界面：系统优先栈 `ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` — 中文自动 PingFang/微软雅黑，英文 SF/Roboto
- 代码/JSON：`ui-monospace, "JetBrains Mono", SFMono-Regular, Menlo, Consolas, monospace`

| 层级 | 字号 / 行高 / 字重 | 令牌变量 | 用途 |
| --- | --- | --- | --- |
| Display 大标题 | 36px / 1.2 / 700 | `--mt-font-display` | 首页欢迎、空状态大 emoji 下一行 |
| H1 页面标题 | 28px / 1.3 / 700 | `--mt-font-h1` | PageHeader 的 title |
| H2 区块标题 | 22px / 1.4 / 600 | `--mt-font-h2` | 卡片内 Section 标题 |
| H3 子标题 | 18px / 1.45 / 600 | `--mt-font-h3` | 次级卡片、分组标题 |
| Body 正文 | 14px / 1.6 / 400 | `--mt-font-body` | 大部分文字、对话消息 |
| Body Bold | 14px / 1.6 / 600 | `--mt-font-body-bold` | 列表项关键值、强调 |
| Caption 辅助 | 12px / 1.5 / 500 | `--mt-font-caption` | 时间戳、路径、描述、元数据 |
| Code 内联代码 | 13px / 1.5 / 500 mono | `--mt-font-code` | `<code>` 块、路径、变量名 |

### 4.3 圆角与阴影

**圆角**

| 半径 | 令牌 | 场景 |
| --- | --- | --- |
| `4px` | `--mt-radius-sm` | Badge / Tag / 小按钮 / 输入框 |
| `8px` | `--mt-radius-md` | Card / Modal / 标准按钮（90% 用这个） |
| `12px` | `--mt-radius-lg` | 大卡片、对话框、页面容器圆角 |
| `9999px` | `--mt-radius-pill` | Toggle / Chip / 胶囊按钮 |
| `50%` | `--mt-radius-circle` | Avatar / 图标按钮圆形 |

**阴影**（深色主题下比浅色高 1 档，保证层次可感知）

| 级别 | 阴影定义 | 场景 |
| --- | --- | --- |
| `none` | 0 0 | 平铺按钮、扁平列表项 |
| `--mt-shadow-sm` | `0 1px 2px rgba(0,0,0,0.06)` | 输入框聚焦外发光、小卡片悬停 |
| `--mt-shadow-md` | `0 4px 16px rgba(0,0,0,0.08)` | 标准卡片、dropdown |
| `--mt-shadow-lg` | `0 12px 32px rgba(0,0,0,0.12)` | Modal 对话框、Toast 浮层 |
| `--mt-shadow-focus` | `0 0 0 3px rgba(99,102,241,0.35)` | 聚焦可见键盘焦点环 |

## 五、图标体系：lucide-react 独占、不混用

### 5.1 强制规范

| 规则 | 说明 |
| --- | --- |
| **单一库**：项目图标唯一来源是 `lucide-react`，禁止引入 FontAwesome / AntD icons / Heroicons / 手写 SVG emoji 组合 | 避免同样的「设置」有 3 种不同画风 |
| **命名映射**：组件 `props.icon: LucideIcon` 类型；传 `<Settings />` 而不是字符串 `'settings'`，TS 类型安全 |
| **尺寸系统**：和 spacing 对齐，24px（默认）/ 20px（body）/ 16px（caption）三档；对应 `size={24}` 等 |
| **颜色**：一律 `color="currentColor"` 继承父元素 fg 色；不写死 stroke |
| **禁止自绘 SVG**：特殊业务图标（如 Agent 人格表情、桌宠状态）也要走单独 `src/renderer/components/icons/` 目录，统一尺寸和描边宽度，再导出成 Lucide 风格组件 | 不允许页面组件内随便插一段 `<svg>` |

## 六、可访问性规范（A11y）

### 6.1 ARIA 属性

| 场景 | 要求 |
| --- | --- |
| 无文字图标按钮 | **必须** `aria-label` 或 `aria-labelledby`：`<Button aria-label="关闭对话框" variant="ghost"><XIcon /></Button>` |
| 自定义控件（Switch / Tag 切换） | `role="switch"` / `role="tablist"` + `aria-checked` / `aria-selected` 状态正确 |
| 动态内容区（聊天、列表） | 新增消息容器 `aria-live="polite"`，屏幕阅读器自动朗读新内容但不打断用户 |
| 错误态输入 | `aria-invalid="true"` + `aria-describedby="error-message-id"` 关联错误文字；不要只红框 |
| Modal 对话框 | `role="dialog"`、`aria-modal="true"`、`aria-labelledby={titleId}`；打开时焦点锁在对话框内 |

### 6.2 键盘可达

**操作可达**：所有鼠标可完成的交互，必须纯键盘也可完成。常见组件键盘要求：

- **Button / Link**：Tab 聚焦 → Enter/Space 触发；`:focus-visible` 时显示 focus ring（不被 outline: none 删）
- **Input / Select**：Tab 顺序自然；Enter 提交；Esc 取消当前编辑
- **Modal**：打开时焦点移到第一个可交互元素；Esc 关闭；Tab 不出对话框（焦点陷阱）
- **Dropdown Menu**：↑↓ 选条目 / Enter 选中 / Esc 关闭 / 输入字母首字母跳
- **虚拟列表**：↑↓ / PageUp PageDown / Home End 键盘滚动；aria-rowcount / aria-rowindex 正确

**Tab 顺序要求**：视觉从上到下、从左到右的自然阅读顺序，和 DOM 顺序一致——不要用 CSS order 或 float 打乱 DOM 视觉映射导致 Tab 顺序跳来跳去。

### 6.3 焦点管理

- **全局焦点可见**：`focus-visible` 样式启用 `--mt-shadow-focus` 3px 靛蓝环；不允许 `*:focus { outline: none }`（除非立刻配套替换方案）
- **动作后焦点落点**：Modal 关闭 → 焦点回到打开 Modal 的那个按钮；删除一行 → 焦点回到删除按钮的上一行或下一行；路由切换 → 焦点跳到 PageHeader 的主标题（skip-link）
- **Skip Link**：首屏渲染隐藏的 `<a href="#main-content">跳到主内容</a>`，Tab 第一个可聚焦，屏幕阅读器和键盘用户跳过 17 个导航项直达内容

## 七、交互反馈规范（Hover / Active / Disabled + 骨架屏）

### 7.1 组件三态 + 加载态

| 状态 | 视觉反馈 | 过渡 |
| --- | --- | --- |
| **Rest 静置** | 基础样式 + 鼠标默认 pointer | — |
| **Hover 悬停**（鼠标指针悬停时） | 背景 +5~10% 明度；`translateY(-1px)` 轻微上浮；cursor: pointer | `--mt-transition-fast` 100ms |
| **Active 按下**（鼠标按下/Enter 按下） | 背景加深 5%；`translateY(0)` 回弹回来；按下阴影 | `--mt-transition-fast` 100ms，按下瞬间无过渡 |
| **Focus 键盘聚焦** | 显示 `--mt-shadow-focus` 3px 靛蓝 focus ring（不依赖 Hover） | 0ms 出现，150ms 消失 |
| **Disabled 禁用** | 整体 `opacity: 0.5` + `cursor: not-allowed`；禁止任何点击事件穿透 | — |
| **Loading 加载中** | 按钮/卡片内容透明度 0.7 + 内嵌小 Spinner（不改变组件整体尺寸，避免布局抖动）；按钮文字变成「保存中…」 | — |

### 7.2 骨架屏 Skeleton 使用场景

**优先用 Skeleton 的场景**（比 Loading spinner 好，避免 UI 跳动）：

| 场景 | Skeleton 设计 |
| --- | --- |
| 页面首屏 列表/卡片/表格 | 页面结构轮廓：PageHeader + 4 张卡片骨架 + 10 行列表骨架，和真实数据尺寸 1:1 |
| 对话消息流 | 2~3 条聊天气泡骨架，头像+文字块占位 |
| Dashboard 图表 | 80% 高的灰色渐变矩形 + shimmer 动画（左右扫光），不画假坐标轴 |
| 设置页表单 | 8 行 FormItem：label 占位符 + 输入框占位符 + 按钮占位 |

**Skeleton 加载态持续时间 ≤ 500ms 时不显示**：如果接口非常快（<500ms），闪一下 Skeleton 反而更抖——加 500ms debounce，加载时间短于阈值就直接显示成功态。

### 7.3 全局反馈通道（Toast / Banner / Modal / Tray）

| 通道 | 严重程度 | 示例场景 | 消失策略 |
| --- | --- | --- | --- |
| **Toast**（右上滑入） | 轻度通知 | 保存成功、删除成功、审批通过 | 自动消失：success 2.5s / info 3.5s；warning 和 danger 不自动消失（除非用户 × 掉） |
| **ErrorBanner**（页头下，红色） | 页面级错误，不阻断其他操作 | 「加载记忆失败，点击重试」 / 「权限不足」 | 手动关闭 + 错误解决后自动消失 |
| **Modal 对话框**（阻断性） | 必须用户决策 | 删除确认、审批 L2 详情、Schema 迁移确认 | 只有按钮关闭，不点击遮罩关（Esc 也要加确认） |
| **托盘通知**（桌面通知） | Agent 主动消息 L1（用户 120s 未交互才发） | 「Agent 学会了新能力」「同步完成 12 条变更」 | 系统自动关闭；同时记录到 AutonomousPage 可回看 |
