2商品描述（直接复制）

【核心功能】
· 导出格式：HTML（图片内嵌，单文件）、PDF、Excel/CSV、Markdown、JSON
· 按会话、时间段、关键词导出；不指定会话就是全库搜索
· 媒体导出：图片、文件、语音 wav，语音可转文字
· 群文件清单：标出正常、同名不同版本、已过期
· 批量归档：先预演，只拷贝不删除、不覆盖，可反复跑
· 空间分析：按会话、文件类型、月份拆分占用
· 统计报表：消息类型、活跃时段、发言人分布
· 其他：增量导出、按月拆分、多会话批量导出

【适用场景】
离职交接、项目存档、发给律师或同事看、对账找记录、换电脑前抢救文件、整理文件传输助手。

【优势】
· HTML 单文件，图片全在里面，换台电脑打开不掉图
· 只读，不修改 WX 数据；归档只做拷贝
· 过期文件提前提醒；过期后任何工具都救不回来
· CSV 中文不乱码，以等号开头的内容会被转义

【定制服务】
离职交接包、群日报/周报、聊天记录转话术库或知识库、图片文字检索、公司格式导出模板。

【发货与安装】
闲鱼聊天窗口发安装包和图文教程。Win10/11 64 位，WX 电脑版需登录并运行。

【拍前须知】
· 只导出本机已有的内容，手机上没同步的不在
· 没在电脑上点开过的图片、视频，本地多半没有
· 导出文件可修改，不能替代公证或司法鉴定
· 虚拟商品，发货后不退不换

5拍前问答话术

买家问这样回
能导出成什么格式？HTML、PDF、Excel 表格、Markdown、JSON，五种都行。
图片会丢吗？会内嵌进网页文件，单个文件发给别人也能看。附件太大就单独放文件夹，会提前说明。
能只导某几句话吗？可以，按关键词筛，不记得在哪个会话也能全库找。
会删我电脑里的东西吗？不会，只读、只拷贝，代码里没有删除操作。
手机上的记录能导吗？只整理这台电脑上已有的内容，手机上没同步过来的不在。
能便宜点吗？标价就是实价，单套已经压得比较低了。可以先拍基础版试。

7内部备注（不要发给买家）

最好卖的三个点：单文件 HTML 不掉图、按关键词只导命中、文件过期预警。主图和前三行描述就讲这三个，别铺功能清单。
「导出」这个词本身可用，但标题优先用「整理 / 归档」，命中率更稳。
买家拿导出记录去举证时，主动说明「本机文件可修改，不能替代公证」，别接「能当证据」的话。
