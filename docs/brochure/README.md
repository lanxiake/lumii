## 让你的 AI，看懂、管好、用上你电脑里的微信

**双击安装 · 大白话提问 · 数据不出电脑 · 不改微信一个字节**

你每天在微信里聊客户、收文件、存资料，可这些东西 **AI 一个字都读不到**：
聊天记录是加密的，图片是加密的 `.dat`，语音是 SILK 编码，文件散在几十个目录里，
撤回的消息转眼就没了。

这四件套把你本机这份微信变成 AI 能直接用的工具。装进你已经在用的 AI 客户端
（Claude Code、Cursor、Codex、Gemini CLI、VS Code 等 14 款，安装时方向键勾选），
然后像跟助理说话一样提问就行。

```
你：看看我有哪些消息还没回
你：把和张三的聊天记录导出来，图片也要
你：哪些客户我很久没联系了？
你：群里刚才撤回的那句是什么？
```

## 四款产品，按需选购

| 产品 | 一句话 | 适合谁 | 王牌功能 |
|---|---|---|---|
| **本机微信助手**<br>`wechat-mcp` | AI 帮你**读消息、听语音、看图片、以你的身份回消息** | 消息多、回不过来的人；想让 AI 学你说话的人 | 锁屏也能发，发前五道校验，发后读库确认 |
| **微信导出与文件归档**<br>`wechat-export-mcp` | 聊天记录**一键导出**成 HTML / Markdown / JSON；群文件**趁没过期**批量存下来 | 需要存档、取证备份、交接工作的人；文件多到找不到的人 | 单个 HTML 文件内嵌全部图片，发给谁都不掉图；过期文件提前预警 |
| **微信客户分析**<br>`wechat-crm-mcp` | 通讯录、群成员、互动排行、**谁很久没联系**；一次调用看清一个客户 | 销售、微商、自由职业者、做私域的人 | 自动找出「客户问了、你没回」的那句话 |
| **微信撤回防护**<br>`wechat-recall-mcp` | 后台自动留档，对方撤回后**原文照样查得到** | 群多、消息多、怕错过关键信息的人 | 不改微信、不装插件，撤回前就存好了 |

**组合建议**

- **个人效率**：本机微信助手 + 撤回防护——消息不漏看、不漏回、撤回也能查。
- **销售 / 私域**：客户分析 + 本机微信助手——先找出该跟进的人，再让 AI 起草回复。
- **存档 / 交接**：导出与文件归档 + 撤回防护——文字、文件、撤回内容全部留在自己电脑上。
- **全都要**：四件套共用同一套读取引擎，口径一致，数字对得上。

## 为什么选它：六个硬核卖点

### 1. 零注入，不碰微信客户端

不打补丁、不挂钩子、不往微信进程里塞任何东西。读取靠本机数据库 + 只读内存取密钥；
发消息走 Windows 窗口消息和系统无障碍接口（UI Automation），**和你自己用键盘打字是同一条路**。
市面上「注入 DLL」一派的工具在 2025 年的封号潮里损失惨重，这条路我们一开始就不走。

### 2. 数据全在本机，不上传任何服务器

图片在本机解密、语音在本机转写（本地语音识别模型，音频不出电脑）、画像存在本机 Markdown 文件里，
连有效期校验都是离线的。**工具本身不向任何地方发送你的聊天内容。**

### 3. 双击即装，不用敲命令

拿到 `wechat-*.exe` 双击，向导会先讲清楚它是什么，再让你用方向键勾选要装到哪些 AI 客户端。
自动写好配置、拷好技能包，重启客户端就能用。不需要装 Python、不需要配环境、不需要授权码。

### 4. 支持新版微信 4.x

本机微信 **4.1.15.x** 已真机验证：取密钥、解密、读取、发送全部实测通过。
遇到未验证的版本**不会悄悄读错**，每条结果都会附上醒目提示，让你先抽查再用。

### 5. 出错就说清楚，绝不假装成功

所有失败都给出统一格式的原因与建议（`ok / error_code / detail / suggestion`）。
「名字没对上」和「真的没数据」分得清清楚楚；图片是缩略图就告诉你是缩略图；
文件过期了就告诉你救不回来。**宁可说「做不到」，也不编。**

### 6. 你的 AI 客户端，它都能接

Claude Code、Claude Desktop、Cursor、Codex、Gemini CLI、Qwen Code、OpenCode、Zed、
VS Code、Copilot CLI、Cline、Roo Code、Trae、Warp——标准 MCP 协议，一次安装多端可用。

## 三步上手

1. **双击** `wechat-*.exe`，按向导用方向键勾选要装到哪些 AI 客户端（不用打字）。
2. **重启**你的 AI 客户端。
3. **开问**：「看看我有哪些没回的消息」「把这个群上个月的记录导出来」。

> 装完请**不要移动或删除 exe**——客户端配置里记的就是它当前的位置。想换位置，在新位置再双击一次即可。
> 撤回防护需要多做一步：开启后台守护（`--install-autostart`），详见它的说明书。

## 常见问题

**Q：会不会封号？**
A：我们**不承诺「零封号」**，任何这样承诺的都不可信。我们能做到的是把风险降到这条路上最低：
不注入、不改客户端、读取完全只读、发送默认只预演不真发。真正的高风险行为是**群发、高频固定间隔发送、
自动加好友、新号跑自动化**——四件套**不提供自动加好友**，群发功能请谨慎使用。建议先用小号试用。

**Q：我的聊天记录会被上传吗？**
A：工具本身不上传任何内容。但请注意：如果你接入的是云端大模型（如在线版 Claude / ChatGPT），
你问 AI 的问题和它读到的内容会发送给那家模型厂商——这一层由你选择的 AI 客户端决定。

**Q：需要微信一直开着吗？**
A：需要。密钥只在运行中的微信进程里，微信要**已登录并在运行**。刚启动、还没点开过任何会话时可能取不到密钥，
点开一个会话等几秒就好。

**Q：支持手机微信、Mac 微信吗？**
A：目前只支持 **Windows 电脑版微信 4.x**，读的是你这台电脑上的数据。

**Q：图片、视频为什么有些拿不到？**
A：微信只会把你**点开过**的图片和视频下载到电脑上（实测 48 条视频消息只有 8 条本地有文件）。
在微信里点开一次，之后再搜、再导就有了。工具会如实告诉你哪些本地没有，不会拿别的顶替。

**Q：有使用期限吗？**
A：每个 exe 在构建时写入到期日，到期后会明确返回「已过期」并告诉你怎么办，可用 `--expiry-status` 随时查看剩余天数。
不需要联网激活，也不需要授权码。

## 购买须知（请务必阅读）

1. **协议风险**：《腾讯微信软件许可及服务协议》8.2.1.6 禁止通过第三方软件对微信进行自动化访问、读取或控制。
   使用本产品**可能违反你与腾讯之间的协议**，是否使用由你自行判断。
2. **只限本人自用**：只能读取**你自己账号、你自己电脑**上的数据，读不了别人的微信。请勿用于监控他人、
   批量导出客户信息转卖或骚扰营销。
3. **三件事我们一件都不做**：破解上传聊天记录、上传通讯录到云端、控制微信自动加好友——
   2024 年有企业正因这三件事被市场监管部门罚款 10 万元。
4. **隐私责任**：聊天内容涉及他人隐私，请只在合法、正当的场景使用；是否交给云端模型分析，请自行评估。
5. **不是法律证据**：导出和留档文件存在你本机，可以被修改，**不能替代公证或司法鉴定**。需要法律效力请走公证并保留原始设备。
6. **运行环境**：Windows 10/11 + 微信电脑版 4.x（已验证 4.1.15.x），微信需登录并运行。
