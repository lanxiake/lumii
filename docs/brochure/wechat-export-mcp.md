## 聊天记录一键导出，群文件过期前帮你存下来

**【一个文件带走】** 导出单个 HTML，图片全部内嵌，发给谁、换台电脑打开都不掉图
**【五种格式】** HTML 给人看、PDF 打印存档、Excel 表格（CSV）、Markdown 存档、JSON 给 AI 分析（附统计报表）
**【只导你要的】** 按关键词只导出提到「发票」「合同」的那几条，不知道在哪个群也能全库搜
**【文件不过期】** 列出所有群文件，标出哪些快没了、哪些已经没了，一键批量归档
**【空间看得懂】** 微信占了几个 G？哪个群、哪种文件、哪个月占的，一张表说清

---

## 你是不是也这样？

- 微信自带的导出只有加密备份，**不能看、不能挑、不能导出**，只能整体恢复到另一台设备；
- 用截图存聊天记录，长对话**截几十张**，还没有日期；
- 用别的工具导出 HTML，发给同事打开**全是裂图**——图片其实在旁边的文件夹里；
- 群里的合同、报价单当时看了一眼，一周后要用，弹出**「文件已过期或已被清理」**；
- 微信占了几十个 G，**不敢清**，怕清掉的正是要用的。

## 核心卖点

### 卖点 1：单个 HTML，图片内嵌，换台电脑也不掉图

```
你：把这个群上个月的记录弄成能发给别人看的样子
AI：已导出 D:\导出\<会话名>\chat.html（单个文件，12 张图片已内嵌）
```

| 同一个会话，不同导出方式（本机实测） | 体积 |
|---|---|
| Markdown 纯文字 | **53 KB** |
| HTML + 图片内嵌 | **797 KB**，仍然是**一个文件** |

797 KB 的文件直接拖进微信发给别人，对方双击就能看，**不用连同一个文件夹一起发**。
跨天的地方自动生成日期目录，点击即可跳转。
合并转发、引用、转账、视频号、拍一拍、群公告都会渲染成看得懂的样子，不是一行「未知消息」。

**要打印、要盖章存档？直接导 PDF。** 同一份页面交给电脑自带的 Edge 打印，图片照样在里面：

> 本机实测：文件传输助手 394 条 + 图片 → **一个 1.2 MB 的 PDF**，约 7 秒。

**要进 Excel 做表？导 CSV。** 一条消息一行（时间 / 发送者 / 类型 / 内容 / 附件 / 语音转写），
Excel、WPS 双击就开，**中文不乱码**；以 `=` 开头的聊天内容会自动转义，不会被当成公式执行。

### 卖点 2：导出给 AI 分析，自带统计报表

选 JSON 格式，除了全部消息，还附一份 `stats.json` 统计报表：

> 本机实测 384 条记录：文本 330、文件 20、链接 15、图片 12、引用 5、语音 2；
> 跨 54 天、其中 29 天有消息；10 月最集中（358 条）；最忙的一天 119 条；
> 另有按小时、按星期、按发言人的分布。

几千条记录直接塞给 AI 又贵又慢。先看报表知道「这段对话集中在哪几天、谁在说」，再决定读哪一段。
报表**只有计数，不做任何主观判断**。

### 卖点 3：按关键词只导你要的部分

```
你：把提到「发票」的记录都导出来，我要对账
AI：已导出 D:\导出\张三\q-发票\chat.json（只含命中的消息）
```

不知道在哪个会话提的？不指定会话就是**全库搜**：

> 本机实测：搜「图片」→ 扫描 **72** 个会话，**42** 个有命中，按命中数导出前几个，
> 另生成一份 `index.md` 清单，耗时 **3.2 秒**。

命中太多被截断时会明确标记 `truncated`，不会让你把「被截断」当成「就这么多」。

### 卖点 4：文件过期预警，趁还来得及

```
你：我那些群里哪些文件已经下不动了？
AI：157 条文件消息里，9 条已经过期，3 条磁盘上是同名的另一个版本……
```

微信里的文件只是缓存，过期后服务器端也没了，**任何工具都救不回来**。
本工具能做的是**在过期之前告诉你**——把「永久损失」变成「赶紧下载」。

每个文件都标出状态：

| 状态 | 意思 | 你该做什么 |
|---|---|---|
| `ok` | 本地有，大小和消息记录完全一致 | 可以归档 |
| `size_mismatch` | 本地有同名文件，但大小对不上，可能是另一版本 | 人工确认 |
| `missing` | 本地没有，已过期或没下载过 | 还没过期就赶紧在微信里点开 |

### 卖点 5：批量归档，先看计划再动手

```
你：能下的都归档到 D:\wechat-backup
AI：（预演）共 20 个，将拷贝 18 个，重复 2 个，过期 0 个——此刻一个文件都还没动
你：可以
AI：已归档到 D:\wechat-backup\文件传输助手\files\，18 个文件
```

- **只拷贝，不移动、不删除**，微信里照样能打开；
- **绝不覆盖**：已归档的同一份文件自动跳过，同名不同版本另存带时间戳的名字；
- **可以反复跑**：只补新增的，不重复、不毁掉已有成果；
- 归档几百个文件时实时显示进度，不用盯着转圈猜是不是卡死了。

### 卖点 6：「微信怎么这么占地方」，答案能直接拿来做决定

| 本机实测 | 大小 |
|---|---|
| 微信账号目录总共 | **1.47 GB** |
| 其中聊天记录数据库 | **只有 67 MB** |
| 收发的文件 | **896 MB** |
| 其中只被一个会话引用（删了真能省） | **455 MB** |
| 被多个会话共用（删一处不一定省） | **281 MB** |
| 没有任何消息引用的「孤儿文件」 | **160 MB** |
| 最占地方的文件类型 | `.exe` 安装包，**581 MB** |

**清理聊天记录根本省不了多少空间，占地方的九成是文件和媒体。**
工具只报告、不删除任何东西，清不清由你决定。

## 功能清单（7 个工具）

| 功能 | 工具 | 说明 |
|---|---|---|
| 找会话 | `list_sessions` | 按关键词找到确切的会话名 |
| 导出预览 | `preview_export` | 先看会导出多少条、多大、哪些会话命中，**不写文件** |
| 导出聊天记录 | `export_chat` | 格式：`md` / `html` / `json` / `csv`（Excel）/ `pdf`<br>媒体：`none` / `images` / `files` / `all`（图片 + 文件 + 语音 wav）<br>按关键词导出、全库搜、按时间段、按月拆分、语音转写、`incremental` 只导新增 |
| 批量导出 | `batch_export` | 一次导出多个会话，逐条报告成功/失败 |
| 文件清单 | `list_files` | 按会话、时间、扩展名、文件名筛选；`only_missing` 只看已过期的 |
| 文件归档 | `archive_files` | 按会话 / 按类型 / 平铺三种摆放方式，默认先预演 |
| 空间分析 | `disk_usage` | 按目录、会话、扩展名、月份拆分占用 |

**导出后能看到的账目**——导不出来的东西，工具会分开告诉你原因：

| 计数 | 意思 | 你能做什么 |
|---|---|---|
| `image_no_key` | 图片在磁盘上，但缺解密密钥 | 在微信里随便点开一张图，再导一次 |
| `image_missing` | 原图本地根本没有 | 无法补救 |
| `file_missing` | 文件过期或没下载 | 没过期就去微信点开一次 |
| `file_dup` | 同一份文件被多次发送，只收一份 | 无需处理 |
| `inline_fallback` | 有图片因超过体积上限没能内嵌 | 需要连 `assets/` 文件夹一起发 |

## 整齐的目录结构

导记录、归档文件写进同一棵目录树，同一份文件只存一次：

```
D:\导出\
  index.md                ← 一次导出多个会话时的清单
  文件传输助手\
    chat.html             ← 正文（md / html / json / csv / pdf）
    stats.json            ← 统计报表（任何格式都有）
    assets\               ← 图片、语音
    files\                ← 文件附件 + 归档的文件
    q-发票\chat.json      ← 按关键词导出
    2026-09\chat.html     ← 按月拆分
```

## 常见问题

**Q：过期的文件能帮我恢复吗？**
A：不能，任何工具都不能。过期后服务器端也没有了。网上流传的「改手机日期恢复」已被微信员工辟谣。
本工具的价值是**在过期之前提醒你**。

**Q：为什么有些图片导不出来？**
A：分两种：一种是缺解密密钥（在微信里点开任意一张图就能修好），另一种是原图本地根本没有（没救了）。
工具会分开计数，告诉你该不该再试一次。

**Q：附件为什么不内嵌进 HTML？**
A：一个 174 MB 的安装包内嵌进去会变成 232 MB 的文本，浏览器直接卡死。所以图片内嵌、文件单独存放，这是刻意的设计。

**Q：导出的记录能当法律证据吗？**
A：不能替代公证。导出文件存在你本机，可以被修改。需要法律效力时请走公证或司法鉴定，并保留原始设备。

**Q：会删我微信里的东西吗？**
A：不会。导出和归档都是只读，归档只做拷贝；空间分析只报告，代码里没有任何删除操作。

**Q：语音转写需要什么？**
A：需要本机装好语音识别模型。没装也不影响导出，语音会逐条跳过并计数。

**Q：导 PDF 需要装什么？**
A：不用另装。Windows 自带的 Edge 就能打印；万一电脑上没有 Edge / Chrome，会退回同内容的 HTML 并告诉你原因，
用浏览器打开后自己「打印 → 另存为 PDF」即可。

## 购买须知

- **运行环境**：Windows 10/11 + 微信电脑版 4.x（已验证 4.1.15.x），微信需登录并运行。
- 导出的是**你本机这份数据**：手机上有、电脑上没同步的部分不在里面；没在电脑上点开过的图片、视频多数不在本地。
- 全库搜一次最多导出 20 个会话（可调），超出部分会如实报数。
- 关键词只匹配文字和附件名，**不识别图片里的文字**。
- 图片、视频不在文件归档范围内（空间分析只报它们的总体积）。
- 导出和归档的内容含他人隐私，请自行妥善保管；是否交给云端 AI 分析，请自行评估。
- 更多风险说明见总册 [`README.md` 的「购买须知」](README.md#购买须知请务必阅读)。
