## 个人微信也有自己的客户管理：该跟进谁、他在聊什么、哪句你没回

**【找人】** 通讯录、群成员、互动排行一键列出，2712 个联系人不用一屏屏翻
**【标签】** 直接读你在微信里打的标签：「标了『客户』的都有谁」一句话列出，还能导成 Excel 表
**【分层】** 30 / 60 / 90 天没联系的人自动分层，连「从没说过话」的人也单独列出
**【看人】** 一次调用看清一个客户：谁更主动、回复多快、最近在聊什么
**【补漏】** 自动找出「客户问了、你 24 小时没回」的那句话
**【可信】** 只给事实和数字，不编「客户健康分」，判断留给你

## 你是不是也这样？

- 通讯录几千人，**谁多久没联系了**，微信从来不告诉你；
- 想看某个群里都有谁，成员列表**翻不动、导不出**；
- 好友打了一堆标签，想把「客户」标签下的人**拉个清单**，微信里只能一个个点；
- 要见一个三个月没聊的客户，得**翻半小时聊天记录**回忆上次聊到哪；
- 客户问了价格，你当时在忙没回，后来**双方都忘了**——一单就这么丢了；
- 企业微信的 SCRM 一年几千上万，**还管不到你的个人微信**。

## 核心卖点

### 卖点 1：沉默分层，看见那些「快要失去」的人

```
你：哪些人很久没联系了？
AI：30 天内有互动 117 人，31–60 天没联系 54 人……
    通讯录里还有一大批人从没说过一句话。
```

| 本机实测 | 人数 |
|---|---|
| 30 天内有互动 | **117** |
| 31–60 天没联系 | **54** |
| 通讯录总量 | **2712** |

真正有过互动的只有 **171** 人，其余约 **2540** 人躺在通讯录里**从没说过话**。
按「会话」统计的工具永远看不见他们，这里按「人」统计，所以看得见：
私聊没说过话、但在群里冒过泡的人也会被识别出来；一句话都没说过的人单独列成一组。

分层刻度默认 30 / 60 / 90 天（可自定义），和成熟 SCRM 的「沉睡客户」口径一致。

### 卖点 2：一次调用，看清一个客户

```
你：张三最近什么情况？我有没有漏掉什么？
AI：614 条消息，来往 127 段；
    他主动开场 83 次，你 44 次；
    你回他中位 52 秒，他回你 50 秒；
    他最近常聊：模型、报价、发货……
    他问过 44 个问题，其中 1 个你 24 小时内没回。
```

| 客户简报包含 | 有什么用 |
|---|---|
| 来往几段、**每段谁先开口** | 谁在主动，是关系里最难伪装的一个数 |
| 双方回复速度（中位数） | 这段关系的节奏是不是对等 |
| 消息类型分布 | 只发文件的客户和爱聊天的客户，沟通方式不一样 |
| 对方高频词 | 他最近在关心什么 |
| **没接的问句** | 唯一能直接变成行动的一项 |

**以前要手工翻半小时，现在一句话。**

### 卖点 3：找出「问了没答」的活口

客户问了价、问了交期，你当时没回，消息被后面的对话压下去，双方都忘了。
客户简报会把「对方提问后 24 小时内你一条都没发」的句子捞出来，直接给你原文位置。

> 判断依据是句子形态（问号、「吗 / 多少 / 能不能」等疑问词），**它告诉你「这像在提问」，不替你猜「他在催你」**。

### 卖点 4：会话 × 时间段 × 关键词，随意组合搜索

```
你：他提过报价吗？
AI：在张三的会话里找到 14 条。
你：只看上个月的
AI：……
你：全微信里谁提过「模型」？
AI：全库 130 条。
```

微信搜索框做不到「某个人在某段时间说过的所有话」，这里三个条件自由组合，不指定会话就是整个微信。
读原文按时间正序返回，图片、语音、引用都显示成看得懂的摘要。

### 卖点 5：通讯录、群成员、标签，一键列清还能导成表格

```
你：我有哪些客户群？
AI：共 35 个群，名字含「客户」的有……
你：XX 企业群里都有谁？
AI：成员清单如下（含群内称呼）……
你：我标了「家长」的都有谁？导成表格给我
AI：「家长」标签下 57 人，已导出 D:\导出\通讯录_家长.csv
```

联系人分为好友、群、公众号、企业微信，分类按账号特征精确判断，可复现、可核对。
群成员清单**包含你自己**，人数和微信里数出来的一致。

**读得到你在微信里打的标签**：每个联系人都带上标签，可以按标签筛人。
任何清单（某个标签、某个群、某类联系人）都能**一次性导成 Excel 表格**（显示名 / 备注 / 微信号 / 标签），
不受每页 200 条的限制——离职交接、整理客户名单直接用。

### 卖点 6：只给事实，不编分数

市面上很多工具喜欢给一个「客户健康度 72 分」——看着专业，其实是把假设包装成事实。
本产品**只给原始时间、条数和原文**：数得出来的才给，数不出来的不编。
「这个客户值不值得跟」交给你和你的 AI 来判断。

## 功能清单（8 个工具）

**通讯录面**（只统计时间和条数，**不读聊天正文**）

| 工具 | 做什么 |
|---|---|
| `list_contacts` | 列好友 / 群 / 公众号 / 企业微信，或某个群的成员；可按标签筛；默认每次 200 条可翻页，也可**整份导成 Excel 表格** |
| `list_labels` | 你打过的全部标签，以及每个标签下有几个人 |
| `contact_stats` | 单个会话的条数、我发 / 对方发、活跃时段、活跃天、沉默天数 |
| `silence_ladder` | 按人分层：多久没联系、从没说过话的人 |
| `interaction_rank` | 按会话排行：聊得最多的、最久没联系的 |

**消息面**（读聊天正文，只在你提问时读）

| 工具 | 做什么 |
|---|---|
| `customer_brief` | 一次看清一个客户：主动性、回复速度、话题、没接的问句 |
| `read_messages` | 按时间段读某个会话的原文 |
| `search_messages` | 会话 × 时间段 × 关键词组合搜索 |

两面共用同一套读取引擎，**数字对得上**：客户简报说的 614 条，和互动排行榜首的 614 条是同一个数。

## 一套完整的客户跟进流程

```
① 找人     silence_ladder()            → 谁很久没联系了
② 看量     contact_stats(张三)          → 多少条、几点最活跃、沉默几天
③ 看摘要   customer_brief(张三)         → 谁主动、回复速度、在聊什么、哪句没回
④ 看原文   read_messages / search_messages → 那几句话的原文
⑤ 做决定   交给你或你的 AI               → 该跟谁说话、该补哪句
```

多数「XX 最近什么情况」到第 ③ 步就够了，不用先读几百条原文。
想让 AI 直接起草跟进消息？搭配 [本机微信助手](wechat-mcp.md) 使用。

## 常见问题

**Q：会读我的聊天内容吗？**
A：分两面说。通讯录面（列联系人、统计、分层、排行）**一个字的正文都不读**，只看时间和条数；
消息面（客户简报、读原文、搜索）**会读正文**，只在你提问时读，只在本机处理，不外传。

**Q：能按标签筛选好友吗？**
A：能。读的就是你在微信里打的标签（本机实测 5 个标签、87 人，和微信里一致）。标签名说错了，
工具会把你现有的全部标签列出来让你挑，不会返回一个「0 人」糊弄过去。只读，不会改你的标签。

**Q：群成员的群昵称为什么有些是空的？**
A：因为那个人在这个群里没设过群昵称（本机实测只有 9.6% 的人设过）。空就是没设过，工具不会拿全局昵称冒充。

**Q：能自动提醒我「某人三个月没联系了」吗？**
A：工具本身不会主动推送，它是被调用的。可以在 AI 客户端里设置定时任务，定期跑一次沉默分层。

**Q：能用来批量导出客户手机号、群发营销吗？**
A：不建议，也不提供。导出的表格只有显示名、备注、微信号和标签，**不含手机号**。整理自己的人脉是一回事，
批量导出客户信息再群发是另一回事——后者有企业因此被罚款 10 万元，
也有机构因批量导出客户手机号触发风控、账号被冻结。

## 定制服务

标准版给的是「清单 + 数字 + 原文」；下面这些**按你的业务定做**，同样只在你电脑上运行：

| 定制方向 | 交付什么 | 适合谁 |
|---|---|---|
| **群接龙 → 订单表** | 自动识别群里的接龙、报单消息，汇总成 Excel 订单表（商品 / 数量 / 收货人），每天一份 | 团购团长、社区店、微商 |

| **离职交接** | 客户名单表 + 每位客户的往来摘要 + 未完成事项，一份交接包 | 销售、客服换岗 |

## 购买须知

- **运行环境**：Windows 10/11 + 微信电脑版 4.x（已验证 4.1.15.x），微信需登录并运行。
- **只读**：不发送、不修改、不删除任何微信数据；不自动加好友；不上传通讯录。
- 读正文、搜索、简报都有扫描上限，撞到上限时会明确标记 `truncated`（没扫完），不会让你把部分结果当全部。
- 单条正文超过 400 字会截断并标出全文长度。
- 高频词按两个字切分，是「线索」不是「主题清单」，会出现一些碎片词。
- 通讯录和聊天内容涉及他人隐私，请只用于整理本人人脉，不得用于监控他人或骚扰营销。
- 更多风险说明见总册 [`README.md` 的「购买须知」](README.md#购买须知请务必阅读)。
