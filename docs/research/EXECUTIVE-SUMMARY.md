# Lumii Agent UI 优化方案 - 执行总结

**日期**: 2026-10-23  
**推荐行动**: 立即启动 Phase 1 (MVP)  
**投资回报**: 用户体验 +30% / 开发成本 7 人天

---

## 现状

### 问题 1: Agent 执行过程"黑盒"
用户提问后，只能等待。看不到 Agent 在做什么，何时完成，为什么失败。

**对标**: Cursor AI、Claude.ai 都能实时显示进度。

### 问题 2: 产出物缺预览
生成的图片、视频、表格都要打开多个窗口才能看。影响用户体验。

**对标**: CopilotKit 的产出物就地展示（不需要打开新窗口）。

### 问题 3: 看不到 Agent 团队进度
多个 Agent 并行执行时，用户无法看清谁在做什么。

**对标**: Flowise、LangChain 都有可视化看板。

---

## 解决方案 (一页纸总结)

### Phase 1: 快速赢 (2 周，7 人天) ⭐⭐⭐⭐⭐

#### 方案 A: 任务进度增强 (3 天)
```
改动前                      改动后
┌─────────────────┐        ┌──────────────────────────┐
│ ✓ 生成视频     │        │ 🎬 生成视频 (3/7 中)    │
│ 已完成 2:34    │   →    │                          │
│ 产出 1        │        │ [████░░░░] 42%           │
└─────────────────┘        │ 处理第 3 个场景          │
                           │                          │
                           │ 📋 日志 (5 条) [展开]   │
                           │ [14:23:15] ✓ 模型加载   │
                           │ [14:24:45] ⚠ GPU 85°C   │
                           │                          │
                           │ [中止] [导出日志]       │
                           └──────────────────────────┘
```

**收益**: 用户知道 Agent 在做什么，还要等多久。

#### 方案 B: 结果预览面板 (4-5 天)
```
产出物类型          预览方式              快捷操作
─────────────────────────────────────────────────
图片                Lightbox (缩放)       [下载] [分享]
视频                HTML5 播放器          [下载] [分享]
表格                可排序的 Table        [导出 CSV] [查看图表]
代码                语法高亮 + 行号       [复制] [在编辑器打开]
Markdown            富文本渲染           [复制] [导出 PDF]
```

**收益**: 不用打开多个窗口，产出物就地看和用。

## 技术要点

### 不需要新依赖
- 使用现有的 React + 样式系统
- 图表库选择 Plotly (成熟、功能全)
- 代码高亮用 Prism (轻量)

### 向后兼容
- 扩展现有的 `BackgroundTask` 类型，不改现有字段
- 新旧 UI 并存，渐进式迁移
- 降级方案：旧版本仍然可用

### 性能设计
- 虚拟滚动处理 100+ 日志条目
- 代码分割减少初始加载
- 轮询 500ms 平衡实时性和成本
