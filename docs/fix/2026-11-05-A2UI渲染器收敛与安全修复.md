# A2UI 渲染器收敛与安全修复

> 2026-11-05 · 涉及 `apps/windows/src/renderer/components/A2UIRenderer/`、`parseA2UIBlocks.ts`、`ChatMessage/index.tsx`、`main/ipc/agent-runtime-ipc.ts`、`packages/agent-runtime/src/prompt/`

## 一、为什么动它：实测「一次都没被用起来」

只读查询 `~/.lumii/data/agent-runtime.db`（2026-11-05，10,125 条消息 / 5,396 条 assistant）：

| 指标 | 数值 |
|---|---|
| 含 ` ```a2ui ` 围栏的消息 | **0** |
| 含 `"components":[` 的消息 | **0** |
| 含 `"chartType"` / `"datasets"` | **0 / 0** |
| `a2ui_guide` 被暴露的回合 | 175 / 525 |
| `a2ui_guide` 实际调用次数 | **0** |
| 对照组：markdown 表格 | 1,169 条消息（21.7%） |
| 对照组：`image_generate` | 210 次 |

根因不是「不需要」，是**入口被注释掉了**：

- `packages/agent-runtime/src/prompt/system-prompt-builder.ts` 里 `buildA2UISection` 的调用被注释（"效果不好，待优化后重新启用"）；
- `misc-sections.ts` 的 FileOutput 段里 FilePreview 的示例整段注释；
- 剩下的唯一指针是工具描述一句话，没有「什么时候用 / 什么时候不该用」。

### P1 健壮性

| 问题 | 修复 |
|---|---|
| `Chart` 对字段类型零校验（`labels` 写字符串即 `labels.map is not a function`） | 新增 `validate.ts` 统一收窄，类型不对整块丢弃 |
| `DataTable` 同样无校验，`pageSize=0` 得 `Infinity` | 同上 + 钳制 pageSize ∈ (0,200] |
| 嵌套 `Card.components` / `List.items` 类型错直崩 | 这两个容器组件一并删除 |
| `ensureComponentIds` 每次 parse 生成新 UUID ⇒ 子树 key 变化 ⇒ Table 排序/页码每次重置 | 改为按最终下标重写 `c0/c1/...`，稳定且唯一 |
| `A2UI_REGEX` 无 `i` 标志 ⇒ ` ```A2UI ` 不识别 | 加 `gi` |
| `ARTIFACT_REGEX` 要求语言后必换行且 `\w+` ⇒ 同行写法 / `vue-sfc` 漏掉 | 放宽为 `[\w-]+` |
| 重叠判断只处理「完全被包含」，部分重叠会重复入列 | 改为 `overlapsAnyMatch` 双向判断 + 渲染前 `index < lastIndex` 兜底 |
| 超 16KB 的消息完全跳过 A2UI 解析（图表静默消失） | 仅对**含可渲染围栏**的 assistant 长回答解除闸门 |
| `parseA2UIBlocks` 未 memo，每次重渲染重跑 4 条全局正则 | `useRef` 内容缓存 |
| 模型输出大数组可卡死主线程 | 限 Chart ≤2000 点 / Table ≤5000 行×50 列 / 消息 ≤20 组件 |
| 用户/系统消息走同一路径，粘贴的 ` ```html ` 会被执行 | 非 assistant 只渲染 markdown，且 `buildMarkdownComponents(richBlocks=false)` |

### 图形语义

- 散点图原先复用类目数据，X 轴是类目名 ⇒ 不是散点图；改为数值型 `{x: 下标, y: 值}`。
- 饼图原先只取 `datasets[0]`，多数据集静默丢数据；改为按数据集逐张绘制。

## 三、收敛结果

保留 **Chart / DataTable** 两类（唯一有真实需求、且无更强既有替代的）。删除 10 类：

| 删除 | 替代 |
|---|---|
| FilePreview | `FilePreviewModal`（pdf/docx/xlsx/pptx/代码全支持）+ 独立预览窗 |
| Image / AudioPlayer / VideoPlayer | Markdown 图片 + `ImageLightbox`；媒体 chip |
| Text / Card / List / Divider | markdown |
| MathVisualizer | KaTeX（13 条真实使用） |
| Button | 无回传通道，无价值 |

同时移除依赖 `mafs`（仅 MathVisualizer 使用）。

## 四、提示词入口

- `buildA2UISection` 重新接入 `system-prompt-builder`，`PromptSectionId` 新增 `"a2ui"`，`PROMPT_SECTIONS` 注册（terse 走 `a2ui_guide`）。
- 文案从**能力清单**改成**选择规则**：只有「图表」或「需要排序/筛选/分页的表」才用；≤4 行的小表和一次性罗列用 markdown；文件绝不用 A2UI。
- `a2ui_guide` 工具的返回值同步收缩到两类组件 + 规模上限 + 选择规则；删掉会诱导模型走坏路径的 FilePreview 示例。
- `A2UI_GUIDE_CONTENT` 同步改写。
