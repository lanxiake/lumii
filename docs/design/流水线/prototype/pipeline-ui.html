✓ 引擎做插件

com.lumii.pipeline，hot: true。停用后工具与页面同时消失，spec 文件保留。

✕ 每条流水线不做插件

一条 = 一个 JSON 文件放进 workspace/pipelines/。若做成插件，就要 manifest + apply + 构建 + 激活时机，直接击穿「不高于 skill」。

★ 随工作区走 git

spec 与 skills 同根，天然被工作区 VCS 跟踪；runs/ 进忽略清单，不污染历史。
