## 关键设计决策

### 1. Elo Rating K 值 = 32

**原因**：快速收敛，适合 Agent 能力评估

**权衡**：K 值过大会导致评级波动，过小收敛慢

### 2. 置信度衰减因子 = 20

**原因**：20 次测试达到 63% 置信度，平衡速度和准确性

**公式**：`confidence = 1 - e^(-testCount / 20)`

### 3. 能力缺口优先级 = demand × gap

**原因**：高需求 + 大缺口 = 高优先级

**示例**：需求 0.8，缺口 0.3 → 优先级 0.24

### 4. 反思使用 claude-opus-5, temperature 0.3

**原因**：
- Opus 5 是最强模型，适合复杂分析
- 低温度确保输出稳定和可靠

### 5. 每日目标上限提升到 5

**原因**：P1 新增 capability-improvement 目标类型，需要更多配额
