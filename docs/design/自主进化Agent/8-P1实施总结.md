## 核心算法验证

### Elo Rating 更新公式

```
expected = 1 / (1 + exp(-10 * (currentLevel - difficulty)))
actual = { 1.0: success, 0.5: partial, 0.0: failure }
newLevel = currentLevel + K * (actual - expected)
```

**测试案例**：
- 初始水平：0.6
- 任务难度：0.5
- 结果：success
- 期望概率：`1 / (1 + exp(-10 * 0.1)) ≈ 0.731`
- 新水平：`0.6 + 0.32 * (1.0 - 0.731) ≈ 0.686` ✅

### 置信度公式

```
confidence = 1 - exp(-testCount / λ)
λ = 20
```

**测试案例**：
- 20 次测试 → 置信度 ≈ 0.63 ✅
- 60 次测试 → 置信度 ≈ 0.95 ✅

### 能力缺口优先级

```
priority = demand × gap
demand = recentTestCount / CAPABILITY_DEMAND_WINDOW_DAYS
gap = max(0, desiredLevel - currentLevel)
desiredLevel = avg(taskDifficulty) over recent tests
```

**测试案例**：
- 维度 A：10 次测试，level=0.5，desiredLevel=0.8 → priority=0.3×10=3.0
- 维度 B：2 次测试，level=0.5，desiredLevel=0.8 → priority=0.3×2=0.6
- 维度 A 优先级更高 ✅
