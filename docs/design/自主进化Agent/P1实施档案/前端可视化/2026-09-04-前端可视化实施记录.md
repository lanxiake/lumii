## 🔧 集成方式

### 1. 导入组件

```typescript
// 在仪表板页面中导入
import { CapabilityRadar } from '../../components/CapabilityRadar/CapabilityRadar'
import { CapabilityProgressBar } from '../../components/CapabilityProgressBar/CapabilityProgressBar'
import { ReflectionCard } from '../../components/ReflectionCard/ReflectionCard'
import { SatisfactionChart } from '../../components/SatisfactionChart/SatisfactionChart'
import { PromptVariantStats } from '../../components/PromptVariantStats/PromptVariantStats'
```

### 2. 加载数据

```typescript
// 在 AutonomousPage 组件中
const [capabilities, setCapabilities] = useState({})
const [reflections, setReflections] = useState([])
const [satisfactionHistory, setSatisfactionHistory] = useState([])

async function loadData() {
  const [capabilitiesData, reflectionsData, historyData] = await Promise.all([
    autonomousApi.getCapabilities(),
    autonomousApi.getReflections(5),
    autonomousApi.getSatisfactionHistory('7d'),
  ])
  setCapabilities(capabilitiesData)
  setReflections(reflectionsData)
  setSatisfactionHistory(historyData.dataPoints)
}
```

### 3. 渲染组件

```typescript
// 能力雷达图
<CapabilityRadar capabilities={capabilities} />

// 能力进度条（遍历所有维度）
{Object.entries(capabilities).map(([dim, state]) => (
  <CapabilityProgressBar key={dim} dimension={dim} {...state} />
))}

// 反思卡片（遍历所有反思）
{reflections.map((reflection) => (
  <ReflectionCard key={reflection.id} reflection={reflection} />
))}

// 满意度趋势图
<SatisfactionChart history={satisfactionHistory} window="7d" />
```

## 🎯 设计亮点

### 1. 无依赖绘图

所有图表组件（雷达图、趋势图）均使用 Canvas 原生 API 绘制，避免了引入 Recharts、ECharts 等大型库，减小打包体积。

### 2. 模块化设计

每个组件独立封装，接口清晰，易于维护和扩展。可以单独使用，也可以组合使用。

### 3. 响应式布局

所有组件都适配不同屏幕尺寸，支持 Canvas 自适应缩放，确保在不同设备上都能正常显示。

### 4. 交互友好

- 雷达图：清晰的图例说明
- 进度条：趋势指示和动画效果
- 反思卡片：展开/收起交互
- 趋势图：鼠标悬停提示
- 变体统计：折叠展开

### 5. 颜色编码

- 红色系：问题诊断
- 蓝色系：改进建议
- 绿色系：建议目标
- 灰色系：中性信息

### 6. 渐变背景

反思卡片使用渐变背景，视觉层次分明，区分不同内容区域。
