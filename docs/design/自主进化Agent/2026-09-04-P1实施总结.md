## 一、实施范围

### 1.1 核心功能

✅ **能力边界检测（Capability Boundary Detection）**
- 使用 Elo Rating System 动态追踪 Agent 在 8 个维度的能力水平
- 识别能力缺口（当前水平 vs 期望水平）
- 生成基于能力提升的学习目标

✅ **自我反思（Self-Reflection）**
- 定时触发深度反思（每日 23:00）
- 使用 LLM 分析满意度低的根本原因
- 生成结构化反思输出（问题诊断 + 改进建议）

✅ **与 P0 集成**
- 能力追踪器正确记录测试、更新评级
- 反思引擎生成改进建议
- 目标生成器支持第三类目标（capability-improvement）
- 每日目标上限提升到 5

## 四、核心算法验证

### 4.1 Elo Rating System

✅ **算法一致性**
- K 值 = 32（与设计文档一致）
- Logistic 函数：`P = 1 / (1 + e^(-10 × (level - difficulty)))`
- 更新公式：`newLevel = level + K × (actual - expected)`
- 边界约束：[0, 1]

✅ **测试覆盖**
- 预期表现计算正确（level = difficulty 时为 0.5）
- 成功任务提升能力水平
- 失败任务降低能力水平
- 置信度随测试次数饱和增长

### 4.2 能力缺口识别

✅ **算法正确性**
- 期望水平 = 0.5 + demand × 0.5（上限 0.9）
- 优先级 = demandFrequency × gap
- 按优先级降序排序

✅ **测试覆盖**
- 正确识别高需求维度的缺口
- 优先级排序正确
- 需求频率分析准确

### 4.3 反思引擎

✅ **LLM 集成**
- 使用 claude-opus-5 模型
- 温度 0.3（低温度确保稳定）
- 结构化 JSON 输出
- 正确解析和验证

✅ **数据脱敏**
- 会话摘要不包含用户消息原文
- 仅保留元数据（时间戳、满意度、工具数、错误数）
