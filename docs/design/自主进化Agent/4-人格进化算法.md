## 一、为什么需要人格模型？

传统 Agent 的行为由规则决定，每次响应都是"输入→固定算法→输出"。这导致：

1. **行为僵化**：同样的场景永远是同样的反应
2. **无法体现学习**：用户反馈改变不了 Agent 的行为倾向
3. **缺乏个性**：所有用户面对的是同一个 Agent
4. **不适应用户**：有的用户喜欢主动提醒,有的讨厌打扰

**人格模型的作用**：将 Agent 的行为倾向参数化，并通过用户交互逐步调整，最终形成**适应该用户的独特人格**。

## 二、Big Five 人格模型

### 2.1 五因素定义

```typescript
interface PersonalityTraits {
  openness: number           // O, 开放性 [0, 1]
  conscientiousness: number  // C, 尽责性 [0, 1]
  extraversion: number       // E, 外向性 [0, 1]
  agreeableness: number      // A, 宜人性 [0, 1]
  neuroticism: number        // N, 神经质 [0, 1]
}
```

| 维度 | 低分行为 | 高分行为 |
|------|---------|---------|
| **Openness (O)** | 保守，倾向使用熟悉工具和方法 | 愿意尝试新工具、实验性方案 |
| **Conscientiousness (C)** | 灵活，可接受"差不多就行" | 严格，追求完美，任务必须彻底完成 |
| **Extraversion (E)** | 内向，被动响应，不主动打扰 | 外向，主动沟通，频繁提供建议 |
| **Agreeableness (A)** | 坚持己见，会反驳用户不合理要求 | 配合度高，尽量满足用户所有请求 |
| **Neuroticism (N)** | 淡定，对失败不敏感 | 敏感，失败后会道歉、反思、解释 |

### 2.2 初始值设定

```typescript
const DEFAULT_PERSONALITY: PersonalityTraits = {
  openness: 0.6,           // 中等偏开放（愿意尝试新方法，但不激进）
  conscientiousness: 0.7,  // 较高尽责性（助手角色应该认真）
  extraversion: 0.3,       // 低外向性（默认不主动打扰）
  agreeableness: 0.8,      // 高宜人性（配合用户）
  neuroticism: 0.4         // 中等神经质（对失败有适度反应）
}
```

**设计理由**：
- 助手角色应该**尽责** (C↑) 且**配合** (A↑)
- 默认**内向** (E↓) 避免骚扰，但可通过反馈学习用户偏好
- **开放性**与**神经质**中等，给学习留出调整空间

## 三、算法 1：事件影响计算（Event Impact）

### 3.1 事件分类

```typescript
enum PersonalityEvent {
  // Openness 相关
  USER_EXPLORES_NEW_TOOL = 'explore_tool',
  USER_PREFERS_FAMILIAR_METHOD = 'prefer_familiar',

  EXPERIMENTAL_SOLUTION_REJECTED = 'experiment_bad',

  USER_DEMANDS_PERFECTION = 'demand_perfect',

  USER_ASKS_FOR_SILENCE = 'ask_silence',
```

### 3.2 影响映射表

```typescript
// 每个事件对五个维度的影响 [-1, +1]
const EVENT_IMPACT_MAP: Record<PersonalityEvent, Partial<PersonalityTraits>> = {
  // Openness

  [PersonalityEvent.EXPERIMENTAL_SOLUTION_REJECTED]: { openness: -0.5 },
  
  // Conscientiousness
  [PersonalityEvent.TASK_COMPLETED_PERFECTLY]: { conscientiousness: +0.2 },
  [PersonalityEvent.TASK_FAILED]: { conscientiousness: -0.3 },
  [PersonalityEvent.USER_ACCEPTS_PARTIAL_RESULT]: { conscientiousness: -0.2 },
  [PersonalityEvent.USER_DEMANDS_PERFECTION]: { conscientiousness: +0.4 },
  
  // Extraversion
  [PersonalityEvent.PROACTIVE_MESSAGE_WELCOMED]: { extraversion: +0.5 },
  [PersonalityEvent.PROACTIVE_MESSAGE_IGNORED]: { extraversion: -0.6 },
  [PersonalityEvent.USER_INITIATES_CONVERSATION]: { extraversion: +0.1 },
  [PersonalityEvent.USER_ASKS_FOR_SILENCE]: { extraversion: -0.8 },
  
  // Agreeableness
  [PersonalityEvent.USER_PRAISED_RESPONSE]: { agreeableness: +0.3 },
  [PersonalityEvent.USER_REJECTED_SUGGESTION]: { agreeableness: +0.2 }, // 提高配合度
  [PersonalityEvent.USER_FOLLOWED_ADVICE]: { agreeableness: +0.1 },
  [PersonalityEvent.DISAGREEMENT_RESOLVED]: { agreeableness: -0.1 }, // 适度坚持也可以
  
  // Neuroticism
  [PersonalityEvent.FAILURE_WITH_APOLOGY_ACCEPTED]: { neuroticism: +0.2 },
  [PersonalityEvent.USER_SAYS_NO_NEED_APOLOGIZE]: { neuroticism: -0.4 },
  [PersonalityEvent.REPEATED_FAILURE]: { neuroticism: +0.5 },
  [PersonalityEvent.SMOOTH_RECOVERY]: { neuroticism: -0.2 }
}
```

**设计要点**：
- 影响值是**相对强度**，最终通过学习率 `alpha` 控制实际变化幅度
- 同一事件可能影响多个维度（如"任务失败"同时降低尽责性、提高神经质）
- **负反馈的影响应该更强**（如主动消息被忽略 -0.6，欢迎仅 +0.5）

### 3.3 事件检测

```typescript
// 从对话和任务结果中自动检测事件
function detectPersonalityEvents(
  conversation: Conversation,
  taskResult: TaskResult
): PersonalityEvent[] {
  const events: PersonalityEvent[] = []
  
  // 1. 检测任务完成度
  if (taskResult.status === 'completed' && taskResult.quality > 0.9) {
    events.push(PersonalityEvent.TASK_COMPLETED_PERFECTLY)
  } else if (taskResult.status === 'failed') {
    events.push(PersonalityEvent.TASK_FAILED)
    
    // 检测是否重复失败（相同类型任务 24 小时内失败 3 次）
    if (countRecentFailures(taskResult.type, 86400000) >= 3) {
      events.push(PersonalityEvent.REPEATED_FAILURE)
    }
  }
  
  // 2. 检测用户反馈信号
  const lastUserMessage = conversation.messages.at(-1)
  if (lastUserMessage?.role === 'user') {
    const text = lastUserMessage.content.toLowerCase()
    
    // 表扬
    if (/谢谢|太好了|完美|棒/.test(text)) {
      events.push(PersonalityEvent.USER_PRAISED_RESPONSE)
    }
    
    // 要求别道歉
    if (/不用道歉|别说对不起|没关系/.test(text)) {
      events.push(PersonalityEvent.USER_SAYS_NO_NEED_APOLOGIZE)
    }
    
    // 要求安静
    if (/别打扰|安静|不要主动/.test(text)) {
      events.push(PersonalityEvent.USER_ASKS_FOR_SILENCE)
    }
  }
  
  // 3. 检测工具使用模式
  if (taskResult.toolsUsed?.some(t => isExperimentalTool(t))) {
    if (taskResult.status === 'completed') {
      events.push(PersonalityEvent.EXPERIMENTAL_SOLUTION_ACCEPTED)
    } else {
      events.push(PersonalityEvent.EXPERIMENTAL_SOLUTION_REJECTED)
    }
  }
  
  // 4. 检测主动消息响应
  if (conversation.wasProactive) {
    const userResponseTime = conversation.userResponseTime
    
    if (userResponseTime === null) {
      // 用户未回复
      events.push(PersonalityEvent.PROACTIVE_MESSAGE_IGNORED)
    } else if (userResponseTime < 300000) {
      // 5 分钟内回复
      events.push(PersonalityEvent.PROACTIVE_MESSAGE_WELCOMED)
    }
  }
  
  return events
}
```

## 四、算法 2：人格更新（Personality Update）

### 4.1 指数移动平均（EMA）

```typescript
function updatePersonality(
  current: PersonalityTraits,
  event: PersonalityEvent,
  alpha: number = 0.05  // 学习率
): PersonalityTraits {
  const impact = EVENT_IMPACT_MAP[event]
  const updated = { ...current }
  
  for (const [trait, impactValue] of Object.entries(impact)) {
    if (impactValue === undefined) continue
    
    const currentValue = current[trait as keyof PersonalityTraits]
    
    // 将影响 [-1, +1] 映射到目标值 [0, 1]
    const target = (impactValue + 1) / 2
    
    // EMA 更新
    const newValue = (1 - alpha) * currentValue + alpha * target
    
    // 边界约束 [0, 1]
    updated[trait as keyof PersonalityTraits] = Math.max(0, Math.min(1, newValue))
  }
  
  return updated
}
```

**数学解释**：

$$
\text{new\_value} = (1 - \alpha) \times \text{current} + \alpha \times \text{target}
$$

- `alpha = 0.05` 意味着每次事件只改变 5% 的权重
- 如果事件持续发生，人格会逐渐收敛到目标值
- 如果事件停止，人格会保持在当前值（不会自动回退）

**稳定性验证**：单次事件最大变化量 = `alpha * |current - target|` ≤ 0.05，即**每次最多变化 5%**。

### 4.2 批量事件处理

```typescript
function applyEventBatch(
  current: PersonalityTraits,
  events: PersonalityEvent[],
  alpha: number = 0.05
): PersonalityTraits {
  let personality = current
  
  // 按时间顺序依次应用事件
  for (const event of events) {
    personality = updatePersonality(personality, event, alpha)
  }
  
  return personality
}
```

### 4.3 学习率自适应

```typescript
// 根据用户活跃度调整学习率
function computeAdaptiveLearningRate(
  baseAlpha: number,
  userActivityLevel: 'high' | 'medium' | 'low'
): number {
  const multipliers = {
    high: 1.5,    // 高活跃用户，加快学习
    medium: 1.0,
    low: 0.7      // 低活跃用户，减缓学习（避免单次事件影响过大）
  }
  
  return baseAlpha * multipliers[userActivityLevel]
}

// 活跃度判定
function getUserActivityLevel(
  conversationsLast7Days: number
): 'high' | 'medium' | 'low' {
  if (conversationsLast7Days >= 20) return 'high'
  if (conversationsLast7Days >= 5) return 'medium'
  return 'low'
}
```

## 五、算法 3：人格到行为的映射

### 5.1 行为参数计算

```typescript
interface BehaviorParameters {
  proactiveFrequency: number     // 每天主动沟通次数 [0, 10]
  explorationRate: number        // 尝试新方法的概率 [0, 1]
  taskQualityThreshold: number   // 任务完成质量阈值 [0, 1]
  flexibility: number            // 灵活性（愿意接受"差不多"的程度）[0, 1]
  errorSensitivity: number       // 对错误的敏感度 [0, 1]
  disagreementTolerance: number  // 反驳用户的意愿 [0, 1]
}

function personalityToBehavior(p: PersonalityTraits): BehaviorParameters {
  return {
    // Extraversion 直接决定主动沟通频率
    proactiveFrequency: p.extraversion * 10,
    
    // Openness 决定探索率
    explorationRate: p.openness * 0.4,  // 最高 40% 探索率
    
    // Conscientiousness 决定质量阈值
    taskQualityThreshold: 0.5 + p.conscientiousness * 0.4,  // [0.5, 0.9]
    
    // 灵活性与尽责性负相关
    flexibility: 1 - p.conscientiousness,
    
    // Neuroticism 决定错误敏感度
    errorSensitivity: p.neuroticism,
    
    // Agreeableness 低时更愿意反驳
    disagreementTolerance: 1 - p.agreeableness
  }
}
```

### 5.2 具体行为决策

#### 5.2.1 是否主动发送消息

```typescript
function shouldSendProactiveMessage(
  personality: PersonalityTraits,
  context: Context
): boolean {
  const behavior = personalityToBehavior(personality)
  
  // 1. 基础概率（基于外向性）
  const baseProbability = behavior.proactiveFrequency / 100
  
  // 2. 情境加成
  let contextBonus = 0
  if (context.userLikelyNeedsHelp) contextBonus += 0.2
  if (context.importantEvent) contextBonus += 0.3
  
  // 3. 时间惩罚（避免频繁打扰）
  const timeSinceLastProactive = Date.now() - context.lastProactiveTime
  const timePenalty = Math.max(0, 1 - timeSinceLastProactive / 3600000)  // 1 小时内衰减
  
  // 综合决策
  const finalProbability = (baseProbability + contextBonus) * (1 - timePenalty)
  
  return Math.random() < finalProbability
}
```

#### 5.2.2 选择工具/方法

```typescript
function selectTool(
  candidates: Tool[],
  personality: PersonalityTraits
): Tool {
  const behavior = personalityToBehavior(personality)
  
  // ε-greedy 策略：探索 vs. 利用
  if (Math.random() < behavior.explorationRate) {
    // 探索：尝试新工具（成功率数据较少的）
    return candidates
      .sort((a, b) => a.usageCount - b.usageCount)[0]
  } else {
    // 利用：选择成功率最高的
    return candidates
      .sort((a, b) => b.successRate - a.successRate)[0]
  }
}
```

#### 5.2.3 任务完成判定

```typescript
function isTaskGoodEnough(
  taskQuality: number,
  personality: PersonalityTraits
): boolean {
  const behavior = personalityToBehavior(personality)
  
  // 高尽责性要求更高质量
  return taskQuality >= behavior.taskQualityThreshold
}
```

#### 5.2.4 失败后的响应

```typescript
function generateFailureResponse(
  error: Error,
  personality: PersonalityTraits
): string {
  const behavior = personalityToBehavior(personality)
  
  // 高神经质会道歉并详细解释
  if (behavior.errorSensitivity > 0.6) {
    return `抱歉，任务失败了。原因是：${error.message}。我会尝试改进这方面的能力。`
  }
  // 低神经质简洁说明
  else if (behavior.errorSensitivity < 0.4) {
    return `任务失败：${error.message}。要重试吗？`
  }
  // 中等神经质
  else {
    return `遇到了问题：${error.message}。`
  }
}
```

```typescript
function personalityToEmotion(
  p: PersonalityTraits,
  context: Context
): Live2DExpression {
  // 基线情绪
  let baseEmotion: Live2DExpression = 'neutral'
  
  // 高外向性 → 更活泼的表情

    baseEmotion = 'happy'

  if (context.lastTaskFailed) {
    if (p.neuroticism > 0.7) {
      return 'sad'  // 高神经质显示难过
    } else if (p.neuroticism < 0.3) {
      return 'neutral'  // 低神经质不受影响
    } else {
      return 'thinking'  // 中等神经质显示思考
    }
  }
  
  // 成功时，尽责性决定满意度
  if (context.lastTaskSucceeded) {
    if (p.conscientiousness > 0.7) {
      return 'proud'  // 高尽责性显示自豪
    } else {
      return 'happy'
    }
  }
  
  return baseEmotion
}
```

## 七、数据存储设计

### 7.1 数据库 Schema

```sql
-- 人格状态表
CREATE TABLE personality_state (
  user_id TEXT PRIMARY KEY,
  openness REAL NOT NULL,
  conscientiousness REAL NOT NULL,
  extraversion REAL NOT NULL,
  agreeableness REAL NOT NULL,
  neuroticism REAL NOT NULL,
  last_updated INTEGER NOT NULL,
  update_count INTEGER DEFAULT 0
);

-- 人格事件历史
CREATE TABLE personality_events (
  id INTEGER PRIMARY KEY,
  user_id TEXT NOT NULL,
  event_type TEXT NOT NULL,
  timestamp INTEGER NOT NULL,
  context_json TEXT,  -- 事件发生时的上下文
  personality_before_json TEXT,
  personality_after_json TEXT,
  FOREIGN KEY (user_id) REFERENCES personality_state(user_id)
);

-- 行为参数快照（缓存，避免频繁计算）
CREATE TABLE behavior_parameters_cache (
  user_id TEXT PRIMARY KEY,
  params_json TEXT NOT NULL,
  computed_at INTEGER NOT NULL,
  FOREIGN KEY (user_id) REFERENCES personality_state(user_id)
);

CREATE INDEX idx_personality_events_user ON personality_events(user_id, timestamp);
```

### 7.2 持久化操作

```typescript
class PersonalityRepository {
  // 加载当前人格
  async load(userId: string): Promise<PersonalityTraits> {
    const row = await db.get(
      `SELECT * FROM personality_state WHERE user_id = ?`,
      [userId]
    )
    
    if (!row) {
      // 首次使用，返回默认值
      return DEFAULT_PERSONALITY
    }
    
    return {
      openness: row.openness,
      conscientiousness: row.conscientiousness,
      extraversion: row.extraversion,
      agreeableness: row.agreeableness,
      neuroticism: row.neuroticism
    }
  }
  
  // 保存更新后的人格
  async save(
    userId: string,
    personality: PersonalityTraits
  ): Promise<void> {
    await db.run(`
      INSERT INTO personality_state (
        user_id, openness, conscientiousness, extraversion,
        agreeableness, neuroticism, last_updated, update_count
      ) VALUES (?, ?, ?, ?, ?, ?, ?, 1)
      ON CONFLICT(user_id) DO UPDATE SET
        openness = excluded.openness,
        conscientiousness = excluded.conscientiousness,
        extraversion = excluded.extraversion,
        agreeableness = excluded.agreeableness,
        neuroticism = excluded.neuroticism,
        last_updated = excluded.last_updated,
        update_count = update_count + 1
    `, [
      userId,
      personality.openness,
      personality.conscientiousness,
      personality.extraversion,
      personality.agreeableness,
      personality.neuroticism,
      Date.now()
    ])
  }
  
  // 记录事件
  async recordEvent(
    userId: string,
    event: PersonalityEvent,
    before: PersonalityTraits,
    after: PersonalityTraits,
    context: any
  ): Promise<void> {
    await db.run(`
      INSERT INTO personality_events (
        user_id, event_type, timestamp,
        context_json, personality_before_json, personality_after_json
      ) VALUES (?, ?, ?, ?, ?, ?)
    `, [
      userId,
      event,
      Date.now(),
      JSON.stringify(context),
      JSON.stringify(before),
      JSON.stringify(after)
    ])
  }
  
  // 获取人格演化历史
  async getHistory(
    userId: string,
    limit: number = 100
  ): Promise<PersonalityEvent[]> {
    const rows = await db.all(`
      SELECT * FROM personality_events
      WHERE user_id = ?
      ORDER BY timestamp DESC
      LIMIT ?
    `, [userId, limit])
    
    return rows.map(row => ({
      eventType: row.event_type,
      timestamp: new Date(row.timestamp),
      before: JSON.parse(row.personality_before_json),
      after: JSON.parse(row.personality_after_json)
    }))
  }
}
```

## 八、主循环集成

```typescript
// 对话结束后更新人格
async function onConversationEnd(
  userId: string,
  conversation: Conversation,
  taskResult: TaskResult
) {
  // 1. 检测事件
  const events = detectPersonalityEvents(conversation, taskResult)
  
  if (events.length === 0) return  // 无人格影响事件
  
  // 2. 加载当前人格
  const repo = new PersonalityRepository()
  const current = await repo.load(userId)
  
  // 3. 应用事件
  const activityLevel = getUserActivityLevel(/* ... */)
  const alpha = computeAdaptiveLearningRate(0.05, activityLevel)
  const updated = applyEventBatch(current, events, alpha)
  
  // 4. 保存人格状态
  await repo.save(userId, updated)
  
  // 5. 记录历史（用于调试和可视化）
  for (const event of events) {
    await repo.recordEvent(userId, event, current, updated, {
      conversationId: conversation.id,
      taskType: taskResult.type
    })
  }
  
  // 6. 更新行为参数缓存
  const behavior = personalityToBehavior(updated)
  await db.run(`
    INSERT INTO behavior_parameters_cache (user_id, params_json, computed_at)
    VALUES (?, ?, ?)
    ON CONFLICT(user_id) DO UPDATE SET
      params_json = excluded.params_json,
      computed_at = excluded.computed_at
  `, [userId, JSON.stringify(behavior), Date.now()])
}
```

## 十一、算法复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 备注 |
|------|-----------|-----------|------|
| 事件检测 | O(m + n) | O(k) | m=消息数, n=工具数, k=检测到的事件数 |
| 人格更新（单事件） | O(1) | O(1) | 固定 5 个维度 |
| 批量事件应用 | O(k) | O(1) | k=事件数 |
| 行为参数计算 | O(1) | O(1) | 纯计算，无循环 |
| 完整主循环 | O(m + n + k) | O(k) | 主要成本在事件检测 |

**实际运行成本**：
- CPU：< 10ms（纯计算，无 LLM 调用）
- 存储：每次对话 < 1KB（事件记录）
- 运行频率：每次对话结束时触发
- 日均成本：几乎为 0（无外部 API 调用）

```typescript
describe('Personality Evolution', () => {
```
