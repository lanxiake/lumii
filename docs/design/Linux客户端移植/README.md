## 阅读顺序

1. 先读调查分析的 §0（结论摘要）与 §0.1（已确认决策）；
2. 再读第一期设计的 §0（结论摘要）与 §1（范围与决策），它增量更新了调查分析的决策；
3. 动手前读第一期设计的 §3（M0 构建环境）——**构建环境不可用是当前第一阻塞项**。
