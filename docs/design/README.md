## 相关约定

- **设计文档必填章节**（结论摘要、方案对比、核心设计、安全风险、分期与退出标准等）见 [`../wiki/05-implementation/01-开发流程与规范.md`](../wiki/05-implementation/01-开发流程与规范.md) §1.2。
- **命名**：过程性设计文档用 `YYYY-MM-DD-中文名.md`；成系列的用 `NN-中文名.md`（如 [`自主进化Agent/`](自主进化Agent/) 的 1–11）。
- **参考项目**：外部开源项目的解构分析收在 [`记忆与Wiki/参考项目/`](记忆与Wiki/参考项目/) 下，每个项目一个目录（`设计解构.md` + `源码/README.md`）。
- 2026-08-04 ～ 08-10 期间设计与计划曾同放 `plans/`；2026-08-13 之后设计统一落在本目录。
