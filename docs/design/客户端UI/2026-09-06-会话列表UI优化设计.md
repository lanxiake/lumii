# 会话列表 UI 优化设计

**日期：** 2026-09-06  
**状态：** 已确认，进入实现

## 目标

提升侧栏会话列表的选中态与 Agent 运行中态辨识度，并按参考图改为精简单行交互。

## 决策摘要

- **信息密度：** 单行（左状态图标 + 标题；悬停/选中右侧 `···`）
- **状态表达：** 左侧图标驱动（默认空心圆 / 选中实心圆 / 运行中旋转 Loader）
- **操作入口：** `···` 与右键共用置顶 / 重命名 / 删除菜单；去掉行内直出按钮
- **去掉：** 预览文案、常驻时间、左侧发光竖条、标题旁 status 小圆点

## 状态矩阵

| 状态 | 左侧 | 行背景 |
|------|------|--------|
| 默认 | 空心圆 | 透明 |
| 选中 | 实心强调色圆 | 胶囊高亮 |
| 运行中 | Loader2 旋转 | 透明（或极淡强调） |
| 选中+运行中 | Loader2 旋转 | 胶囊高亮 |
| 置顶 | 标题前小 Pin | 同上 |

时间写入 `title` tooltip，不常驻显示。`prefers-reduced-motion` 下 Loader 停转，改为静态强调色圆点。

## 非目标

不改会话数据模型、`isStreaming` 数据源、IPC、侧栏 tab/搜索/分组逻辑；不新增「添加到项目 / 移到分组」。
