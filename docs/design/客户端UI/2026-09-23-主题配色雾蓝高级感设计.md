**日期**：2026-09-23

**Figma（初稿，色相已转向雾蓝，以代码为准）**：[Lumii Theme Palette](https://www.figma.com/design/jqR0gDalNsu9is9nBBssu8)

> 曾探索鼠尾草（Sage）方案；拍板改为 **低饱和雾蓝**，保留「双温并存 + 强调色同源」。

## 1. 目标

- 三主题表面温度分工清晰，同一产品气质
- 强调色同源（约 HSL **215°** 雾蓝），只调明度/饱和；护眼不再用琥珀分叉
- 比旧版 `#3b82f6` / `#2a76f6` 更克制、适合长读
- 浅色微暖石、护眼米黄纸、深色冷石板
