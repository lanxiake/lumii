# Wiki 设置页 UI / 交互重设计

日期：2026-08-27  
范围：设置 → 记忆管理 → Wiki Tab（不改其他记忆 Tab）  
目标：更直观、简单、美观；日常浏览优先；操作进度可观测  

## 1. 背景与问题

当前 `WikiTab` 为左栏扁平导航 + 右栏多视图互斥切换：

- 内容分区（资料 / 多媒体 / 待整理）与运维工具（运行日志 / 清理 / 综述 / 图谱 / 重建索引）同级，主次不清
- 打开页面后列表被替换，返回路径弱
- 状态多为英文枚举（如 `pending`）
- 归档、清理、合成、重建等长任务缺少统一、可持续观测的进度界面

## 2. 设计目标与约束

| 决策 | 选择 |
|---|---|
| 主场景 | 浏览优先；整理 / 运维分层下沉 |
| 打开页面 | 详情侧滑覆盖主内容，底层列表保留 |
| 进度观测 | 顶栏轻量 pill + 可点开完整任务中心 |
| 工具入口 | 图谱留在左栏一级；清理 / 综述 / 重建进入「⋯ 更多」 |
| 视觉 | 沿用现有设计令牌，Wiki 区做同体系升级（密度、状态色、空状态） |

不在本设计范围：改变 Wiki 后端能力、记忆注入开关、其他记忆 Tab、清理/合成内部算法。

## 3. 方案选择

采用 **邮件式双栏 + 详情侧滑**：

- 左：一级浏览分区 + 图谱；底部分隔后「⋯ 更多」
- 中：当前分区列表；顶栏含搜索与任务进度 pill
- 叠加：详情侧滑、任务中心抽屉、更多菜单

备选（未采用）：工作台双模式（与「图谱同级」冲突）；Notion 式全屏文档（与设置页密度差过大）。

## 4. 信息架构

```
记忆管理 → Wiki
└─ Wiki 工作区
   ├─ 顶栏：搜索 | 分区标题 | [任务进度 pill]
   ├─ 左导航
   │  ├─ 资料 / 多媒体 / 待整理(角标) / 知识图谱
   │  └─ ⋯ 更多 → 清理 | 综述合成 | 重建索引（唯一入口）
   ├─ 主内容：列表 | 待整理 | 图谱全页 | 清理/合成全页
   └─ 叠加层：详情侧滑 | 任务中心抽屉 | 更多菜单
```

导航原则：

1. 一级只放浏览分区、图谱、更多入口
2. 原「运行日志」并入任务中心历史，不再占左栏
3. 待整理点开后主区显示待办列表（不用侧滑）
4. 重建索引触发后不跳全页，只进入任务进度流

## 5. 关键界面

### 5.1 主列表（资料 / 多媒体）

- 行：标题 · 路径或类型标签 · 一行摘要（可选）· 相对时间
- 选中态：左侧指示条；侧滑打开时保持选中
- 空状态：短文案说明自动归档来源；不堆操作按钮
- 搜索：顶栏触发，结果替换主列表，提供「清除搜索」；点结果开侧滑

### 5.2 待整理

- 状态中文 + 色点：待处理 / 处理中 / 失败（禁止直接展示英文枚举）
- 失败行可展开：原因、重试次数；行内「重试」「丢弃」
- 本版不做批量操作

### 5.3 详情侧滑

- 宽度约主内容区 60–70%；窄窗全宽
- 顶：标题 · 版本/更新时间 · 编辑 / 删除 · 关闭
- 中：Markdown 预览；编辑态保留 live 编辑、拖拽附件、`[[` 补全
- 反链 / 修订历史默认折叠摘要，展开看全量
- 关闭：关闭按钮、Esc、点击遮罩
- 删除：确认框，保留反链数量提示

### 5.4 任务进度

**顶栏 pill**

- 无任务：隐藏
- 进行中：如 `归档中 3/12`、`重建索引…`；多任务时 `2 个任务进行中`
- 刚完成：短暂成功态约 3s
- 失败：红点常驻，直至用户打开任务中心查看

**任务中心抽屉**

分段：进行中 → 最近完成 → 失败。打开时默认落在最高优先级有内容段：失败 > 进行中 > 最近完成。

| 操作 | 进度形态 |
|---|---|
| 归档（inbox → pages） | 确定进度 `已处理/总数` |
| 清理 | 分阶段：扫描 → 执行 |
| 综述合成 | 不确定进度 + 当前目标标题 |
| 重建索引 | 不确定进度 |
| 图谱长任务（bootstrap / extract） | 不确定进度 |

进行中项可「查看关联」跳到待整理或对应页面。失败项在可重试时提供「重试」，否则「忽略」。历史归档 run 明细沿用现有 result detail 结构，以中文 outcome 展示。

### 5.5 ⋯ 更多

| 菜单项 | 行为 |
|---|---|
| 清理 | 主区切到清理全页 |
| 综述合成 | 主区切到合成全页 |
| 重建索引 | 立即触发；顶栏 pill + 任务中心 |

菜单项可附一行极短说明。

### 5.6 知识图谱

- 左栏一级；主区全宽展示
- 点节点打开详情侧滑（底层为图谱）
- 长任务走任务中心；图谱页仅轻量「运行中」条

## 6. 视觉规范（同体系升级）

- 令牌：沿用 `--color-bg-*`、`--color-text-*`、`--color-border`、`--color-primary`、`--color-success` / `--color-error`、圆角与字号变量
- 列表行略增高；摘要用 tertiary 色；角标更清晰
- 状态语义色：成功绿 / 进行中主色 / 失败红 / 中性灰
- 侧滑：轻阴影 + 左侧分割线，避免厚重卡片堆叠
- 空状态：文案为主，Figma 预留简单线框插画位

## 7. 交互状态机（摘要）

```
默认浏览 ──点列表项──► 详情侧滑（列表仍在）
        ──点待整理──► 待整理主区
        ──点图谱──► 图谱主区
        ──点更多·清理/合成──► 工具全页
        ──点更多·重建 / 后台任务──► 顶栏 pill ──点 pill──► 任务中心
详情侧滑 ──关──► 回到打开前主区
任务中心 ──关──► 回到打开前主区（pill 按规则更新）
```

## 10. 成功标准

- 新用户能在 10 秒内理解：左栏选分区、中间看列表、点开看详情
- 长任务无需离开 Wiki 即可知道「在干什么 / 进度 / 成败」
- 无英文机器状态直接暴露给用户
- 视觉仍像 Lumii 设置页的一部分，但 Wiki 区更清晰可读
