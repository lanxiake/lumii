# Wiki 自动综述与知识图谱设计

> 日期：2026-08-27  
> 状态：待用户审阅  
> 范围：原问题 6（综述 AI 自动合成，人只改/删）与问题 7（双链图谱 → 知识图谱）  
> 实现顺序：**先综述，后图谱**（两轮各自 plan → 实现；本文一次定稿）

## 1. 背景与目标

原 P2 设计要求综述「仅用户显式触发 + 候选接受」，图谱「双链为主、ERO 可选」。产品方向调整为：

1. **综述**：由 AI 定时自动生成并直接成页；人只做修改与删除。
2. **图谱**：做成混合知识图谱（实体 + 页面；关系边 + 双链边；可切换图层）；ERO 以 AI 抽取为主、双链 bootstrap 为冷启动。

### 成功标准

| # | 标准 |
|---|---|
| S1 | 定时任务按顶层分类自动写出/更新 `syntheses/` 页，无需人手选题或接受候选 |
| S2 | 综述 UI 以「已生成列表 + 编辑/删除」为主；可「立即刷新」 |
| S3 | 知识图谱默认混合视图；支持图层：全部 / 仅实体关系 / 仅页面双链 |
| S4 | ERO 为空时自动双链冷启动；AI 抽取增量写入实体与关系 |
| S5 | 不 bundling：综述可先上线；图谱可后上线 |

## 2. 综述自动成页（实现轮次 1）

### 2.1 人机分工

- AI：定时（及手动「立即刷新」）合成 → **直接** `savePage` 到 `syntheses/`。
- 人：打开综述页编辑（新 revision）或删除页。
- 主流程不再依赖「多选页面发起」与「接受/拒绝候选」。
- 页可标 `editor: ai`，UI 提示「AI 自动生成」。

### 2.2 定时与按分类策略

- **触发**：系统级定时任务（复用现有 Cron / bridge 调度）。默认每天 1 次（cron 可配置）。
- **手动**：综述视图提供「立即刷新全部综述」。
- **分类**：对每个有页面的目标分类各写一篇。本轮默认目标：`sources`、`media`（可配置扩展到 `concepts` / `entities` 等；`inbox` 默认排除）。
- **输入**：该分类下活跃页；排除 `archived` / `outdated`（若已有 status）。硬上限默认 **最多 40 页** 或合计约 **80k 字符**（先到为准）；超限按遗忘曲线/新近度截断。
- **输出路径**：稳定 slug，例如：
  - `syntheses/overview-sources`
  - `syntheses/overview-media`
- **已存在**：更新正文并写新 revision，不无限新建同题页。
- **失败**：单分类失败不阻断其他；记录错误与上次成功时间，UI 可见。
- **成本**：整次任务串行；与 `WikiOrganizeQueue` 错峰，避免抢 LLM。

### 2.3 管线复用

- 复用 `WikiSynthesizer` 的分块合成能力；新增「按 category 自动成页」入口（例如 `autoSynthesizeCategory(agentId, userId, category)`），内部选页 → 合成 → **直接 savePage**（跳过或短路 candidate 接受态）。
- 历史 `wiki_syntheses` 中 `candidate` 记录：本轮可不做迁移；UI 可忽略，或提供一次性「转为页面」次要操作（非必须）。

### 2.4 UI（SynthesisView）

- 主区：已生成综述列表（按分类）→ 点击打开编辑。
- 次要：「立即刷新全部」；可选「刷新本分类」。
- 移除（或折叠到高级区）：多选页面发起、接受/拒绝主按钮。

### 2.5 非目标（综述轮次）

- AI 主题聚类多篇（本轮固定按分类一篇）。
- 自动引用数字校验。
- 归档批次成功后即时增量合成（仅定时 + 手动）。

## 3. 混合知识图谱（实现轮次 2）

### 3.1 节点与边

| 种类 | 含义 |
|---|---|
| 节点 `entity` | ERO 实体：名称、类型、可选 `pageId` |
| 节点 `page` | Wiki 页面：保留分类色 |
| 边 `relation` | ERO 有向关系：类型 + 强度 |
| 边 `wikilink` | 已解析双链 |

### 3.2 图层与交互

- 默认：**全部（混合）**。
- 图层开关：`全部` / `仅实体关系` / `仅页面双链`。
- 点实体：侧栏显示观察摘要（只读）+ 跳转关联页（若有 `pageId`）。
- 点页面：打开页面（现有行为）。
- 菜单文案：「双链图谱」→「知识图谱」。
- 布局：继续 xyflow + dagre；节点上限与截断提示保留。

### 3.3 数据 API

- **扩展现有** `wiki:graph:data`（不另开命令）：在节点/边上增加 `kind` 字段并兼容旧调用方。
  - `nodes[]`: `{ id, kind: 'entity'|'page', title, entityType?, pageId?, category?, path?, useCount? }`
  - `edges[]`: `{ id, kind: 'relation'|'wikilink', source, target, label, strength? }`
  - `truncated: boolean`
- 查询仍支持中心页 / 分类 / limit（默认 50），避免全库大图。
- 实体节点 `id` 使用 `entity:<eroId>` 前缀，避免与 pageId 冲突。

### 3.4 ERO：冷启动 + AI 抽取

- **冷启动**：打开知识图谱且实体数为 0 → 自动 `bootstrapEroFromWikilinks`；可保留「重建双链引导」按钮。
- **AI 抽取（主路径）**：定时任务（可与综述同 cron **错峰**，或独立较低频率如每周）对最近更新页面批量抽取：
  - 实体（含类型）
  - 关系（类型 + 强度；`upsertRelation` 概率并集合并）
  - 可选一句观察
- **范围**：每轮默认最多 **20 页**；单页正文截断约 **4k 字符**；单页失败跳过。
- **绑定**：抽取实体名与已有页面标题匹配时绑定 `page_id`。
- **图层语义**：AI 关系在「实体关系 / 全部」中展示；双链边在「页面双链 / 全部」中展示。

### 3.5 非目标（图谱轮次）

- 实体模糊合并 UI。
- 多跳问答。
- 完整观察编辑器（只读侧栏即可）。
- 替换为第三方图数据库。

## 4. 与既有设计的关系

| 原 P2 条款 | 本设计变更 |
|---|---|
| 综述仅用户显式触发、候选接受 | 改为定时自动直接成页；人改/删 |
| 图谱以双链为主、ERO 晚绑定可视化 | 改为混合知识图谱为默认产品形态 |
| ERO 发布门槛「反链不够用才启动」 | 产品选择提前启用；冷启动 + AI 抽取 |

原设计文档可作为历史背景；以本文为实施依据。

## 5. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 自动综述结论错误污染库 | 页标 AI 生成；人可改删；稳定路径可覆盖更新；不做静默多主题发散 |
| 定时 LLM 成本 | 分类少、截断上限、串行、与归档错峰 |
| 图谱节点爆炸 | limit + 中心/分类过滤 + 截断提示 |
| AI 抽取噪声 | 低强度起步、并集合并、双链图层可对照 |

## 6. 测试要点

**综述轮次**

- 定时/手动刷新：`sources`/`media` 各生成或更新一页。
- 同路径再次运行写 revision，不复制同题页。
- UI 无强制接受/拒绝即可打开编辑。
- 单分类失败时其他分类仍成功。

**图谱轮次**

- 混合数据含 entity/page 与 relation/wikilink。
- 三图层过滤正确。
- ERO 为空时自动 bootstrap。
- AI 抽取后关系边出现在实体图层。
