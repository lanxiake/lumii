# 实验功能页 UI 重设计

**日期：** 2026-09-13  
**状态：** 已确认并实施  
**范围：** `apps/windows` 设置 → 实验功能（列表 + 提示词风格详情 + 自主进化详情布局）

## 目标

1. 实验功能之间用**列表**展示；配置在**独立子页**完成。
2. 提示词风格、自主进化详情更简洁清晰，修复嵌入设置时的布局变形。
3. 不改变业务逻辑与数据流（设置存储、IPC、自主进化 API 保持不变）。

## 已确认决策

| 项 | 选择 |
|----|------|
| 详情打开方式 | 设置内栈式子页（非全局 Router、非抽屉） |
| 列表交互 | 无行内开关；列表只做入口，启用/配置在详情 |
| 自主进化信息架构 | 保留 7 个 Tab，只修布局与样式 |
| 提示词风格段表 | 去掉；详情只保留详细/简要 + 说明 |

## 架构

### 视图状态

`ExperimentalSection` 持有本地视图：

```ts
type ExperimentalView = 'list' | 'promptStyle' | 'autonomous'
```

- 默认 `list`
- 点列表行 → 对应详情
- 详情顶栏「← 返回」→ `list`
- 离开「实验功能」分类再进入时，重置为 `list`

### 组件边界

```
ExperimentalSection
├── ExperimentalFeatureList          // 列表
├── PromptStyleDetail                // 提示词风格子页
└── AutonomousPage embedded={true}   // 自主进化子页（已有，改布局）
```

- 列表与栈切换只在 `ExperimentalSection`
- `PromptStyleDetail`：风格读写（沿用 `useSettings` + `updatePromptStyle`）
- `AutonomousPage`：继续自管启用开关与 Tab 内容；嵌入模式样式重做

独立全页 `activeView='autonomous'` 仍可用，与设置内嵌入共享组件，样式按 `embedded` 区分。

## 列表页

- 页头：标题「实验功能」+ 一行说明（实验项可能变更；部分配置下一轮对话生效）。
- 卡片列表，每行：
  - 左：功能名 + 状态摘要（提示词风格：`当前：详细|简要`；自主进化：`状态：已启用|已禁用`）
  - 右：进入指示（`>`）
  - **无开关**
- 自主进化有待审批目标时，行上保留小红点（与侧栏 badge 一致）。
- 初始两项：提示词风格（实验）、自主进化。后续实验项按同一行模式扩展。

## 提示词风格详情

- 顶栏：`← 返回` + 「提示词风格（实验）」
- 主区（单列、窄宽，对齐其他设置段）：
  1. 标签「全局风格」
  2. 分段控件：详细 | 简要（现有 radiogroup 行为不变）
  3. 简短说明：差异与「下一轮对话生效」
- **删除** `PROMPT_SECTIONS` 只读表及相关样式
- 写入路径不变：localStorage + `SETTINGS_UPDATE_EVENT` + IPC `updatePromptStyle`

## 自主进化详情（布局修复）

功能与 Tab 不变：概览 / 能力 / 规划任务 / 反思 / Prompt / 内心 / 设置。启用开关仍在详情页头。

### 布局问题根因

嵌入设置时内容区较窄，现有 `auto-fit minmax(300px, …)` 与固定高度卡片导致图表、Tab、目标列表互相挤压变形。

### 修复原则

1. **单列优先**：嵌入模式下概览、能力、反思、内心等网格改为单列纵向堆叠（或仅在容器足够宽时用 2 列）。
2. **固定高度改为内容撑开**：嵌入模式取消强制 `min-height: 200px` / 固定卡片高度，图表给合理 `min-height` 但不与目标列表抢同一行高度。
3. **Tab 栏**：嵌入时允许横向滚动，避免 7 个 Tab 挤变形；图标+短文案，字号与间距与设置页一致。
4. **页头**：标题 + 启用开关同一行；字号下调以适配设置内容区（避免 22px 标题 + 大图表同时抢空间）。
5. **滚动**：仅内容区纵向滚动；页头与 Tab 吸顶或固定在子页顶部。
6. **概览**：上为满意度评分 + 趋势（可上下叠），下为最近目标列表；避免三列并排。

独立全页（非 embedded）可保留更宽的多列布局。

## 样式与一致性

- 复用设置页 token：`--spacing-*`、`--color-*`、`--radius-md`、现有 `.setting-row` / `.setting-hint` 模式。
- 列表卡片：轻边框、无重阴影；与设置其他列表行视觉接近。
- 不引入新依赖；不改设计系统全局主题。

## 非目标

- 不改自主进化业务逻辑、审批流、心跳/配额语义
- 不改 prompt 风格后端 / `PROMPT_SECTIONS` 数据本身（仅 UI 不再展示表）
- 不把工具进化迁回实验功能
- 不新增全局 Router 路由

## 测试

- 更新 `ExperimentalSection.test.tsx`：列表渲染、进入/返回详情、风格切换；去掉段表断言
- 手动：设置 Hub 内列表 → 两详情 → 返回；自主进化开关与各 Tab 在窄宽下不再横向挤压；独立 `autonomous` 全页仍可用

## 验收标准

1. 实验功能默认只见列表，不出现双功能同屏全展开。
2. 点行进入子页，返回回到列表。
3. 提示词风格页无段表，仅风格切换 + 说明，切换仍生效。
4. 自主进化嵌入详情 7 Tab 可用，概览/图表在设置宽度下可读、不严重变形。
5. 现有相关单测通过。
