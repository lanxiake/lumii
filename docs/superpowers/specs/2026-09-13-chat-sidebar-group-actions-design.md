# 对话列表分组操作区简化

日期：2026-09-13  
范围：`ChatSidebar` 分组标题（默认 / 渠道 / 系统）

## 目标

组头右侧 `+`、`···`、折叠箭头挤在一起，视觉嘈杂。统一为「左侧信息 + 右侧单一 `···`」，折叠靠点整行。

## 交互

### 组头布局

`[图标?] 组名 (数量) [运行中圆点?] ···`

- 去掉组头 `+` 与折叠箭头 `▾`
- 点击组头空白区域 → 展开 / 折叠
- `···` 点击 `stopPropagation`，不触发折叠
- **自主进化**：无可操作项，不渲染 `···`
- 底部「新建对话 / 绑定渠道」保留

### 菜单内容

| 分组类型 | 菜单项 |
| --- | --- |
| 默认 Tab · Agent / 系统默认 | `在此新建对话` → 分隔 → `清空历史（保留最近 5 条）` → `清空全部历史` |
| 渠道 / 系统（非自主进化） | 仅两项清空 |
| 自主进化 | 无 `···` |

新建回调沿用 `onCreateSessionInGroup(agentId | null)`；清空逻辑不变。

## 非目标

- 不改底部主按钮
- 不改会话项右键菜单
- 不做悬停才显示 `···`
