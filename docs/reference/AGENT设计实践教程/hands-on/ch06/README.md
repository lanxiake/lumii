对应章节：`chapters/ch06-反思与自我进化.md`。
两个实验都**纯标准库、完全离线、结果确定可复现**（内置样例数据，不需要 API key）。

## 样例数据里埋了什么（先别看答案，跑完再回来对）

`runs_sample.json` 的 `memories` 中有五条记忆，其中三条来自 `auto-reflection`
（即某次失败后模型自己写下的"教训"）。数据刻意构造了三种角色：

1. **毒记忆 mem_017**：由 r005 一次"只看第一页就下结论"的失败换来，
   解释是"返回空=当天没有新数据，不必翻页也不必调时间窗"——
   一个自信、貌似合理、且**永远不被下一次空结果反证**的解释。
   此后它被 12 次引用、伴随 11 次失败，横跨三个不同错误类目。
2. **侥幸样本 r050**：引用 mem_017 却成功了——那次上游 total 真的是 0。
   防止你把指标设计成"引用过失败的记忆=永远失败"这种过强假设。
3. **健康高频记忆 mem_003**："导出前先拉 1 条样本核对结构"，人写的，
   13 次引用失败率 8%。用来证伪"按引用次数一刀切"的监控方案。

## 每个步骤对应本章哪个论点

| 实验步骤 | 对应论点（章节） |
|---|---|
| A-1 分类学统计：类目名、定义、修正规则全部写死在 `TAXONOMY` 常量 | §3.5 守则：错误分类学由人/代码定义，不由模型自由发挥（反模式 4） |
| A-1 输出"关联记忆"列 | §3.6：错误不是孤立事件，而是同一条记忆在不同类目里反复出场——单类目视角看不见 |
| A-2 RRR 排名：`被倚重次数 × 关联失败率`，阈值 `refs≥4 ∧ rate≥60% ∧ score≥4` | §3.6 联合监控（工程化外推，非 Honest Lying 论文原文定义）；mem_003 不被误杀、mem_017 被揪出，就是联合 vs 单指标的答案 |
| A-3 纠正卡：每卡=错误例（带 run_id）+ 同任务族正例 + 一条祈使句规则 | §3.5 工程版路径：3–5 条 few-shot/规则就是可用的"进化"，不必等自动优化器 |
| A-3 卡片文件头"未验证、需回归后才入库" | 守则一（入库门）与守则二（证据指针）；§5 反模式 3 |
| B-A 线：反思入库后连续 6 个任务被污染，且每次失败"验证"解释 | §2.3 memory confabulation：失败不反证解释，解释就永生（Honest Lying，C 级证据） |
| B-B 线：无任何自然语言解释入库，存活的是一条窗口对齐信号 | §3.4 Honest Lying 的 mitigation：程序化轨迹级失败信号（0%→86% 指正确目标提及率，不是正确率） |
| 两线对照小结"变的不是模型，是入库物形态" | §2.4 判据：可执行、可验证、可计数；§3.2 Voyager 技能库思想 |

## 你应该观察到什么

- 实验 A：`mem_017` 综合分 11.0 高居第一（12 引用 / 11 失败 / 92%），
  三个头部错误类目（空结果 9 次、分页 8 次、时间窗 7 次）共享同一批记忆引用；
  `mem_003` 高频但 8% 失败率，正确判为正常。
- 实验 B：A 线 6 连败且 RRR 计数递增，B 线自第 2 个任务起全绿。
  同一个"笨模型"，两种结局——差异全部来自入库物的形态。

## 延伸练习

1. 把 `MIN_FAIL_RATE` 从 0.6 调到 0.9 再跑：哪些毒记忆漏网了？（提示：mem_021）
   体会阈值设计为什么必须是"次数下限 + 比率下限"双保险。
2. 从 `runs_sample.json` 删掉 mem_017 并假设纠正卡已注入，人工推演哪些
   run 会转为成功，把推演结果写成回归测试用例——这就是 §3.5 的准入门。
3. 给实验 A 增加"新错误类目"检测：出现 `error_type=null 且 success=false`
   的记录时报警，提示分类学需要人工扩充（而不是让模型自动加类目）。

## 诚实性说明

- 样例数据为教学构造，数字（12 引用 / 92% 等）是脚本输出的固有属性，
  不是任何论文的实验结果。
- Honest Lying（arXiv:2605.29463）为未同行评审预印本（C 级证据）；
  实验 B 演示的是其机制逻辑，桩代码不模拟真实模型能力。
- RRR 联合指标是本书对论文概念的工程化外推，论文原文只定义了
  "基于日志的重复倚重错误反思内容"这一度量思想。
