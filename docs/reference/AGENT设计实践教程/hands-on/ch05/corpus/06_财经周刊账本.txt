# source: 媒体
# title: 《财经周刊》深度报道：12号线的账本

12号线工程总投资189亿元，其中专项债与银行贷款合计142亿元，按平均利率4.1%测算，年利息支出约5.8亿元。

开通第一个月，票款收入2413万元；而按运营方内部预算，含人工、能耗、维保的运维成本约日均385万元，月度直接运营亏损约9000万元。利息保障倍数远低于1，机构测算需区级财政按年补贴约2.6亿元才能维持收支平衡。

某城投平台内部人士坦言："这条线赌的是走廊沿线土地增值，票款从来不是还款来源。"报道同时对比徐州、洛阳等同类城市：新线开通前两年爬坡期补贴压力具有普遍性，但土地市场走弱时缺口会被放大。
