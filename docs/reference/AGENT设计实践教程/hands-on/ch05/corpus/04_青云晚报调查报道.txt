# source: 媒体
# title: 《青云晚报》调查报道：12号线的乘客都去哪儿了？

早高峰8点10分，记者在某中心站站台看到，进站旅客稀稀拉拉，驶站的列车满载率不足三成。

晚报援引市政交通卡清算数据：12号线各站日均进站量38.4万人次，与工可报告中"日均客流预测65万人次"相比，缺口超过四成。

沿线居民反映的问题集中在三点：车站离小区远，平均步行约40分钟；平峰行车间隔8分钟太长；沿线15条公交线路中，首月完成调整并实现接驳的只有3条。

市城市发展研究院专家则认为，客流预测所依赖的还是2016年总规的人口与岗位分布，"这些年城市向西，人跟产业走了，轨道走廊的人口根本没长到规划预期。"
