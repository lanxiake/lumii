# source: 官方
# title: 青云市交通运输局《关于地铁12号线开通运营第一个月的情况通报》

9月28日，市交通运输局发布情况通报。12号线自8月28日开通以来运行平稳有序，第一个月日均客运量51.2万人次，累计客运量1536万人次，列车运行图兑现率99.91%，正点率99.8%。

通报指出，客流尚处于正常的爬坡期，与2号线开通首月日均44.3万人次相比，12号线同期高出15.6%；参照2号线经验，爬坡期通常持续6至8个月。

对于社会关注的预测口径，通报专门说明：工可批复中"日均65万人次"为开通初年高峰日负荷目标，并非日均客流目标，以65万作为日均对照基准属于口径误读。下一步将组织公交线网接驳优化与行车间隔动态调整。
