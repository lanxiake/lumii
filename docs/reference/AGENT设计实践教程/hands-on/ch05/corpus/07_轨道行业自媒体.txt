# title: 轨道行业公众号"列车早点到"：12号线到底算不算失败？

结论先行：按可比口径，12号线第一个月的表现不差。

我们统计了近五年23个同类城市（非直辖、地铁运营里程100至300公里）新线首月数据：首月客流达到工可预测值的比例中位数在62%—75%之间，第6个月普遍回升至预测值的85%左右。12号线首月51.2万比65万，达成率约79%，位于同类中位以上。

必须提醒的是口径问题：预测值多为"包含换乘的客运量"，而媒体常用的进站量不含换乘，二者相差约25%。先把口径对齐，再谈"缺口"。

真正的隐忧不在爬坡，在线网和人口：12号线走廊的岗位密度是否支撑长期客流，建议参考最新的人口与岗位分布研究，而不是2016年的总规。
