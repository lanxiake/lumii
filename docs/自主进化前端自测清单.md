## 🐛 常见问题排查

### 问题 1: 单元测试失败

**排查步骤**:
1. 检查 Node.js 版本（需要 18+）
2. 重新安装依赖：`pnpm install`
3. 清理缓存：`pnpm clean`
4. 查看具体错误信息

### 问题 2: TypeScript 编译错误

**排查步骤**:
1. 检查是否有缺失的类型定义
2. 运行 `pnpm tsc --noEmit` 查看详细错误
3. 检查导入路径是否正确

### 问题 3: 数据库迁移失败

**排查步骤**:
1. 检查当前 schema 版本
2. 查看数据库日志
3. 手动运行 SQL 验证语法
4. 检查是否有锁定的数据库连接

### 问题 4: IPC 通道不可用

**排查步骤**:
1. 检查是否调用了 `registerAutonomousIpcHandlers()`
2. 检查 Preload API 是否正确导出
3. 在控制台检查 `window.autonomousApi` 是否存在
4. 查看主进程日志是否有错误
