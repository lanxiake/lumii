## 1. Wiki 是什么

Wiki 是你的**个人资料库**：把文件与笔记放在一起，像文件夹一样浏览和搜索。

**三个特点：**

1. **先收进来，再慢慢分** — 新东西默认进「收件箱」，不必立刻想放哪  
2. **在 App 里就能看** — 点标题预览内容；很少需要打开磁盘上的原文件  
3. **默认只建引用** — 原文件留在原处；笔记与 Agent 写入的资料才落在 `<工作空间>/wiki/`  

与「工作记忆」「个人记忆」不同：Wiki 存的是**真实资料和正文**，不是对话摘要。聊天文字不会自动进 Wiki；你上传的文件、Agent 任务产物可以。

**应用内帮助**：Wiki 顶栏右侧 **?** 按钮可打开操作指引抽屉；左栏与各功能悬停可查看简要说明。

## 3. 资料怎么进来

### 3.1 上传文件 / 任务产物

在聊天里上传附件，或 Agent 产出文件 → 资料进入 **收件箱**。

- 原文件**不会自动搬家**，只在 Wiki 里建立「引用」  
- 系统会尝试抽取正文方便搜索（PDF、Word、Markdown 等）  
- **不会自动帮你分类** — 分类由你决定（开启「更多 → AI 自动分类」后由后台整理器尝试归档）  

### 3.2 链接类资料

早期保存的链接仍可在收件箱/列表中预览、在浏览器打开。当前**没有**「粘贴网址」入口；需要留存网页内容时，请把网页另存为文件后通过「从文件夹导入」收进来，或让 Agent 把内容整理成笔记。

### 3.3 从文件夹导入（批量 + AI 自动分类）

Wiki → **收件箱** → **「从文件夹导入」**：

1. 选择本地文件夹（例如 `outputs/某任务/`）  
2. 系统预览可导入数量与目录结构 → 确认  
3. **AI 给出目录映射方案**（综合源路径、目录树、库内已有分类、文件内容）  
4. 在预览页逐簇确认或改选分类，点**应用**后才真正归档；直接关闭则什么都不会改  
5. 无法确定的文件留在 **收件箱**，可批量重试或手动归档  

原文件不移动，Wiki 只建立引用。适合一次性整理任务产物、下载目录等。

### 3.4 新建笔记

在某个分类下可新建 Markdown 笔记，直接写在 `wiki/` 文件夹里。

### 3.5 让 Agent 帮忙整理

在聊天中可以直接说：

> 帮我把 `outputs/竞品调研` 目录下的文件整理到 Wiki（资料库）

Agent 会通过 **`lumii-ui` CLI**（不是只读 wiki 工具）完成：

1. `wiki folder scan` — 预览可导入文件、`directoryTree`、`topicOccupancy`  
2. `wiki folder import` — 导入并让 AI 给出映射方案（`migrateRun.phase` 应为 `review`）  
3. `wiki inbox count --status pending` — 验证是否还有待人工处理的条目  

映射方案需要用户在 Wiki 的迁移预览页确认后才会落位；仅当用户明确要求「只导入不分类」时加 `--no-auto-classify`。

## 4. 日常怎么用

### 4.1 收件箱（推荐先看这里）

新资料都会先到 **收件箱**。不必一条条点，可以批量处理：

1. 左栏点 **收件箱**  
2. **勾选**要处理的条目（或点 **全选**）  
3. 选操作：  
   - **批量归档到…** — 一次把多条放进同一分类（最常用）  
   - **让 AI 分类** — 让 AI 给所选条目定目录  
   - **批量重试** / **全部重试** — 对失败或待处理的条目重新跑后台处理  
   - **批量删除** — 永久删除所选条目  

单条操作：点标题预览 → **归档到…** / **重试** / **删除**。

### 4.2 浏览已分类资料

1. 左栏点 **工作 / 学习 / 生活 / 收藏 / 归档**  
2. 右侧出现该分类下的资料列表  
3. **点任意一行** → 弹出预览（详情抽屉）  

**列表上方的筛选条（从宽到窄）：**

| 筛选 | 作用 |
|------|------|
| 小类芯片 | 只看某个小类（或「未细分」） |
| 标签芯片 | 只看带某个标签的资料；默认显示 12 个，点「更多标签」展开 |
| 路径芯片 | 点行首的 `a / b /` 路径前缀，只看该目录下的资料 |
| 文档类型 | 全部 / 文档 / 图片 / 音视频 |

列表默认按用户路径聚簇排列，同目录内按更新时间新旧。行尾动作：查看详情、移动、存到临时存放、删除。

### 4.3 预览（最常用）

点标题或整行 → 看正文、Markdown 或链接卡片。

- **文件**：显示提取出的文字；看原文件用预览区里的「打开原文件」  
- **链接（未保存）**：显示标题和网址；点「在浏览器打开」或「保存网页内容」  
- **已保存的网页**：显示 Markdown 正文  

详情抽屉底部可**编辑分类信息**：用户路径（用 `/` 分层）、标签（逗号分隔）、一句话描述。路径与标签随后会成为列表筛选芯片的来源。

### 4.4 搜索

顶栏搜索框 → 输入关键词 → 回车。悬停搜索框可看说明。

搜索命中**标题与正文**；标签和用户路径不在全文索引里，请用上方的标签/路径筛选。

### 4.5 分类（移到… / 归档到…）

1. 在列表点 **移动** 或收件箱里 **归档到…**  
2. 选大类（**工作 / 学习 / 生活 / 收藏 / 归档**）  
3. 再选小类；不确定就点 **「暂不细分」**，之后会显示为「未细分」  
4. 点 **确认归档**  

大类与小类来自「更多 → 编辑主题树」，可以自行增删改。  
对已入库文件，选择器里可点 **「让 AI 建议」** 参考分类（采纳与否由你决定）。

**批量移动**：在分类目录内多选文件后 **移动到…**；在收件箱多选后 **批量归档到…**。

### 4.6 临时存放

还没想好放哪、但也不想留在收件箱：列表行点 **存到临时存放**。之后从左栏 **临时存放** 进去，再移动到正式分类。

### 4.7 重新编目

- **本小类**：进入某小类后点 **重新编目本小类**，AI 复查这一类的目录归属  
- **全库**：更多 ⋯ → **全库重新编目**，AI 复查已归档文件  

两种都会先生成候选，逐条确认后才改；收件箱里的未分类条目请用「批量归档到…」。

| 分类 | 放什么 |
|------|--------|
| **收件箱** | 刚进来、还没想好 |
| **工作** | 跟上班、项目、赚钱有关 |

## 8. 常见问题

**Q：为什么新文件一直在收件箱？**  
A：默认没有开启「AI 自动分类」；可勾选多条 **批量归档到…**，或暂时留在收件箱。

**Q：能不能 AI 自动全部归档？**  
A：可以开启「更多 → AI 自动分类」让后台整理器尝试；拿不准的仍会留在收件箱。对已分类文件可用 **全库重新编目**（须预览确认）。导入时 AI 给出的映射方案也**必须你点应用**才会生效。

**Q：标签和路径怎么用？**  
A：在详情抽屉里编辑：路径按 `/` 分层（如 `项目/2026/竞品`），标签用逗号分隔。它们会出现在列表上方的筛选条里。

**Q：原文件会被移动或删除吗？**  
A：不会。只有主动 **迁入 wiki** 才会复制到 `wiki/`。
