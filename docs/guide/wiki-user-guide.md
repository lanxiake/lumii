## 1. Wiki 是什么

Wiki 是你的**个人资料库**：把文件、网页链接、笔记放在一起，像文件夹一样浏览和搜索。

**三个特点：**

1. **先收进来，再慢慢分** — 新东西默认进「收件箱」，不必立刻想放哪  
2. **在 App 里就能看** — 点标题预览内容；很少需要打开磁盘上的原文件  
3. **文件在 workspace 里** — 资料保存在 `<工作空间>/wiki/` 文件夹，资源管理器里也能看到  

与「工作记忆」「个人记忆」不同：Wiki 存的是**真实资料和正文**，不是对话摘要。聊天文字不会自动进 Wiki；你上传的文件、保存的链接可以。

## 2. 界面一览

```
┌─────────────┬────────────────────────────────────┐
│  收件箱 (3)  │  🔍 搜索                    ⋯     │
│  工作        ├────────────────────────────────────┤
│  学习        │  列表：点一行 = 预览               │
│  生活        │                                    │
│  收藏        │  [ + 添加文件 ]  [ + 添加链接 ]     │
│  归档        │                                    │
│  ─────────  │                                    │
│  搜索        │                                    │
└─────────────┴────────────────────────────────────┘
```

**左栏只有这些：**

| 入口 | 什么意思 |
|------|----------|
| **收件箱** | 还没分类的新资料（角标是未处理数量） |
| **工作** | 上班、项目、会议、汇报相关 |
| **学习** | 读书、课程、教程、考试相关 |
| **生活** | 证件、家庭、私人随笔 |
| **收藏** | 网上链接、模板、长期参考 |
| **归档** | 暂时不用、但还要留着 |
| **搜索** | 搜全部资料 |

**知识图谱、清理、整合长文** 等高级功能在右上角 **⋯** 里，日常不用找它们。

## 3. 资料怎么进来

### 3.1 添加文件

点 **「+ 添加文件」**，或聊天里上传附件 → 资料进入 **收件箱**。

- 原文件**不会自动搬家**，只在 Wiki 里建立「引用」  
- 系统会尝试抽取正文方便搜索（PDF、Word、Markdown 等）  
- **不会自动帮你分类** — 分类由你决定  

### 3.2 添加链接

点 **「+ 添加链接」**，粘贴网址 → 进入 **收件箱**。

- 默认**只保存链接**（标题 + 网址），**不会自动下载网页**  
- 需要离线阅读时，在预览里点 **「保存网页内容」**  

### 3.3 新建笔记

在某个分类下（P1 起）可新建 Markdown 笔记，直接写在 `wiki/` 文件夹里。

## 4. 日常怎么用

### 4.1 浏览

1. 左栏点 **收件箱** 或 **工作 / 学习 / 生活 / 收藏 / 归档**  
2. 右侧出现该分类下的资料列表  
3. **点任意一行** → 右侧或上方弹出预览（详情抽屉）  

列表行尾只有一个 **⋯** 菜单，里面有：移到…、保存网页内容、迁入 wiki、稍后处理、删除等。

### 4.2 预览（最常用）

点标题或整行 → 看正文、Markdown 或链接卡片。

- **文件**：显示提取出的文字；看原文件用预览区里的「打开原文件」  
- **链接（未保存）**：显示标题和网址；点「在浏览器打开」或「保存网页内容」  
- **已保存的网页**：显示 Markdown 正文  

### 4.3 搜索

顶栏或左栏 **搜索** → 输入关键词 → 点结果预览。

### 4.4 分类（移到…）

资料分好了类，才像自己的文件夹：

1. 在列表点 **⋯ → 移到…**  
2. 选 **工作 / 学习 / 生活 / 收藏 / 归档**，再选小类（如「笔记」「链接」）  
3. 点 **确定**  

可能会看到一行灰色小字「建议：收藏」— 可以忽略，按你自己的习惯选。

**批量移动**：在收件箱多选后一次移到同一目录（P1）。

### 4.5 保存网页内容

只对**链接类**资料：

1. 打开预览  
2. 点 **「保存网页内容」**  
3. 等几秒，网页会下载并保存为 Markdown，可离线搜索阅读  

### 4.6 迁入 wiki（可选）

对**本地文件引用**：若希望文件复制一份到 `wiki/` 文件夹里：

1. 预览或 ⋯ 菜单 → **「迁入 wiki」**  
2. 确认后**复制**到当前分类目录，**原文件保留**

## 5. 分类怎么选（口诀）

| 分类 | 放什么 |
|------|--------|
| **收件箱** | 刚进来、还没想好 |
| **工作** | 跟上班、项目、赚钱有关 |
| **学习** | 主动在学、在读、在备考 |
| **生活** | 私人、家庭、证件、日记 |
| **收藏** | 网上看到的链接、模板、参考资料 |
| **归档** | 暂时不用了 |

**拿不准就留在收件箱**，没有对错。

小类示例：

- 工作：文档 · 会议 · 汇报 · 整合长文  
- 学习：笔记 · 课程 · 资料 · 整合长文  
- 生活：证件 · 家庭 · 随笔 · 整合长文  
- 收藏：链接 · 模板 · 媒体 · 整合长文  

可在 **⋯ → 编辑主题树** 中调整小类名称（大类名称与 `wiki/` 文件夹对应，高级用户可改映射）。

## 6. 资料存在哪

| 内容 | 位置 |
|------|------|
| Wiki 文件夹 | `<当前工作空间>/wiki/` |
| 索引与任务 | `~/.lumii` 本地数据库（可用 `LUMII_CLIENT_DATA_DIR` 覆盖） |

目录示例：

```
wiki/
├── 00-收件箱/
├── 01-工作/
├── 02-学习/
├── 03-生活/
├── 04-收藏/
└── 05-归档/
```

链接引用是 `.url.lumii-ref` 小文件；本地文件引用是 `.lumii-ref`；笔记和保存后的网页是 `.md`。

## 7. 高级功能（⋯ 菜单）

日常整理用不到时可以忽略：

| 功能 | 说明 |
|------|------|
| **整合长文** | 同一目录下多篇短文合并为一篇（⋯ 或目录内提示） |
| **综述合成** | 多选文件生成主题综述 |
| **知识图谱** | 可视化资料之间的关系 |
| **清理** | 扫描重复、失效引用等 |
| **重建索引** | 刷新全文搜索 |
| **编辑主题树** | 管理小类结构 |
| **全库重新编目** | AI 批量建议调整目录（须预览确认） |

任务进度：顶栏任务 pill → **任务中心**。

## 8. 常见问题

**Q：为什么新文件一直在收件箱？**  
A：这是正常的。系统**不会自动分类**，需要你点「移到…」或暂时就放在收件箱里。

**Q：保存链接后为什么看不到正文？**  
A：默认只存链接。需要正文请点 **「保存网页内容」**。

**Q：原文件会被移动或删除吗？**  
A：不会。添加文件只是建立引用；只有在你主动点「迁入 wiki」时才会**复制**一份到 `wiki/`。

**Q：AI 会帮我自动归档吗？**  
A：默认**不会**。整理时可能有一行分类建议，采纳与否由你决定。

**Q：聊天内容会进 Wiki 吗？**  
A：不会。上传的文件、保存的链接可以。

**Q：删了分类，文件会丢吗？**  
A：不会直接删文件；编辑主题树时若目录非空，需指定合并到其他目录。

**Q：和 Agent 什么关系？**  
A：Agent 可通过 Wiki 工具搜索、读取你已整理的资料；关闭记忆注入不影响 Wiki 按需读取。
