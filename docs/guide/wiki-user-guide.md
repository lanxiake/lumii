# Lumii Wiki 使用手册

> 适用版本：2026-08 用途目录树改造后的 Wiki 知识库  
> 入口：**设置 → 记忆 → Wiki** 标签页

---

## 1. Wiki 是什么

Wiki 是你的**个人文件知识库**：把上传的文件、任务产物、网页搜索结果等资料，按**用途**整理成两级目录（大类 / 小类），方便浏览、搜索和直接打开原文件。

与「工作记忆」「个人记忆」不同，Wiki 存的是**真实文件及其正文索引**，不是对话摘要。Agent 聊天消息不会自动进入 Wiki；但你上传的会议纪要、聊天导出文件等**文件**可以归档进来。

---

## 2. 界面概览

```
┌──────────────┬─────────────────────────────────────────┐
│  左栏导航     │  顶栏：搜索框 + 当前目录标题 + 任务状态    │
│              ├─────────────────────────────────────────┤
│  待整理       │                                         │
│  知识图谱     │  主内容区：文件列表 / 图谱 / 待整理队列等   │
│  临时存放     │                                         │
│  ─────────   │                                         │
│  用途目录树   │                                         │
│  （大类/小类） │                                         │
│  ─────────   │                                         │
│  ⋯ 更多      │                                         │
└──────────────┴─────────────────────────────────────────┘
```

### 左栏固定入口

| 入口 | 作用 |
|------|------|
| **待整理** | 系统尚未完成自动归档、或 AI 无法确定分类的文件；需你手动归档或重试 |
| **知识图谱** | 可视化浏览资料之间的关系（结构边 + 语义边） |
| **临时存放** | 你主动搁置、暂不进入正式目录的文件 |
| **用途目录树** | 六大默认大类及其小类；右侧数字为**该目录下的文件数量** |
| **⋯ 更多** | 高级维护工具（见第 7 节） |

大类默认**收起**，点击左侧箭头展开小类；点击大类名称可查看该大类下全部文件。

## 3. 资料如何进入 Wiki

资料会自动进入 **待整理**，常见来源：

1. **聊天中上传文件** — Agent 对话里拖入或选择的附件  
2. **任务产物** — 某些 Agent 任务生成的文件  
3. **网页搜索结果** — 通过搜索工具保存的资料  

进入待整理后，系统会尝试：

1. 抽取正文（PDF、Word、Markdown 等；音视频只建索引不抽正文）  
2. 用 AI 按用途目录自动归类  

若 AI **拿不准**，条目会留在待整理并提示「待人工归档」，不会乱猜目录。

## 4. 日常操作

### 4.1 浏览目录

1. 在左栏展开某个大类（如「学习资料」）  
2. 点击小类（如「课堂&课程笔记」）→ 右侧列出该小类下的所有文件  
3. 或直接点击大类名称 → 列出该大类下**全部**文件（跨小类）  

列表支持按类型筛选：**全部 / 文档 / 图片 / 音视频**。

### 4.2 打开原文件

在文件行点击 **「打开」**，系统会用本机默认程序打开磁盘上的原始文件。若文件已被移动或删除，会显示具体错误原因。

### 4.3 搜索

在顶栏输入关键词后按 **Enter**：

- 优先全文检索（FTS）命中正文  
- 必要时降级为混合/向量检索  
- 结果以文件形式展示，并标注所属大类 / 小类  

### 4.4 手动归档（待整理 → 正式目录）

对待整理条目：

1. 点击 **「归档到…」**  
2. 先选大类，再选小类  
3. 点击 **「确认归档」**  

也可点击 **「让 AI 建议」** 获取单条目录建议（可选采纳）。

对待补分文件（已在资料层但缺少分类）操作相同。

### 4.5 移动文件

在正式目录的文件行：

- **「移动」** — 改到其他大类 / 小类  
- **「存到临时存放」** — 搁置到临时区（仅用户操作，AI 不会自动写入）  

在临时存放区，用 **「移出」** 重新选择正式目录。

### 4.6 批量操作

在小类视图可开启多选，批量移动或批量存到临时存放。

## 5. 默认用途目录

Wiki 按**文件用途**分类，不是按学科或文件形态。默认六大类：

| 大类 | 典型内容 | 部分小类示例 |
|------|----------|--------------|
| 做事记录 | 项目交付物、会议纪要、汇报 | 项目/任务资料、会议聊天记录 |
| 学习资料 | 教材、笔记、调研材料 | 课堂&课程笔记、读书摘抄整理 |
| 计划与复盘 | 计划、预算、复盘总结 | 目标规划方案、经历复盘总结 |
| 证件凭据 | 合同、证件扫描、发票 | 合同协议文件、票据收据凭证 |
| 模板参考 | 可复制的模板与素材 | 各类文档模板、范文案例参考 |
| 随笔创作 | 个人创作与草稿 | 原创作品底稿、灵感随手记录 |

**快速归类口诀：**

- 事情做完留下的结果 → 做事记录  
- 用来学习吸收知识 → 学习资料  
- 打算做什么、做完反思 → 计划与复盘  
- 可以当证据凭证 → 证件凭据  
- 拿来复制修改参考 → 模板参考  
- 自己随心写的爱好作品 → 随笔创作  
- 没想好放哪里 → **临时存放**（仅你手动选择）

可在 **⋯ 更多 → 编辑主题树** 中增删改大类与小类；删除非空目录时需指定文件去向。

## 6. 进阶功能

### 6.1 新建笔记

在某个**小类**视图顶栏点击 **「新建笔记」**，会在该小类下创建 Markdown 笔记文件（本地落盘 + 进入资料层）。

### 6.2 重新编目

- **单文件 / 单小类**：文件行的「重新编目」或选择器里的 AI 建议  
- **全库**：⋯ 更多 → **全库重新编目** — AI 复查已归档文件并给出目录调整建议  

编目结果是**候选**，需你在「重新编目」视图逐条 **接受 / 忽略** 后才会生效。编目运行期间新上传的文件仍进待整理，不会丢失。

### 6.3 综述合成与短文整合

**综述**：从目录中多选文件，可生成主题综述（⋯ 更多 → **综述合成**，或小类内多选后点「生成本组综述」）。接受综述后，产物成为目录里的一份普通文件。

**整合短文**（减少碎片化）：同一小类下若有多篇**偏短**的同主题资料（如多篇网页摘录），系统会提示「检测到 N 篇短文，可整合…」。你可以：

1. 多选 ≥2 篇短文 → 点 **「整合为长文」**；或
2. 点 **「整合全部短文」** 一键合并当前目录下全部短文。

整合会生成一篇 **1000 字以上** 的结构化长文。生成完成后**自动归档**到当前大类下的 **「整合长文」** 小类，并归档被合并的原短文；也可在「综述合成」中手动审阅后再接受。

整合产物标题带 `[整合]` 前缀，与自动/手动综述区分。

### 6.4 知识图谱

左栏 **知识图谱** 可浏览：

- **结构边** — 由用途目录推导的层级关系  
- **语义边** — 从正文抽取的实体关系（ERO）  

点击节点可定位关联资料。

### 6.5 清理与维护

| 功能 | 说明 |
|------|------|
| **清理** | 扫描陈旧、重复或需维护的资料，支持归档保留 / 恢复 / 删除 |
| **重建索引** | 重新生成全文检索索引（大库可能耗时，可在任务中心查看进度） |
| **历史页面** | 查看早期 P0/P1 自动生成的摘要页（只读，与当前「目录→文件」模型并存） |

任务进度与失败重试：点击顶栏任务 pill 打开 **任务中心**。

| 菜单项 | 用途 |
|--------|------|
| 全库重新编目 | AI 复查已归档文件的目录位置 |
| 编辑主题树 | 管理大类 / 小类结构 |

| 清理 | 资料健康扫描与批量处理 |
| 综述合成 | 从已有文件生成主题综述 |
| 重建索引 | 刷新全文检索索引 |

## 8. 常见问题

**Q：为什么文件一直在待整理？**  
A：可能正在排队处理、自动归档失败、或 AI 无法确定分类。可点「重试」或手动「归档到…」。

**Q：待整理角标数字比列表条数多？**  
A：角标 = 待整理队列 + **待补分**（已入库但未分类的文件）之和。

**Q：聊天内容会进 Wiki 吗？**  
A：不会。Agent 对话消息不归档；你**上传的文件**（如会议纪要 docx）可以。

**Q：音视频能搜正文吗？**  
A：音视频会入库并标注类型，但默认不抽取正文，主要靠文件名与元数据检索。

**Q：删了主题树里的目录，文件会丢吗？**  
A：不会直接删除；编辑主题树时若目录非空，需选择合并到其他目录或移入临时存放。

**Q：数据存在哪里？**  
A：默认 `~/.lumii` 下的本地数据库与文件副本；可用环境变量 `LUMII_CLIENT_DATA_DIR` 覆盖。

---

## 9. 与 Agent 的关系

Agent 可通过内置 Wiki 工具搜索、读取已归档资料，用于回答问题时引用你的本地知识。Wiki 归档完成后，相关内容可被检索召回；关闭「注入工作/个人记忆」不影响 Wiki 工具按需读取。
