# 分析与反思

本目录存放**方案分析、批判性反思**类文档 —— 回答"为什么选这个方案 / 这个方案哪里会塌"。

与 [`../design/`](../design/) 的区别：设计文档给结论与方案，本目录给**推导过程与反面论证**。

## 落点约定

**本目录只收跨主题的分析。** 单一主题的分析放对应主题目录，与它的设计/计划同处：

- 多设备数据同步策略分析、同步策略反思 → [`../design/数据同步功能/`](../design/数据同步功能/)（结论已影响后续实现：同步层因此硬拦截 `--squash` 与 `--force`）

理由：分析是设计的直接输入，读设计时应该能顺手看到它。
