# 实施总结

功能模块实施完成后的总结报告。必填章节见 [`../wiki/05-implementation/01-开发流程与规范.md`](../wiki/05-implementation/01-开发流程与规范.md) §1.6：代码实装状态（逐 Task 打勾）、与设计文档的对比表、已解决问题列表、文件清单、已知限制、下一步工作。

## 落点约定

规范允许实施总结落在本目录**或** `../plans/<领域>/`（§1.6 交付物 1）。**本项目统一选后者**：

- 单一主题的实施总结 → [`../plans/<领域>/`](../plans/)（例如云同步的总结在 [`../plans/数据同步功能/`](../plans/数据同步功能/)、自主进化 Agent 的 P1 总结在 [`../plans/自主进化Agent/`](../plans/自主进化Agent/)）
- 本目录只收**跨主题、无法归入单一领域**的实施总结

理由：一件事的设计、计划、总结放同一处，查"这件事当时怎么做的"不用跨目录。
